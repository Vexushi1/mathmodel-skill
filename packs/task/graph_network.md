# 图与网络 Pack

## 1. 进入条件

当题目对象可抽象为节点与边，并涉及连通、路径、流、匹配、传播、社区、中心性或网络韧性时加载。必须先说明节点、边、方向、权重、容量、时间和多重边如何从题目对象生成。

## 2. 路线比较与初始化结构化简优先项

先识别**图的特殊拓扑**，再决定算法：

- **连通分量**：可独立处理的分量先拆开，避免对整个网络统一求解。
- **树 / 森林**：无环结构优先树 DP、递归、割边/子树分解，不按一般图问题处理。
- **DAG**：优先拓扑序、动态规划和路径递推；有向无环性可把大量组合搜索降为线性/多项式算法。
- **二部图**：优先匹配、指派、最小顶点覆盖等专用结构。
- **流网络**：守恒、容量、费用若与题意一致，优先最大流/最小费用流，而不是一般 MILP。
- **度量/欧氏结构**：距离满足三角不等式或几何邻近时，优先利用 metric、空间索引和几何剪枝。
- **对称与等价节点**：结构完全等价的节点可聚合；周期/重复子图可只计算基本单元。
- **稀疏和局部性**：邻接范围有限时优先稀疏矩阵、局部更新和专用图算法。
- **边/权的生成机制**：若边只是人为阈值化产生，先验证阈值是否必要；图结构不成立时不要为了使用 GNN 强造图。

主模型应利用真实拓扑得到最小充分网络结构。多层网络、随机图、图嵌入或 GNN 可作为 comparator，专门检验复杂关系是否提供超出经典拓扑算法的额外信息。

## 3. 变量与公式闭环

- 定义节点集合 $V$、边集合 $E$、邻接/权重矩阵、容量、成本、时间和流守恒；
- 说明自环、重复边、方向、负权、缺失边和孤立节点处理；
- 路径、流、匹配或传播模型给出目标与约束；
- 中心性和社区指标说明现实含义及其与决策输出的关系；
- 动态网络明确快照、事件时间或时间展开规则。

## 4. 必做验证与输出

- 检查连通分量、孤立节点、重复边、负权环和容量一致性；
- 与小规模枚举、替代算法或理论上下界比较；
- 分析删边、增边、权重扰动和节点失效下的稳定性；
- 报告时间/空间复杂度和规模可行性；
- 工作簿保留节点表、边表、路径/流明细、网络指标、扰动场景和约束检查。

## 5. 否决或降级条件

图结构无法从题意解释、边权混合不同单位、方向/时间属性被忽略、算法前提不满足，或只给网络可视化而没有决策闭环时，模型不通过。GNN 等方法缺少标签、样本规模或经典基准时降级。
