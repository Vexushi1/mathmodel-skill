# 机理/物理题 Pack

## 1. 进入条件

当题目核心是几何关系、运动过程、传热传质、力学、电磁、流体、守恒、碰撞、遮挡、临界状态或连续演化时加载。必须先明确对象、坐标系、参考系、状态量、作用关系、边界和初始条件。

若结论依赖“是否碰撞/覆盖/遮挡/进入/退出/到达/可见”等物理或几何事件，进入具体 solver 前还必须闭合**精确事件判据**；若结论依赖连续时间临界时刻，必须先说明事件集合或局部区间结构，再选择求根、二分或时间离散方法。不能用“数值上看起来发生了”代替判据定义。

## 2. 路线比较

- **路线 A：经典机理模型 + 本题修正。** 从守恒律、几何关系、动力学方程或经验定律建立闭合模型，再加入题目特有边界、介质、阻力、延迟或离散修正。
- **路线 B：高保真数值或机理—数据融合。** 使用有限差分、有限元、数值积分、状态空间估计或机理约束学习；只有经典模型误差无法接受且数据、计算量和验证条件充分时采用。
- 选择依据必须落到误差来源、题目精度、参数可获得性和竞赛时限，不能用算法复杂度代替机理合理性。
- 几何/事件问题在扩大采样或上黑箱优化前，先检查对称性、可见/活动边界、临界集合、解析消元、单调区间和可证明候选域；只有不能可靠化简的部分再离散或数值搜索。

## 3. 变量与公式闭环

- 区分位置、速度、加速度、温度、浓度、通量、能量等状态变量，以及几何、材料和环境参数。
- 给出量纲一致的状态方程、守恒方程、几何约束、初边值条件和事件切换条件。
- 每个核心公式对应 Python 函数或变量；离散模型说明时间步、空间步和数值格式。
- 核心公式优先配对象关系图、公式来源图、约束来源图或临界状态图，不用通用流程图替代。

### 精确物理/几何判据闭合

当模型包含碰撞、遮挡、覆盖、可见性、到达、穿越、进入/退出、接触、包含关系或其他布尔事件时，至少恢复以下语义：

```text
physical event
→ object domain / active or visible subset
→ reference frame
→ exact mathematical predicate
→ quantifier order
→ line / ray / segment / surface / volume semantics
→ exact or approximate status
→ code predicate / evidence anchor
```

特别注意：

- 无限直线、射线和有限线段不是同一几何对象；若物理意义要求方向或端点限制，不能只检查到无限直线的最短距离；
- “覆盖整个对象”“每个点至少被一个资源覆盖”“存在一个资源覆盖所有点”等命题必须显式写出量词顺序，不能凭自然语言默认等价；
- 对连续边界/表面/实体进行数值判定前，先判断是否能由对称性、凸性、可见性、极值原理或临界点条件缩减到活动边界或有限临界集合；若不能证明缩减，再说明离散依据；
- 若存在两个数学上独立、计算代价合理的等价判据，例如距离判据与交点/投影判据，应优先用其中一个作为主判据、另一个作实现交叉复核；数值一致只能检查实现，不替代等价性证明。

### 活动边界、临界集合与缩域依据

若连续对象、几何边界、时间域或候选空间被缩减后再求解，必须消费 Module 02 的 Reduction Provenance，并按真实依据标记：

```text
exact             = 与原问题严格等价的变换、消元或对象重表达
proven_sufficient = 已证明保留全部所需临界解，或至少保留一个原问题最优解
heuristic         = 由物理直觉、经验、粗数据或计算预算提出，但没有充分性证明
```

- `exact` 说明等价或可逆关系；
- `proven_sufficient` 连接相应命题、证明、极值性质或其他充分性依据；
- `heuristic` 必须声明被排除的区域/对象，并设计弃置域反例检查或有限覆盖证据；结果只能在真实验证范围内表述，不能写成严格全域性质；
- 仅因为离散采样没有发现反例，不能把 heuristic 提升为证明；数值审查与数学充分性必须分开。

### 连续事件拓扑与边界定位

连续时间事件先定义状态或事件函数，例如 `I(t)` 或 `g(t)`，再描述事件集合。若事件可能多次进入/退出，优先表示为

```text
T = union_k [t_enter,k, t_exit,k]
```

而不是先验假定只有一个连续区间。

使用二分、牛顿、单调搜索或其他根定位方法前必须说明：

- 搜索时间域与有效 bracket；
- 当前 bracket 内的符号变化、单调性、单峰/局部相位或其他可定位依据；
- 左右端点的真实更新规则；
- 时间/状态容差和停止条件；
- 若全局状态呈 `0→1→0`、多次切换或非单调，如何先分段、粗定位或枚举候选事件，再在局部 bracket 精修。

“采用二分法求临界时刻”但没有 bracket、局部结构和更新规则，视为算法语义未闭合。

### 多资源组合语义

多个烟幕、传感器、执行器、车辆、能源单元、路径或其他资源共同作用时，先声明真实组合语义，例如：

```text
sum / union / intersection / max / min / forall-exists / exists-forall / custom
```

并写出对应数学关系。时长相加不能自动代表区间并集；单资源指标最优不能自动代表多资源协同最优；若真实语义是“对每个目标点，至少存在一个资源满足条件”，必须保持该 `forall-exists` 量词结构，不能错误改写成“存在一个资源满足全部点”的 `exists-forall` 结构。

## 4. 必做验证与输出

### 03A：当前主计算的内在有效性

只检查当前 locked model 与当前 numerical method 是否足以形成 accepted 主结果，按实际适用项执行：

- 量纲、符号方向、坐标转换、初值和边界条件检查；
- 极限状态、退化情形、守恒残差和几何可行性检查；
- 精确事件判据的方向/端点/量词/活动边界语义检查；
- 时间步/空间步、事件定位容差或数值积分精度是否足以支撑当前答案；
- 当前迭代/仿真方法的必要收敛或残差证据；
- 与解析解、严格简化模型或当前运行内可获得的独立等价判据进行实现交叉检查；
- 工作簿保留当前运行真实产生的状态轨迹、关键事件、边界状态、距离/角度等判定量、残差、离散精度和约束违反量。

### 03B：accepted 后的结论深化

参数敏感性、现实参数扰动、压力场景、替代模型/算法、多 seed / 多初值结论稳定性、失效边界扩展搜索等只在主工作簿 accepted 后进入 Module 03B。不得因为本 Pack 要求“最终应验证”就把这些内容提前塞进 03A 主质量门。

## 5. 否决或降级条件

出现以下情况时必须重构或降级：

- 单位不一致、坐标系混乱、参数来源缺失、边界条件不闭合或守恒明显违反；
- 物理事件只用模糊文字描述，无法给出可计算的精确判据；
- 把 line / ray / segment、表面/实体、可见/不可见区域或量词顺序混为一谈；
- 未证明活动边界/临界集合充分性，却把离散遗漏区域当成不存在；
- heuristic 缩域被写成 exact / proven_sufficient，或没有说明弃置域与有限验证边界；
- 对非单调或多区间事件直接使用全局二分而没有局部 bracket 与更新依据；
- 多资源真实存在协同或重叠，却用简单求和或独立单体结果替代联合判定；
- 离散结果不收敛，或只靠黑箱拟合解释物理机制。

无法验证的高保真模型降级为补充分析，不作为主结论。
