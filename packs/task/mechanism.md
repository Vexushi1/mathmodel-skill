# 机理/物理题 Pack

## 1. 进入条件

当题目核心是几何关系、运动过程、传热传质、力学、电磁、流体、守恒、碰撞、遮挡、临界状态或连续演化时加载。必须先明确对象、坐标系、参考系、状态量、作用关系、边界和初始条件。

## 2. 路线比较

- **路线 A：经典机理模型 + 本题修正。** 从守恒律、几何关系、动力学方程或经验定律建立闭合模型，再加入题目特有边界、介质、阻力、延迟或离散修正。
- **路线 B：高保真数值或机理—数据融合。** 使用有限差分、有限元、数值积分、状态空间估计或机理约束学习；只有经典模型误差无法接受且数据、计算量和验证条件充分时采用。
- 选择依据必须落到误差来源、题目精度、参数可获得性和竞赛时限，不能用算法复杂度代替机理合理性。

## 3. 变量与公式闭环

- 区分位置、速度、加速度、温度、浓度、通量、能量等状态变量，以及几何、材料和环境参数。
- 给出量纲一致的状态方程、守恒方程、几何约束、初边值条件和事件切换条件。
- 每个核心公式对应 Python 函数或变量；离散模型说明时间步、空间步和数值格式。
- 核心公式优先配对象关系图、公式来源图、约束来源图或临界状态图，不用通用流程图替代。

## 4. 必做验证与输出

- 量纲、符号方向、坐标转换、初值和边界条件检查；
- 极限状态、退化情形、守恒残差和几何可行性检查；
- 时间步/空间步收敛、求解容差和参数敏感性；
- 与解析解、简化模型、实验/附件数据或独立数值方法对照；
- 工作簿保留状态轨迹、关键事件、残差、离散精度和约束违反量。

## 5. 否决或降级条件

出现单位不一致、坐标系混乱、参数来源缺失、边界条件不闭合、守恒明显违反、离散结果不收敛或只靠黑箱拟合解释物理机制时，必须重构。无法验证的高保真模型降级为补充分析，不作为主结论。
