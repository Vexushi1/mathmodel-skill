# 综合评价题 Pack

## 1. 进入条件

当题目要求构建指标体系、综合评分、排序、分级、优选或比较对象时加载。先确认评价对象、评价目的、决策主体、时间/空间口径和最终排序或分类用途。

## 2. 路线比较

- **路线 A：透明指标体系 + 稳健赋权。** 完成指标筛选、方向统一和量纲处理后，使用熵权、CRITIC、AHP 或组合赋权，再采用 TOPSIS、加权和、秩和或聚类完成评价。
- **路线 B：潜变量、效率或偏好学习。** 在数据和机制支持时使用 PCA/因子分析、DEA、模糊评价、离散选择或学习排序，并用路线 A 验证方向和排序。
- 模型选择必须说明“距离、效率、隶属度或潜变量”对应的现实含义。

## 3. 变量与公式闭环

- 指标先于赋权，记录指标来源、正负向、单位、层级、缺失和现实解释；
- 检查高相关、重复计量、低方差和目标泄漏；
- 说明归一化、权重、综合得分和排序规则；
- AHP 需一致性检验，熵权只反映离散度，不能直接解释为现实重要性；
- 组合赋权说明主客观权重的融合机制。

## 4. 必做验证与输出

- 替代归一化、替代赋权或权重扰动；
- 指标删减、异常对象和缺失处理敏感性；
- 使用 Spearman/Kendall、Top-k 重合率或名次区间检查排序稳定性；
- 与单指标、专家规则或已知等级对照；
- 工作簿保留原始指标、标准化值、权重、综合得分、名次和扰动下名次。

## 5. 否决或降级条件

指标含义不清、正负向错误、重复指标被多次计权、权重来源无法解释、TOPSIS 理想点不具现实含义，或轻微扰动导致排名完全翻转时，主评价体系必须重构。复杂方法不能提高解释性或稳定性时降级。
