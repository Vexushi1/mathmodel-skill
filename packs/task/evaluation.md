# 综合评价题 Pack

## 1. 进入条件

当题目要求构建指标体系、综合评分、排序、分级、优选或比较对象时加载。先确认评价对象、评价目的、决策主体、时间/空间口径和最终排序或分类用途。

## 2. 初始化结构化简优先项

综合评价之前先判断**题目是否真的需要构造综合指数**：

- 若题目已经给出明确目标函数、合格阈值、硬性优先级或唯一决定性指标，优先直接回答，不为形式完整强行 AHP/熵权/TOPSIS。
- **指标定义优先**：先剔除同义、重复、线性依赖或由定义可恢复的指标；能由守恒/比率关系消去的信息不重复计权。
- **支配与 Pareto**：若对象 A 在所有关键指标上不劣且至少一项更优，可先删除被严格支配对象，再讨论权衡。
- **单调变换不变性**：明确排序是否只依赖相对次序，避免对不影响结论的归一化或尺度处理赋予虚假“方法创新”。
- **阈值/等级结构**：存在明确标准时优先建立可解释的分级规则，而不是先压成单一分数再反推等级。
- **权重必要性**：只有当多个不可约指标必须折中时才引入权重；客观离散度不自动等于现实重要性。
- **潜变量/效率模型**：只有指标存在共同潜在结构、前沿效率或偏好机制时，才考虑 PCA/因子/DEA/学习排序。

主模型应是能直接回答评价目的的最小充分评价结构；复杂评价模型可作为 comparator，用于检验排序、分级或权重机制是否真正改变结论。

## 3. 变量与公式闭环

- 指标先于赋权，记录指标来源、正负向、单位、层级、缺失和现实解释；
- 检查高相关、重复计量、低方差和目标泄漏；
- 说明归一化、权重、综合得分和排序规则；
- AHP 需一致性检验，熵权只反映离散度，不能直接解释为现实重要性；
- 组合赋权说明主客观权重的融合机制。

## 4. 必做验证与输出

- 替代归一化、替代赋权或权重扰动；
- 指标删减、异常对象和缺失处理敏感性；
- 使用 Spearman/Kendall、Top-k 重合率或名次区间检查排序稳定性；
- 与单指标、专家规则或已知等级对照；
- 工作簿保留原始指标、标准化值、权重、综合得分、名次和扰动下名次。

## 5. 否决或降级条件

指标含义不清、正负向错误、重复指标被多次计权、权重来源无法解释、TOPSIS 理想点不具现实含义，或轻微扰动导致排名完全翻转时，主评价体系必须重构。复杂方法不能提高解释性或稳定性时降级。
