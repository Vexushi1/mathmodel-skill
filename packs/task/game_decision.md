# 博弈与决策 Pack

## 1. 进入条件

当存在多个具有不同目标的参与者，且一方策略会改变他方收益、响应或信息时加载。先明确参与者、策略集合、收益、信息结构、行动时序、承诺能力和均衡概念。

## 2. 初始化结构化简优先项与 comparator 选择

首先判断题目是否**真的需要博弈模型**，再判断需要哪一种均衡结构：

- **战略互动必要性**：若各主体目标并不相互依赖，问题应拆成独立优化或集中式决策，不为了“多主体”强行博弈。
- **支配策略**：存在严格/弱支配策略时先消去被支配策略，必要时可直接得到均衡。
- **零和/常和**：若收益可化为零和，优先 minimax / 线性规划结构。
- **potential / identical-interest**：若存在势函数或共同目标，可把均衡搜索化为单一优化问题。
- **行动时序**：只有题面确有先承诺—后响应时才进入 Stackelberg；同时行动不能被人为改成双层。
- **信息结构**：完全/不完全信息、可观测/不可观测、信念更新必须由题面决定；信息结构不能靠方便求解假设。
- **best response 结构**：检查单调性、凸性、唯一响应和阈值性质，能解析得到反应函数时先化简再求均衡。
- **联盟与可转移效用**：合作博弈只有在联盟价值和可执行分配有现实基础时使用。

主模型是保留真实战略依赖后的最小充分决策/博弈结构。MPEC、双层规划、多主体仿真可作为 comparator，检验先后决策、有限理性或复杂交互是否真正改变策略。

## 3. 变量与公式闭环

- 定义参与者 $i$、策略 $s_i$、收益 $u_i$、信念、约束和时序；
- 收益函数必须由题目数据、成本收益机制或可解释参数构成；
- 明确纯/混合策略、完全/不完全信息和一次/重复博弈；
- 双层模型给出上下层变量、目标、约束和响应映射；
- 合作博弈说明联盟价值、分配公理和可执行条件。

## 4. 必做验证与输出

- 检查均衡存在性、唯一性或多均衡选择规则；
- 比较集中决策、非合作基准和不同信息情景；
- 对收益参数、信念、响应弹性和理性程度做敏感性；
- 检查策略可执行性、个体理性和预算/资源约束；
- 工作簿保留策略组合、参与者收益、均衡残差、情景比较和参数扰动。

## 5. 否决或降级条件

参与者目标没有冲突或互动、收益函数无法量化、行动顺序与 Stackelberg 假设不符、响应函数不可识别、均衡残差未检查，或只写博弈名称而无闭环时，模型不通过。MPEC 等方法未通过高级方法准入时降级。
