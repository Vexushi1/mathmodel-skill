# 博弈与决策 Pack

## 1. 进入条件

当存在多个具有不同目标的参与者，且一方策略会改变他方收益、响应或信息时加载。先明确参与者、策略集合、收益、信息结构、行动时序、承诺能力和均衡概念。

## 2. 路线比较

- **路线 A：静态/动态经典博弈或多准则决策。** 根据同时或先后行动选择 Nash、合作博弈、演化博弈、动态博弈、贝叶斯博弈或决策分析。
- **路线 B：双层、Stackelberg、MPEC 或多主体仿真。** 只有真实存在领导者—跟随者结构、响应函数可识别、互补约束可求解且结果可验证时使用。
- 路线选择必须说明信息可得性、理性假设、收益来源和均衡与实际决策的对应关系。

## 3. 变量与公式闭环

- 定义参与者 $i$、策略 $s_i$、收益 $u_i$、信念、约束和时序；
- 收益函数必须由题目数据、成本收益机制或可解释参数构成；
- 明确纯/混合策略、完全/不完全信息和一次/重复博弈；
- 双层模型给出上下层变量、目标、约束和响应映射；
- 合作博弈说明联盟价值、分配公理和可执行条件。

## 4. 必做验证与输出

- 检查均衡存在性、唯一性或多均衡选择规则；
- 比较集中决策、非合作基准和不同信息情景；
- 对收益参数、信念、响应弹性和理性程度做敏感性；
- 检查策略可执行性、个体理性和预算/资源约束；
- 工作簿保留策略组合、参与者收益、均衡残差、情景比较和参数扰动。

## 5. 否决或降级条件

参与者目标没有冲突或互动、收益函数无法量化、行动顺序与 Stackelberg 假设不符、响应函数不可识别、均衡残差未检查，或只写博弈名称而无闭环时，模型不通过。MPEC 等方法未通过高级方法准入时降级。
