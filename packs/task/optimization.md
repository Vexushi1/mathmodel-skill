# 优化题 Pack

## 1. 进入条件

当题目要求选择方案、分配资源、规划路径、确定时序、控制成本、最大化收益或在约束下权衡多个目标时加载。先识别决策主体、决策时点、决策变量、可行域、目标和评价口径。

## 2. 路线比较

- **路线 A：结构化数学规划。** 根据线性、凸性、整数性和网络结构选择 LP、MILP、QP、SOCP、NLP、动态规划、最短路、流或匹配模型。
- **路线 B：分解、鲁棒/随机优化或启发式。** 仅在不确定性、非凸性或规模使经典精确方法不足时采用 Benders、列生成、场景优化、DRO、CVaR、ALNS、遗传算法等，并保留可解释的基准模型。
- 路线选择必须报告规模、变量类型、约束数量、理论性质、预期最优性证据和时间预算。

## 3. 变量与公式闭环

- 明确决策变量、辅助变量、状态变量、参数、目标指标和硬/软约束；
- 给出完整目标函数、约束集合、变量定义域和必要的线性化/松弛推导；
- 多目标问题说明量纲处理、权重来源或 Pareto 规则，不直接把异质目标相加；
- 每项约束对应现实机制和 Python 约束函数，惩罚项不能替代硬约束。

## 4. 必做验证与输出

- 输出求解器状态、最大约束违反量、目标值和可行性；
- 凸/精确问题报告对偶信息、KKT 残差或最优间隙；
- 非凸问题采用多初值、全局启发式 + 局部精修、上下界或网格/分支验证；
- 组合优化与基准算法、松弛下界或已知可行解比较；
- 工作簿保留推荐方案、变量明细、约束检查、多算法对比和参数扰动结果。

## 5. 否决或降级条件

没有闭合可行域、约束只写在文字中、惩罚系数无依据、启发式没有基准和重复运行、非凸结果无证明却宣称全局最优时，主模型不通过。高级优化方法未通过 `advanced_method_gate.md` 时降级为备选验证。
