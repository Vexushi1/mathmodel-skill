# 仿真题 Pack

## 1. 进入条件

当系统由随机事件、个体交互、排队、库存、传播、可靠性、复杂动态或难以解析的机制驱动，需要通过重复运行获得分布和风险时加载。先定义系统边界、状态、事件/转移、时间推进和停止条件。

## 2. 路线比较

- **路线 A：透明的离散事件、蒙特卡罗或系统动力学仿真。** 直接依据题目机制构造状态更新和事件逻辑，并用解析近似或简化模型校验。
- **路线 B：代理模型、智能体或仿真—优化。** 在交互异质性、规模或外层决策需要时使用 ABM、元模型、仿真优化或强化学习，但必须保留可解释的状态和奖励/成本机制。
- 路线选择说明随机性来源、时间尺度、计算预算和需要估计的统计量。

## 3. 变量与公式闭环

- 定义状态变量、事件类型、转移概率、随机变量分布、资源容量和停止条件；
- 参数分布必须有数据、文献或题目机制来源；
- 连续时间、固定步长和事件驱动方案说明更新顺序；
- 仿真—优化区分外层决策变量与内层随机输出，避免把噪声当成目标改进。

## 4. 必做验证与输出

- 固定并记录随机种子、重复次数和置信区间；
- 检查暖启动、稳态、时间步、运行长度和重复次数收敛；
- 采用共同随机数、对偶变量或分层抽样等方差控制时说明方法；
- 与解析结果、历史数据、边界场景和独立实现对比；
- 工作簿保留逐次试验、轨迹/事件明细、分位数、置信区间和收敛诊断。

## 5. 否决或降级条件

随机分布无依据、事件逻辑与现实矛盾、重复次数不足、未处理暖启动/稳态、结果随步长剧烈变化，或只展示单次轨迹时，仿真结果不通过。强化学习或代理模型缺乏稳定性和基准比较时降级为探索性分析。
