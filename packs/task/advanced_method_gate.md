# 高级模型与算法准入 Pack

仅在用户明确提出高级方法，或经典路线存在可说明且不可忽略的缺陷时加载。该文件不是高级名词清单，而是主模型准入门槛。

## 1. 七项硬门槛

候选方法必须逐项回答：

1. **必要性**：经典模型在哪个可量化环节不足；
2. **变量闭环**：新增变量、状态、分布、层级或策略是否可定义；
3. **数据支撑**：样本量、场景、标签、空间/时间结构是否足够；
4. **计算可行**：竞赛时间、内存和求解器能否完成；
5. **解释性**：核心机制、参数和约束能否进入论文；
6. **验证性**：是否存在基准、消融、上下界、外样本或多算法验证；
7. **复现性**：代码、随机种子、依赖、终止条件和底层结果能否交付。

任一关键项不通过，方法不得作为主模型；可降级为补充验证、敏感性场景或未来改进。

## 2. 常见方法专项门槛

| 方法 | 只有在以下条件满足时采用 | 最低验证要求 |
|---|---|---|
| W-DRO / 分布鲁棒优化 | 不确定分布确实影响决策；歧义集、距离和半径有数据或理论依据 | 与确定性、场景随机优化比较；半径敏感性；样本外表现 |
| CVaR | 题目关注尾部风险而非仅均值；置信水平和损失定义明确 | 不同置信水平、均值—风险前沿、极端场景回测 |
| MPEC / Stackelberg / 双层规划 | 存在真实先后决策；跟随者响应可识别；互补条件可求解 | 单层重构正确性、均衡残差、集中/非合作基准、参数敏感性 |
| ALNS / 元启发式 | 问题规模使精确法超时；邻域、修复和接受准则对应题目结构 | 小规模精确解、下界/间隙、重复运行、消融和时间预算 |
| GNN / 图深度学习 | 图样本或节点标签足够；图结构不是人为拼接；预测目标明确 | 经典图特征基准、时间/节点外验证、消融、稳定性和解释 |
| 空间杜宾等空间计量 | 权重矩阵有机制依据；空间诊断支持滞后/溢出 | 替代权重矩阵、残差空间相关、效应分解、稳健标准误 |
| DML / 因果机器学习 | 处理、结果和混杂明确；可辩护的识别假设；样本支持交叉拟合 | 平衡/重叠、替代学习器、安慰剂/敏感性、置信区间 |
| 强化学习 | 存在连续决策、可重复环境和可验证奖励；离线数据覆盖策略空间 | 规则/优化基准、多随机种子、奖励分解、安全约束和外场景 |
| 深度学习 | 样本量和结构复杂性足以抵消参数规模；任务确有非线性优势 | 简单基准、学习曲线、正则化、外样本、消融和不确定性 |

## 3. 准入记录

内部记录至少包含：候选方法、经典不足、所需新增变量、数据证据、计算预算、验证设计、主要风险和最终裁决。该记录属于模型选择过程，不机械进入终稿正文。

## 4. 终稿表达

正文只写：为何需要该方法、它解决了哪个具体缺陷、核心数学结构、求解方式、验证结果和适用边界。禁止用“模型更高级”“创新性强”代替证据。
