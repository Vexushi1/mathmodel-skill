# 空间模型 Pack

## 1. 进入条件

当观测对象具有坐标、区域邻接、距离、网络空间或明显空间相关，且问题关注空间分布、溢出、聚集、异质性或空间预测时加载。先明确空间单元、尺度、投影坐标、时间切片和边界单元。

## 2. 路线比较与初始化结构化简优先项

空间模型之前先识别“空间”到底提供了哪一种数学结构：

- **坐标与尺度**：先统一 CRS、距离单位和空间粒度；距离关系若可解析，优先直接使用几何关系而不是先构造黑箱权重矩阵。
- **对称与规则区域**：规则几何、周期网格、径向/平移对称可降维、卷积化或只计算基本区域。
- **邻接稀疏性**：局部邻接、有限支持 kernel、KNN 等形成稀疏结构时优先稀疏线性代数或图算法。
- **卷积/平稳结构**：规则格点且关系仅依赖相对位移时，检查 convolution / spectral / Toeplitz 结构。
- **边界与孤立单元**：先识别边界条件、孤岛和 disconnected region，能拆分的区域不强行同一模型。
- **网络等价**：若空间问题本质是邻接、路径、流或覆盖，优先转入 graph/network 专用结构。
- **空间相关是否必要**：先用残差或机制判断空间依赖是否真实存在；“有经纬度”不自动推出 SAR/SDM/GWR。
- **尺度与 MAUP**：题目若只要求某固定空间单元，不为方法复杂度主动引入多尺度；若结论对尺度敏感，再使用多尺度 comparator。

主模型应是保留真实空间依赖后的最小充分空间结构。SDM、贝叶斯层次、GWR、GNN 等可以作为 comparator，用来检验溢出、非平稳或复杂邻接是否显著改变目标结论。

## 3. 变量与公式闭环

- 定义空间单元、坐标/邻接、距离阈值、权重标准化和时间维度；
- 说明权重矩阵 $W$ 的构造、稀疏性、方向性和孤立单元处理；
- 区分空间滞后、空间误差和解释变量溢出；
- 空间回归报告直接、间接和总效应，不能只解释原始系数；
- 因果表述需额外识别假设，空间相关本身不构成因果证据。

## 4. 必做验证与输出

- 比较邻接、距离、K 近邻等替代权重矩阵；
- 检查 Moran's I、LISA、残差空间相关和边界效应；
- 使用稳健标准误、时空切分或留区验证；
- 检查尺度变化和 MAUP 风险；
- 工作簿保留空间单元键、坐标、权重摘要、局部统计量、效应分解和替代矩阵结果。

## 5. 否决或降级条件

空间单元与数据无法对齐、投影/距离计算错误、权重矩阵无机制依据、孤立单元未处理、残差仍有强空间相关，或直接把空间相关解释为因果时，模型必须重构。复杂图模型缺少空间基准和外区验证时降级。
