# 统计与机器学习 Pack

## 1. 进入条件

当任务涉及参数估计、假设检验、关系解释、分类、聚类、风险识别、特征筛选或因果分析时加载。必须先声明目标属于描述、预测还是因果，三者不能混写。

## 2. 路线比较

- **路线 A：经典统计模型。** 使用描述统计、检验、线性/广义线性模型、混合模型、降维或经典分类器，强调假设、置信区间和解释性。
- **路线 B：机器学习或半参数/因果方法。** 在非线性、高维或识别需求明确时使用集成学习、核方法、DML、倾向评分、因果森林等，并保留路线 A 作为解释和校验基准。
- 选择依据应包含样本量、变量维数、缺失机制、标签质量、类不平衡、可解释性和识别假设。

## 3. 变量与公式闭环

- 定义总体、样本、响应变量、特征、分组/时间结构、损失函数和统计量；
- 数据清洗、插补、标准化、编码、采样和特征选择必须在训练折内完成；
- 回归检查函数形式、共线性、异方差、残差和影响点；
- 因果模型明确处理、结果、混杂、识别假设和估计量，不由相关性直接推出因果。

## 4. 必做验证与输出

- 训练/验证/测试严格分离，分类使用分层或时间/组别感知划分；
- 报告置信区间或 Bootstrap，不只报点估计；
- 分类检查不平衡指标、阈值、校准和混淆矩阵；
- 回归检查残差、稳健标准误和替代设定；
- 工作簿保留样本划分、逐折指标、预测/残差、系数或重要性、校准和稳健性结果。

## 5. 否决或降级条件

存在数据泄漏、检验前提明显不满足、样本量无法支撑参数规模、只报告训练指标、用特征重要性代替因果效应，或因果识别假设不可辩护时，结论必须降级。黑箱模型无法验证且未优于透明基准时不作主模型。
