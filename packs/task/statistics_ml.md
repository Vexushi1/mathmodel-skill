# 统计与机器学习 Pack

## 1. 进入条件

当任务涉及参数估计、假设检验、关系解释、分类、聚类、风险识别、特征筛选或因果分析时加载。必须先声明目标属于描述、预测还是因果，三者不能混写。

## 2. 路线比较与初始化结构化简优先项

在选择统计模型或机器学习器之前，先确定**estimand / 识别对象**，再检查数据结构能否把问题降成低维：

- **目标类型先分清**：描述、关联、预测、因果对应不同 estimand；模型复杂度不能弥补目标定义不清。
- **可识别性优先**：先检查设计矩阵秩、处理/结果/混杂、重复测量、分组与时间结构；不可识别参数不能靠更复杂算法“估出来”。
- **充分统计量/低维参数**：若题目或分布结构允许用均值、方差、计数、低维系数等充分统计量回答，不保留全部原始高维状态。
- **函数形式与变换**：对数、比率、链接函数、分层结构或交互项若有机制依据，先让模型表达正确，再比较 ML 容量。
- **共线与冗余特征**：定义相关、近线性依赖、高相关重复变量先处理其数学冗余，不把冗余特征数量当作“高维复杂性”。
- **组别/时间依赖**：cluster、panel、longitudinal、paired data 先保留真实采样结构，不能用 i.i.d. 黑箱模型抹掉设计信息。
- **透明模型充分性**：低维 GLM/混合模型/经典分类器若已满足解释和外样本要求，可作为主模型；ML 只有在非线性或高维交互带来稳定增益时升级。

高级 ML、DML、因果森林等可作为 comparator 或主模型，但必须说明相对最小充分统计结构新增了什么可识别信息或预测能力。

## 3. 变量与公式闭环

- 定义总体、样本、响应变量、特征、分组/时间结构、损失函数和统计量；
- 数据清洗、插补、标准化、编码、采样和特征选择必须在训练折内完成；
- 回归检查函数形式、共线性、异方差、残差和影响点；
- 因果模型明确处理、结果、混杂、识别假设和估计量，不由相关性直接推出因果。

## 4. 必做验证与输出

- 训练/验证/测试严格分离，分类使用分层或时间/组别感知划分；
- 报告置信区间或 Bootstrap，不只报点估计；
- 分类检查不平衡指标、阈值、校准和混淆矩阵；
- 回归检查残差、稳健标准误和替代设定；
- 工作簿保留样本划分、逐折指标、预测/残差、系数或重要性、校准和稳健性结果。

## 5. 否决或降级条件

存在数据泄漏、检验前提明显不满足、样本量无法支撑参数规模、只报告训练指标、用特征重要性代替因果效应，或因果识别假设不可辩护时，结论必须降级。黑箱模型无法验证且未优于透明基准时不作主模型。
