# 预测题 Pack

## 1. 进入条件

当题目要求预测未来数值、类别、风险、需求、趋势或事件概率时加载。先锁定预测对象、时间粒度、预测跨度、可用历史窗口、信息可获得时点和数据泄漏边界。

## 2. 路线比较

- **路线 A：可解释基准 + 经典统计模型。** 至少设置朴素、季节朴素或线性基准，再比较 ARIMA/ETS、回归、状态空间或灰色模型等。
- **路线 B：机器学习、深度学习或机理融合。** 在样本量、特征质量和非线性证据充分时使用树模型、集成学习、序列网络或机理约束预测，并保留路线 A 作为基准。
- 选择依据应包括预测跨度、非平稳性、季节性、外生变量可得性、样本量和解释要求。

## 3. 变量与公式闭环

- 定义目标变量、时间索引、滞后项、窗口、外生变量、预测区间和评价指标；
- 所有特征只能使用预测时点之前可获得的信息；标准化、插补和特征选择必须在训练折内完成；
- 说明趋势、季节、周期、结构突变和异常值处理；
- 递归多步、直接多步或多输出策略必须与预测跨度一致。

## 4. 必做验证与输出

- 使用时间顺序划分、滚动验证或扩展窗口，不随机打乱时间；
- 报告至少一个尺度相关指标和一个尺度无关指标，并给出预测区间覆盖率；
- 检查残差均值、相关性、异方差、极端时段和结构突变；
- 与朴素基准、替代模型和不同窗口比较；
- 工作簿保留真实值、预测值、上下界、逐折指标、残差和特征/参数敏感性。

## 5. 否决或降级条件

存在未来信息泄漏、用训练集误差代替外样本误差、只报单一平均指标、预测跨度与验证设计不一致，或小样本盲用深度学习时，模型不通过。无法稳定优于朴素基准的复杂模型降级为补充。
