# 预测题 Pack

## 1. 进入条件

当题目要求预测未来数值、类别、风险、需求、趋势或事件概率时加载。先锁定预测对象、时间粒度、预测跨度、可用历史窗口、信息可获得时点和数据泄漏边界。

## 2. 初始化结构化简优先项

预测模型选择前先识别数据生成结构，目标是把“需要学习的未知部分”压缩到最小：

- **预测对象与 horizon**：先确定一步/多步、短期/长期、点预测/区间预测，不同 horizon 不共用未经论证的模型复杂度。
- **趋势、季节、周期与 regime**：能由题面周期、日历、制度阶段或显式趋势分解的部分先显式建模；机器学习只学习剩余结构。
- **信息可得时点**：外生变量、滞后项和统计量必须在预测时点真实可用；未来信息不能因为相关性强就进入模型。
- **最小充分状态/滞后**：检查是否存在 Markov 状态、低阶递推、充分滞后或状态空间表达，避免把完整历史窗口无差别输入高容量模型。
- **层级与同质结构**：多个地区/产品/主体若共享趋势或季节结构，优先考虑 pooling、hierarchical、grouped forecast，而不是每组独立堆模型。
- **目标变换与约束**：比率、增长率、对数、差分、守恒/容量约束若能显著简化动态关系，应在模型容量升级前考虑。
- **基准充分性**：季节朴素、漂移、线性/状态空间等透明基准若已满足题目精度和机制要求，它就可能是主模型；复杂模型只有在外样本证据显示仍存在可学习结构时升级。

主模型取能满足 horizon、精度和信息约束的最小充分预测模型。树模型、深度时序模型、机理融合等可作为 comparator，用于回答“非线性/长依赖/高维交互是否带来稳定的外样本增益”。

## 3. 变量与公式闭环

- 定义目标变量、时间索引、滞后项、窗口、外生变量、预测区间和评价指标；
- 所有特征只能使用预测时点之前可获得的信息；标准化、插补和特征选择必须在训练折内完成；
- 说明趋势、季节、周期、结构突变和异常值处理；
- 递归多步、直接多步或多输出策略必须与预测跨度一致。

## 4. 必做验证与输出

- 使用时间顺序划分、滚动验证或扩展窗口，不随机打乱时间；
- 报告至少一个尺度相关指标和一个尺度无关指标，并给出预测区间覆盖率；
- 检查残差均值、相关性、异方差、极端时段和结构突变；
- 与朴素基准、替代模型和不同窗口比较；
- 工作簿保留真实值、预测值、上下界、逐折指标、残差和特征/参数敏感性。

## 5. 否决或降级条件

存在未来信息泄漏、用训练集误差代替外样本误差、只报单一平均指标、预测跨度与验证设计不一致，或小样本盲用深度学习时，模型不通过。无法稳定优于朴素基准的复杂模型降级为补充。
