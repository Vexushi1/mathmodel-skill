# Artifact Pack：代码

## 进入条件

用户要求 Python/MATLAB 代码、可复现求解脚本、检验脚本或代码附件时加载。代码交付必须对应已锁定的变量、公式、约束和结果口径，不以通用脚手架代替题目实现。

## Python 输入契约

- 赛题、附件数据表和具体问题 Python 脚本直接放在同一项目根目录；
- 脚本使用 `Path(__file__).resolve().parent` 定位项目根目录；
- 明确输入文件、工作表、字段、单位、时间/空间粒度和关联键；
- 启动时检查文件存在、字段完整、空值、维度、重复、单位冲突和时间错位；
- 固定随机种子，并记录求解器、终止条件、容差和依赖版本；
- 核心公式、目标函数和约束必须能映射到函数或变量；
- 每问分别声明主/次题型与验证能力标志，禁止用项目级标签替代逐问契约。

## Python 输出契约

每问直接写入：

```text
结果数据表/问题X/
├─ 问题X求解结果.xlsx
└─ 问题X敏感性与鲁棒性结果.xlsx
```

不得再创建 `问题X结果数据/`。写入前由 `result_io.py` 按 `core/workbook_schema.yaml` 检查通用工作表、能力条件工作表、题型专项工作表、必需字段、显式主键、非空、缺失审计和非有限数值。不得默认导入 Matplotlib/Seaborn 或生成正式论文图。

## MATLAB 契约

- 每问唯一入口 `q{x}_plot.m` 与该问两类工作簿同放在 `结果数据表/问题X/`；
- 脚本使用 `fileparts(mfilename("fullpath"))` 获取自身目录并直接读取同目录工作簿；
- 不为简单绘图强制拆分目录搜索、读取或样式辅助函数；
- 以 `VariableNamingRule="preserve"` 保留中文字段；
- 绘图前声明工作簿、工作表、必需字段和排序规则；
- 只读取标准工作簿，不重新求解核心模型；
- 默认保留可见图窗，导出由显式分支触发并写入同级 `图表/`。

## 文件与入口

```text
项目根目录/
├─ 问题一求解.py
├─ 问题一敏感性与鲁棒性.py
└─ 结果数据表/
   └─ 问题一/
      ├─ 问题一求解结果.xlsx
      ├─ 问题一敏感性与鲁棒性结果.xlsx
      ├─ q1_plot.m
      └─ 图表/
```

主求解脚本必须有 `main()` 和 `if __name__ == "__main__":`。单脚本原则上 300--500 行以内，单函数 80 行以内；不得以删除检查、约束或结果底层数据换取短代码。

## 验收条件

- Python 代码可从项目根目录按复现说明运行；
- 两类工作簿通过 `scripts/hsk_check_artifact.py --mode data`；
- 每问 `q{x}_plot.m` 与两类工作簿同目录；
- 逐问题型与能力标志可从 `state/project_state.yaml` 定位；
- 约束型题最大违反量在声明容差内；
- 随机算法可由种子复现，并报告重复运行稳定性；
- 正文关键数值可从工作簿反向定位；
- MATLAB 图可由同目录工作簿重绘，不依赖手工录入摘要数字。
