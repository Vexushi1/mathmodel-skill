# Artifact Pack：代码

## 进入条件

用户要求 Python/MATLAB 代码、可复现求解脚本、检验脚本或代码附件时加载。代码交付必须对应已锁定的变量、公式、约束和结果口径，不以通用脚手架代替题目实现。

## Python 输入契约

- 明确项目根目录、输入文件、工作表、字段、单位、时间/空间粒度和关联键；
- 启动时检查文件存在、字段完整、空值、维度、重复、单位冲突和时间错位；
- 固定随机种子，并记录求解器、终止条件、容差和依赖版本；
- 核心公式、目标函数和约束必须能映射到函数或变量。

## Python 输出契约

每问写入：

```text
结果数据表/问题X/问题X结果数据/
├─ 问题X求解结果.xlsx
└─ 问题X敏感性与鲁棒性结果.xlsx
```

写入前由 `result_io.py` 按 `core/workbook_schema.yaml` 检查通用工作表、题型条件工作表、必需字段、显式主键、非空和非有限数值。不得默认导入 Matplotlib/Seaborn 或生成正式论文图。

## MATLAB 契约

- 只读取标准工作簿，不重新求解核心模型；
- 以 `VariableNamingRule="preserve"` 保留中文字段；
- 绘图前声明工作簿、工作表、必需字段和排序规则；
- 默认保留可见图窗，导出由显式可选函数触发。

## 文件与入口

具体项目使用中文描述性文件名，例如：

```text
问题一求解.py
问题一敏感性与鲁棒性.py
问题一结果绘图.m
```

主求解脚本必须有 `main()` 和 `if __name__ == "__main__":`。单脚本原则上 300--500 行以内，单函数 80 行以内；不得以删除检查、约束或结果底层数据换取短代码。

## 验收条件

- 代码可从项目根目录按复现说明运行；
- 两类工作簿通过 `scripts/hsk_check_artifact.py --mode data`；
- 约束型题最大违反量在声明容差内；
- 随机算法可由种子复现，并报告重复运行稳定性；
- 正文关键数值可从工作簿反向定位；
- MATLAB 图可由工作簿重绘，不依赖手工录入摘要数字。
