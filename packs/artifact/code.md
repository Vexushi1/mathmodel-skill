# Artifact Pack：每问自包含求解目录

每问的新项目默认只建立：

```text
问题X求解/
├─ 问题X求解.py
├─ 问题X求解结果.xlsx
├─ 问题X结果深化分析.xlsx
└─ qX_plot.m
```

`问题X求解.py` 是唯一Python文件：首次版本完成主求解；主工作簿验收后覆盖更新同一文件，加入结果深化分析阶段。完整运行配置嵌入代码并写入工作簿，不生成独立 YAML、MD 或校验报告。

MATLAB 只读取同目录两个真实工作簿，精确匹配表头，不重新计算核心结果，默认只保留图窗和 `qX_plot.m`。旧 `结果数据表/问题X/` 与独立分析脚本仅作只读兼容。
