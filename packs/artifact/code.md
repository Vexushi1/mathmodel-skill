# Artifact Pack：代码

## 进入条件

用户要求 Python/MATLAB 代码、可复现求解脚本、检验脚本或代码附件时加载。代码交付必须对应已锁定的变量、公式、约束和结果口径，不以通用脚手架代替题目实现。

## 当前框架前置条件

代码生成前必须读取项目根目录最新版 `模型论文框架.md`，核对当前模型、变量、参数、约束、算法和验证计划。代码或求解过程导致模型口径变化时，先将对应小问和框架标记 stale，删除旧模型与旧结果摘要，重写当前版本后再继续求解。每次正式代码交付必须同时附带完整最新版框架。

## Python 输入契约

- 赛题、附件数据表、`模型论文框架.md` 和具体问题 Python 脚本直接放在同一项目根目录；
- 脚本使用 `Path(__file__).resolve().parent` 定位项目根目录；
- 明确输入文件、工作表、字段、单位、时间/空间粒度和关联键；
- 启动时检查文件存在、字段完整、空值、维度、重复、单位冲突和时间错位；
- 固定随机种子，并记录求解器、终止条件、容差和依赖版本；
- 核心公式、目标函数和约束必须能映射到函数或变量；
- 每问分别声明主/次题型与验证能力标志，禁止用项目级标签替代逐问契约。

## Python 输出契约

每问直接写入：

```text
结果数据表/问题X/
├─ 问题X求解结果.xlsx
└─ 问题X敏感性与鲁棒性结果.xlsx
```

不得再创建 `问题X结果数据/`。写入前由 `result_io.py` 按 `core/workbook_schema.yaml` 检查通用工作表、能力条件工作表、题型专项工作表、必需字段、显式主键、非空、缺失审计和非有限数值。不得默认导入 Matplotlib/Seaborn 或生成正式论文图。

两类工作簿通过校验后，必须同步重写 `模型论文框架.md` 中该问的模型与算法、核心数值、验证/可行性、敏感性/鲁棒性、最终结论和证据位置。数值以工作簿为准，框架不保存与工作簿冲突的手工结果。

## MATLAB 契约

- 每问唯一入口 `q{x}_plot.m` 与该问两类工作簿同放在 `结果数据表/问题X/`；
- 脚本使用 `fileparts(mfilename("fullpath"))` 获取自身目录并直接读取同目录工作簿；
- 生成 MATLAB 代码前，必须先实际读取两类工作簿并锁定真实文件名、工作表名、第一行表头、固定列位置、单位和数据类型；
- 正式脚本直接写真实工作表名、真实表头文字和固定列号，不根据 Schema、旧模板或语义猜测字段；
- 优先使用 `readcell` 读取原始单元格，并对固定列执行真实表头断言，再从固定列提取绘图数据；
- 禁止动态表头校准、模糊匹配、别名映射、相似字段猜测、自动回退、自动搜索替代列或运行时改变列映射；
- 禁止交付仍含“明细结果”“横轴字段”“纵轴字段”等未实例化占位符的脚本；
- `VariableNamingRule="preserve"` 不能替代实际工作簿核对，也不能作为跨 MATLAB 版本的唯一字段读取保障；
- 工作簿结构变化时，重新读取并重写脚本中的真实名称和列位置，不增加动态兼容逻辑；
- 不为简单绘图强制拆分目录搜索、读取或样式辅助函数；
- 绘图前声明工作簿、工作表、真实字段、固定列位置和排序规则；
- 单图必须设置简洁 `title`，多面板必须设置一个整体 `sgtitle`，并默认保留在导出图中；
- 每个图标题及其图注、数据源、脚本和支撑结论必须同步写入 `模型论文框架.md`；
- 只读取标准工作簿，不重新求解核心模型；
- 默认保留可见图窗，导出由显式分支触发并写入同级 `图表/`。

## MATLAB 交付前检查

交付 `q{x}_plot.m` 前必须逐项确认：

1. 已读取本次实际工作簿，而不是复用历史表头；
2. 脚本中的每个工作表名与 Excel 完全一致；
3. 脚本中的每个表头断言与 Excel 第一行完全一致；
4. 每个绘图字段的固定列号与实际工作簿一致；
5. 脚本不含动态字段猜测、别名回退和未替换占位符；
6. 单图存在 `title`，多面板存在 `sgtitle`，标题简洁且不是结论性长句；
7. 标题和图表映射已同步到 `模型论文框架.md`；
8. 文件名变更或下载产生 `(1)`、`(2)` 后缀时，应明确锁定本次实际文件，不能宽泛匹配多个同名前缀文件；
9. 无法访问实际工作簿时，不输出正式绘图代码。

## 文件与入口

```text
项目根目录/
├─ 模型论文框架.md
├─ 问题一求解.py
├─ 问题一敏感性与鲁棒性.py
└─ 结果数据表/
   └─ 问题一/
      ├─ 问题一求解结果.xlsx
      ├─ 问题一敏感性与鲁棒性结果.xlsx
      ├─ q1_plot.m
      └─ 图表/
```

主求解脚本必须有 `main()` 和 `if __name__ == "__main__":`。单脚本原则上 300--500 行以内，单函数 80 行以内；不得以删除检查、约束或结果底层数据换取短代码。

## 验收条件

- Python 代码可从项目根目录按复现说明运行；
- 两类工作簿通过 `scripts/hsk_check_artifact.py --mode data`；
- `模型论文框架.md` 通过 `scripts/validate_model_paper_framework.py`，且本次交付包含完整最新版；
- 每问 `q{x}_plot.m` 与两类工作簿同目录；
- MATLAB 脚本已依据实际工作簿写入真实工作表、真实表头和固定列位置；
- MATLAB 脚本不含动态字段校准、别名回退或通用占位字段；
- MATLAB 正式图有简洁标题，框架中存在标题—图注—数据—结论映射；
- 逐问题型与能力标志可从 `state/project_state.yaml` 定位；
- 约束型题最大违反量在声明容差内；
- 随机算法可由种子复现，并报告重复运行稳定性；
- 正文关键数值可从工作簿反向定位；
- MATLAB 图可由同目录工作簿重绘，不依赖手工录入摘要数字。
