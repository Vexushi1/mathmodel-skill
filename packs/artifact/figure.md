# Artifact Pack：图表

正式结果图由 MATLAB 读取两类标准工作簿生成。每图必须记录源工作簿、工作表、MATLAB 脚本、图号和正文结论。

每个问题只交付一个自包含绘图文件 `MATLAB绘图/问题X/QX_plot.m`，其中 `X` 为问题编号。一次运行必须生成该问题全部需要的核心结果图、诊断图、多算法比较图、敏感性图和鲁棒性图；读取、样式、导出和项目根目录定位逻辑均写在同一文件的本地函数中，不额外交付辅助 `.m` 文件。

一个 `QX_plot.m` 可以创建多个独立图窗。只有同一结论确实需要互补证据时才组合多面板，不把所有图强行拼成总览图。不适用图不创建空图窗，由结果工作簿中的 `适用性说明` 记录原因。

默认图窗可见并保留；不批量自动导出。人工调整后使用同一 `QX_plot.m` 内的显式导出开关，将正式图保存到 `figures/`，可编辑源保存到 `figures_editable/`。

机理图根据题目选择 GeoGebra、PPT、draw.io、SVG、TikZ 或 MATLAB；禁止通用“输入—模型—输出”模板。
