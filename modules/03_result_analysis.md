# Module 03B：结果深化分析与证据增强

本模块只在 `result_quality_report` 通过后执行。它不重新定义主求解精度，也不把结果分析当成补救错误结果的工具。输入必须是已经在当前模型口径下算准并锁定的主结果。

## 1. 分析目标

结果深化分析回答：

- 结果为什么形成；
- 哪些因素主导结论；
- 结论在什么范围内稳定；
- 何时出现阈值、反转或失效；
- 是否存在算法偶然性、结构依赖或群体差异；
- 哪些证据最值得进入正文、图表和答辩。

敏感性、鲁棒性和多算法验证只是可选手段，不是固定三件套。

## 2. 先诊断风险，再选择方法

根据题目要求、模型结构、数据特征、主结果表现和评委可能质疑点，建立 `result_analysis_plan`。每项分析至少记录：

| 字段 | 要求 |
|---|---|
| 风险来源 | 参数误差、环境不确定性、局部最优、结构假设、样本漂移、权重主观性等 |
| 分析问题 | 需要解释或验证的具体结论 |
| 方法 | 与风险匹配的方法，不得默认统一扰动 |
| 输入 | 参数、样本、场景、算法、模型结构或分组 |
| 指标 | 弹性、排名变化、违反率、Gap、误差、覆盖率、稳定概率等 |
| 通过标准 | 结论稳定或方法一致的判据 |
| 论文作用 | 正文结论、图表、附录或仅内部复核 |

## 3. 可选分析族

按需选择 1—3 类高价值分析，必要时扩展，不要求全部执行：

### 参数与机制敏感性

局部弹性、参数剖面、Morris、Sobol、阈值分析、参数交互和相图。适用于结果确实依赖外生参数、权重或边界条件的题目。

### 不确定性与鲁棒性

Bootstrap、Monte Carlo、不确定性传播、场景压力测试、分布漂移、噪声污染、缺失与异常实验、区间或分布鲁棒分析。重点评价结论稳定性、可行概率和失效范围。

### 多算法与数值一致性

精确算法与启发式算法、小规模枚举、上下界、不同求解器、多初值、多随机种子、全局搜索与局部精修。重点检查局部最优、随机性和实现偶然性。

### 结构稳健性

替换损失函数、模型形式、约束集合、空间权重矩阵、分布假设、赋权方式、标准化方式或指标体系，判断核心结论是否依赖单一建模结构。

### 异质性与误差分解

按区域、时间、人群、资源等级、场景或风险层级分析差异；分解系统误差、随机误差、结构误差和数据误差。

### 阈值、边界与极端情景

识别策略切换点、可行域边界、临界容量、极端负荷、失效时间和安全裕度。机理、调度和资源配置题优先考虑此类分析。

### 外样本与迁移稳定性

滚动验证、时间外推、空间外推、跨组验证、分布漂移和校准稳定性。预测与统计推断题优先采用。

## 4. 禁止模板化实验

禁止以下做法：

- 对所有参数统一做 ±5%、±10% 扰动；
- 把随机重复运行直接称为鲁棒性；
- 把主求解器状态重复包装为多算法验证；
- 为凑章节生成无解释的敏感性曲线；
- 用后续分析掩盖主结果未收敛、不可行或外样本精度不足；
- 在方法明显不适用时生成空表或占位图。

## 5. 反馈回路

结果深化分析不是只负责证明原结论。若发现合理变化下结论频繁反转、不同算法差异显著、结构选择导致结果失真或关键群体误差失控，必须：

```text
标记主结果与下游图表 stale
→ 回退模型设计或主求解
→ 修改数据处理、参数、约束、算法或模型结构
→ 重新完整求解并通过质量门
→ 基于新结果重新开展深化分析
```

不得在旧结果后追加解释继续写论文。

## 6. 结果深化工作簿

统一输出：

```text
结果数据表/问题X/问题X结果深化分析.xlsx
```

工作表只创建实际执行的分析，例如：

- `参数敏感性`；
- `阈值与失效边界`；
- `场景压力测试`；
- `算法一致性`；
- `结构稳健性`；
- `异质性分析`；
- `误差分解`；
- `外样本稳定性`；
- `结论稳定性汇总`。

必须保留逐参数、逐场景、逐算法、逐分组或逐重复的底层数据。分析规模较大时可以拆分多个工作簿，但不得恢复固定的“敏感性与鲁棒性结果.xlsx”模板。

## 7. 输出与写作衔接

本模块输出：

- `result_analysis_plan`；
- `result_analysis_workbook`；
- `result_analysis_report`；
- `validated_results`；
- 更新后的 `evidence_map`；
- 当前版 `model_paper_framework`。

框架中只写实际采用的方法、关键数值、稳定范围、失效边界、回退记录和证据位置。论文按题型裁剪章节，可以称为“结果分析”“模型检验”“稳定性分析”或更具体的题目专属标题，不机械设置“敏感性与鲁棒性分析”。
