# Module 03B：在同一Python脚本中加入结果深化分析

本模块只接受已验收的主工作簿。根据真实主结果选择参数敏感性、场景压力、多算法/多初值、结构稳健性、阈值、异质性、误差分解或外样本稳定性。

## 更新规则

```text
主工作簿accepted
→ 建立result_analysis_plan
→ 覆盖更新问题X求解/问题X求解.py
→ 用户本地运行analysis阶段
→ 同目录问题X结果深化分析.xlsx
→ 验收后进入analyzed或redo_required
```

不得另建 `问题X结果深化分析.py`，不得生成独立运行配置、运行说明或校验报告。若核心结论未保持，必须回退模型设计或主求解并标记下游 stale。
