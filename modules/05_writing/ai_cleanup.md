# Module 05C：AI 模板感清除

本模块只负责**清除模板化、空泛化、机械重复和推理呈现风险**，不建立第二套正文写作规则。

正文结构、章节组织和表达权威：`modules/05_writing/latex.md`。
跨竞赛推理、规则等级、术语、数值展示、标题主张、命题预算、引用证据和段落必要性治理：`core/writing_reasoning_contract.yaml`。

若本模块与上述 Authority 出现冲突，以 Authority 为准；本模块不得把 Recommendation 重新写成 Hard。

> **Skill 负责原则，脚本负责穷举。** 本模块不再通过不断追加编号条目维护“第100条、第150条”式检查清单；确定性结构检查集中交给 `scripts/audit_paper_prose.py`。

## A. Integrity / Hard boundary

本层只确认不能被语言润色掩盖的事实与交付边界：

- 摘要、正文、表格和图中的核心数值必须回到已验收工作簿复核；
- stale 模型、结果、命题、图表或 paper fragment 不得当作 current 使用；
- 真实的算法分歧、边界失效、异常样本、阈值敏感和与预期不一致结果不得为了叙事顺滑而删除；
- 有限数值实验、准确率或求解器退出状态不得冒充严格数学证明；
- 必需的 citation、label、ref 和正式 LaTeX 结构必须闭合；
- **评分型连续核心结果不得为了“简洁”擅自降精度。** 题面、官方规则、官方评讲或已核验评分口径指定精度时严格服从；没有更具体口径时，摘要和正文默认优先保留小数点后 6--7 位的高精度决定性结果。

本层发现的确定性错误交由 Authority 和 audit 映射为 blocking；本模块不重复定义具体规则。

## B. Evidence closure

围绕“这句话、这个数字、这个图到底支撑什么”清理正文：

- 空泛的“显著提高、明显优于、效果较好、稳定性强”必须换成可追溯的误差、排名、提升率、区间、约束违反量、外样本或扰动结果；
- 核心结论至少能回到公式、命题/证明、工作簿、图表、约束检查、结果深化或代码输出之一；
- Formula Trace 只保留有 `Source → Derivation → Destination` 的核心关系；无后续用途公式删除、压缩或移附录；
- Citation Evidence 只支撑外部来源型主张，不能代替本文自己的推导和工作簿结果；
- Terminology Registry 中的标准术语保持一致，不为了“避免重复”机械更换同义词；易混术语必须保留不同定义、单位、分母或样本单元；
- Numeric Profile 决定核心结果的展示口径。摘要可以减少次要数字数量，但不能降低保留下来的评分型核心结果的小数位；
- Title Claim Gate 要求标题中的主方法、核心机制或核心贡献在至少一个核心问题中有实质建模/算法使用和结果证据；
- 深化分析进入正文前明确标记 `support / modify / reject`，并说明它支撑、修正或否决了哪个具体主张。

## C. Style & necessity

重点处理机器难以替代人工判断的语言与删减问题：

- “本节主要……”“下面将……”“为了更好地解决……”等重复管理型句子；
- 多段连续以“本文/本问/该模型”作主语；
- 多次使用“本文不是……而是……”“不能……只能……”制造无必要冲突；
- “首先、其次、最后”“由图可知”“由表可知”等固定短语高密度重复；
- 与本题无直接作用的模型史、算法百科、通用优点和大段教科书定义；
- “揭示、表征、耦合、驱动机制、内在关联、多尺度”等抽象词无对象支撑地连续堆叠；
- 逐格复述表格、逐点重复图中数值的报表式段落；
- 连续图表解释复制同一三句式；
- 图内标题、正式 caption 和正文解释逐字重复；
- 为凑数量设置变量定义型、题意复述型或直接代数变形命题。

清理目标不是禁词，而是恢复自然的信息推进：

```text
具体对象/条件 → 当前困难 → 数学处理 → 证据/结果 → 下一步或边界
```

### Paragraph Necessity Test

对每一节和较长段落都问：删掉它以后，是否会丢失以下任一内容？

```text
题意要求
机制或对象关系
数学关系
求解/参数依据
结果或验证证据
必要适用边界
标题/Citation/跨问依赖闭环
```

如果全部为“否”，优先删除、与邻段合并或移到附录。机器只能给 `possible_redundant_paragraph` warning，不能自动删除正文。

## D. Optional machine diagnostics

清理完成后运行：

```bash
python scripts/audit_paper_prose.py \
  final_latex/main.tex \
  --bib final_latex/references.bib \
  --framework 模型论文框架.md
```

脚本负责可可靠检查的结构与轻量启发式诊断，包括：

- missing/duplicate label 与不存在的 `\ref` 目标；
- 图表/公式编号未引用、图表引用距离异常；
- `\cite{}`、BibTeX missing/duplicate/unused 与 `\nocite{*}`；
- 图题/表题相对内容的位置、题注过长；
- Abstract 中出现图、表、图片或展示公式；
- 可识别的关键词数量；
- 已登记的不推荐术语别名、局部易混术语；
- Numeric Profile 已声明精度时的明显小数位不足；
- 公式密集、参数无邻近依据、模板句法、元话语和疑似冗余段落。

严重度继续遵循 Authority：

- Hard/确定性结构错误 → `blocking`；
- Default 偏离 → `review_required`；
- Recommendation/风格风险 → `warning`。

`--strict` 只阻断 blocking 或未解释的 review_required；warning 不阻断编译。

机器审计不得自动重写正文，也不得从正则推断数学正确性、公式真实来源、参数最优性、文献质量、citation 语义支持、未登记术语的同义关系或物理单位正确性。

最终文本保持规范、朴素、技术含义稳定，并保留真实推理痕迹。用户若只要求润色正文，默认直接输出最终文本，不保留原文对照，除非另有要求。
