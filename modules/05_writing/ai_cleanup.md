# Module 05C：AI 模板感清除

本模块只负责**清除模板化、空泛化、机械重复和推理呈现风险**，不建立第二套正文写作规则。

正文结构、章节组织和表达权威：`modules/05_writing/latex.md`。
跨竞赛推理、规则等级、命题预算和引用证据治理：`core/writing_reasoning_contract.yaml`。

若本模块与上述 Authority 出现冲突，以 Authority 为准；本模块不得把 Recommendation 重新写成 Hard。

## 一、内容与证据清理

1. 删除“具有重要意义、提供参考价值、较好地解决、具有一定优越性”等没有证据落点的判断；
2. 将“显著提高、明显优于、效果较好、稳定性强”等表达替换为可追溯的误差、排名、提升率、区间、约束违反量、外样本或扰动结果；
3. 核心结论至少能回到公式、命题/证明、工作簿、图表、约束检查、结果深化或代码输出之一；
4. 无证据但重要的结论补检验，否则降级为讨论或删除；
5. 摘要数值与正文、表格和已验收工作簿一致；
6. 真实的局部不稳定、算法分歧、边界失效、异常样本、阈值敏感和与预期不一致的结果不得为了叙事顺滑而删除；
7. 模型评价不能替代模型检验。

## 二、模板段与元话语清理

重点识别并重写：

- “本节主要……”“下面将……”“为了更好地解决……”等重复管理型句子；
- 多段连续以“本文/本问/该模型”作主语；
- 多次使用“本文不是……而是……”“不能……只能……”“由于……因此本文不能……”制造无必要冲突；
- “首先、其次、最后”“由图可知”“由表可知”等固定短语高密度重复；
- 把对象名替换成另一赛题后仍完全成立的通用段落；
- 与本题无直接作用的模型史、算法百科、通用优点和大段教科书定义；
- “揭示、表征、耦合、驱动机制、内在关联、理论框架、多尺度”等抽象词无对象支撑地连续堆叠。

清理目标不是禁词，而是恢复自然的：

```text
具体对象/条件 → 当前困难 → 数学处理 → 证据/结果 → 下一步或边界
```

## 三、公式与求解呈现风险

按 reasoning contract 检查表现层风险，但不重新定义公式规则：

- 连续展示公式之间几乎没有解释；
- “进一步可得、同理可得、容易得到、不难得到”反复替代关键推理；
- 数值参数直接赋值但邻近没有题面来源、收敛、误差、验证或稳定性依据；
- 算法段只介绍软件或通用算法优点，没有当前变量、目标、约束、参数和终止条件；
- 高级算法前完全看不到解析关系、降维、候选域、界或分解等结构检查。

这些主要属于 warning/review 提示；机器不得由关键词判断公式正确性、来源真实有效或参数最优。

## 四、结果与图表表达清理

- 删除逐格复述表格、逐点重复图中数值的报表式段落；
- 核心结果至少写清“发生什么—为什么—对题目意味着什么”；
- 连续图表解释不要复制同一三句式；可从关键数值、异常、对比、阈值、空间差异或边界切入；
- 只有 caption、正文完全不引用核心图表属于证据链风险，应按 writing authority 补显式编号引用；
- 图内标题、正式图注和正文解释各自承担不同功能，不逐字重复。

## 五、命题与证明清理

命题准入与预算由 `writing_reasoning_contract.proposition_governance` 和 `packs/artifact/proposition_proof.md` 管理。本模块只清理以下问题：

- 为凑数量设置变量定义型、题意复述型或直接代数变形命题；
- 有限数值实验、模型准确率或求解器退出状态冒充严格证明；
- 证明循环论证、隐藏必要条件、偷换变量/定义域，或把局部性质扩大为全局性质；
- 证明结束后没有说明对后续模型或计算的实际作用；
- 连续短证明被机械拆成列表，或真正多阶段证明被挤成一整块长段。

0--4 是默认阅读预算，不是自动否决线；超过预算时只检查是否有必要性说明和是否可合并/移附录。

## 六、引用证据清理

引用语义规则由 `writing_reasoning_contract.citation_evidence` 唯一定义。本模块只做写作层检查：

- 外部经验参数、数据、领域事实、非显然标准定理或既有研究比较是否有实际引用位置；
- 引用后是否说明该外部参数/结论怎样作用到本题，而不是只在句末堆 citation；
- 本文自己的推导和数值结果是否错误地依赖外部文献代替证据；
- 是否存在为“看起来有文献”而加入的无实际正文用途引用。

BibTeX key、重复条目、未使用条目等确定性结构问题交给 `scripts/audit_paper_prose.py`。

## 七、科研初学者式自然重写

最终文本保持规范、朴素、技术含义稳定，并保留真实推理痕迹。允许适度解释为什么建立下一关系、某条件怎样缩小搜索范围、某结果为什么需要继续比较。

不通过故意病句、口语化、机械同义词替换或频繁自我否定来制造“人工感”。固定专业术语、数学对象和变量含义必须保持一致。

用户若只要求润色正文，默认直接输出最终文本，不保留原文对照，除非另有要求。

## 八、机器审计

清理完成后运行：

```bash
python scripts/audit_paper_prose.py final_latex/main.tex --bib final_latex/references.bib
```

机器审计只处理可可靠检测的结构、重复和 BibTeX 问题：

- Hard/确定性结构错误 → blocking；
- Default 偏离 → review_required；
- Recommendation/风格风险 → warning。

`--strict` 只阻断 blocking 或未解释的 review_required；warning 不阻断编译。

机器审计不得自动重写正文，也不得从正则推断数学正确性、公式真实来源、参数最优性、文献质量或引用是否真正语义支持某个 claim。
