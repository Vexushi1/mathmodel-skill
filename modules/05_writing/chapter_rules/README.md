# Chapter Writing Rules (v8.0.0)

本目录保存章节级论文写作规则。

原则：章节规则属于 Writing Skill，不迁移到 Template Authority。

Template Authority 负责：
- 章节位置
- 标题结构
- LaTeX 渲染
- 环境组织

Chapter Rules 负责：
- 本章节应该解决什么写作任务
- 数学论证如何展开
- 变量、公式、结果如何衔接
- 常见失效写法与修正方式

## 保留章节能力

- abstract
- problem_analysis
- assumptions
- notation
- model_building
- solving
- result_validation
- evaluation
- conclusion
- appendix

## 重构原则

1. 不删除 v7.20 已形成的章节能力。
2. 只消除重复规则和职责冲突。
3. 通用数学叙事规则进入 core。
4. 章节特殊规则保留在对应章节。
5. 正式论文内容规则与内部工程治理规则分离。
