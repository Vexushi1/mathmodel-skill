# Module 05A：DOCX 草稿写作

DOCX 用于模型、结果和逻辑尚未完全锁定时的快速浏览、修改、批注和协作，不承担最终提交排版。

## 进入门槛与事实源

写作前必须读取项目根目录最新版 `模型论文框架.md`，并从每问两类标准工作簿复核核心数值。模型语义、章节结构、逐问结果摘要和图表映射以框架为当前入口；数值事实以工作簿为准；不得依赖聊天记忆重新拼接旧模型。

若框架标记 stale、结果摘要不是 current，或框架与工作簿冲突，停止写作并返回模型/求解模块修正。DOCX 结构调整若改变论文框架或图表位置，也要同步重写完整 `模型论文框架.md`。

## 内容要求

完整章节结构、逐问问题分析、模型路线、变量假设公式、核心结果表、结果解释、机理图合同或占位、结果图或占位、待补项和 LaTeX 迁移备注。正文不堆完整代码，可放精简伪代码；完整代码放附录或附件并配说明表。

各问写作必须直接消费框架中的“当前模型口径”“结果摘要”“证据位置”和“论文与图表映射”。不得保留框架已删除的旧参数、旧约束、旧结果或旧图表结论。

## 排版硬规则

- 用户已人工修改 DOCX 时，以最后上传版本为唯一底稿；
- 中文宋体、英文 Times New Roman、小四、两端对齐、段前后 0、首行缩进 2 字符、1.5 倍行距；
- 一级标题居中黑色，禁止默认蓝色；
- 表格必须是 Word 原生三线表，表题在上；
- 图片居中，图题在下，只写“图号 + 图名”；MATLAB 导出图中的简洁标题保留，图下注释补充统计口径且不逐字重复图内标题；
- 图后另起正文段解释；
- 核心公式单独居中、连续编号，公式前说明来源，公式后解释含义；
- 摘要分段，覆盖各问方法、核心数值和结论；
- 摘要、目录、正文、参考文献、附录等主要部分分页；致谢如有则单独分页。

输出前执行 `templates/writing/docx_check.md`。图后与表后解释按 `templates/writing/caption_explanation.md` 的证据要素组织，不套用固定句式。正式 DOCX 交付同时附带完整最新版 `模型论文框架.md`。
