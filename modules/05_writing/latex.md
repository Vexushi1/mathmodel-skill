# Module 05B：LaTeX 终稿写作

论文从首个正文版本开始直接使用 LaTeX，并在源码中持续修改至终稿。中文国赛基于 `templates/latex/cumcm/cumcmthesis/`。DOCX 不是进入本模块的前置条件；显式 DOCX 审阅件也不得成为模型或数值事实源。

## 进入门槛

- `模型论文框架.md` 为 current；
- 各已求解小问的主结果质量门通过；
- `问题X求解结果.xlsx` 包含主结果、底层明细和 `主结果质量门`；
- `问题X结果深化分析.xlsx` 包含 `分析设计`、实际分析数据和 `结论稳定性汇总`；
- 深化分析未要求回退重算；
- 若 `preprocessing_decision=project_level`，`数据预处理结果.xlsx` 已通过质量门，且 `data_process.m` 已基于工作簿真实底层数据形成至少一张有效预处理证据图；
- 若存在实质 `question_local` 数据变换，其数学定义、参数依据、验证数据和必要图证据已由对应小问工作簿/`qX_plot.m` 锁定；
- 结果图由 MATLAB 读取真实工作簿生成并人工确认；
- 全文命题必要性已筛选，数量允许为 0 且最多 4 个。

写作前读取框架中的当前模型、`preprocessing_decision`、预处理方法与证据、主结果、分析方法选择理由、稳定范围、失效边界和图表映射，再从实际工作簿复核数值。不得根据聊天记忆恢复框架已删除的旧模型、旧预处理、旧结果或旧分析。

## 终稿结构

摘要、关键词、问题重述、问题分析、假设与符号、数据预处理、各问建模求解、结果分析、模型评价与改进、结论、参考文献、附录。按题型裁剪；`not_needed` 时不机械保留大段“数据预处理”，可在数据说明中简洁交代审计结论。`project_level` 时必须保留实质的数据预处理章节/节。

各问推荐采用：

```text
模型详细推导
→ 必要命题与短证明（可选）
→ 核心模型汇总
→ 主求解算法与质量门
→ 主结果
→ 题目专属结果深化分析
→ 小问结论
```

结果深化部分根据实际方法命名，例如“阈值与失效边界”“算法一致性”“场景压力测试”“结构稳健性”“外样本稳定性”或“群体异质性”。不得为了版式完整堆砌未执行的分析标题。

## 数据预处理正文合同

### `not_needed`

只需说明数据审计结论和为什么原始数据可直接支撑模型，不编造清洗、插值或标准化步骤，也不为了论文形式完整强行画预处理图。

### `question_local`

若局部变换实质改变某问模型输入，则在该问的数据处理/模型输入构造段说明：

1. 数据问题或模型输入要求；
2. 实际变换公式、算法定义或确定性映射；
3. 参数、阈值、窗口或训练口径；
4. 方法合理性验证与误差/信息损失；
5. 处理后的变量如何进入该问模型；
6. 必要时引用该问 `qX_plot.m` 绘制的处理前后证据图。

### `project_level`

必须设置实质性的“数据预处理”章节或节，不能写成“对数据进行了清洗、插值和标准化”后直接跳到建模。正文至少形成：

```text
数据问题与必要性
→ 方法选择及替代方案说明
→ 数学公式/变换关系/目标函数
→ 参数与阈值来源
→ 方法合理性验证
→ 处理前后数据证据
→ data_process 图
→ 统一数据口径与后续模型接口
```

对于单位换算、坐标修正、主键对齐等确定性结构处理，应给出映射关系和一致性检查；对于标准化、归一化、对数/Box-Cox 等统计变换，应给出公式和参数估计范围；对于插值、填补、预测修复，应给出插值公式/目标函数/特征集合、边界条件与人工掩蔽或留出恢复误差；对于滤波、平滑、去噪、重采样，应给出核函数、频率响应或离散映射以及参数依据；对于异常删除/替换，应给出判定指标、阈值来源及保留/处理方案对照。

“合理的方法证明”不能机械等同于形式定理。只有存在等价性、守恒性、单调性、误差界或可行性保持等可证明命题时才写证明；经验型清洗以统计检验、物理约束、人工掩蔽、留出验证、残差、频谱、分布或处理前后对照作为合理性证据。

### 预处理图写法

`project_level` 的预处理图统一由 `数据预处理/data_process.m` 读取 `数据预处理结果.xlsx` 绘制。图可展示处理前后曲线/场/剖面、缺失与填补、分布、频谱、残差、恢复误差、采样覆盖、异常阈值等。图后正文必须解释：

- 图证明了什么数据问题；
- 处理后改善了什么可量化指标；
- 是否保留了需要的物理/统计结构；
- 验证误差或信息损失是否可接受；
- 为什么处理后的数据可以作为后续模型输入。

正式导出图片文件基名使用 `data_process` 或 `data_process_<evidence>`。

## 主结果与深化分析表述

主求解段先说明：

- 求解器、初始化、停止条件和随机种子；
- 当前模型下的精度、可行性、残差、收敛或外样本门槛；
- 主结果和必要底层明细；
- 不夸大最优性和泛化范围。

结果深化段必须说明：

1. 风险来源和为什么选择该方法；
2. 输入变化、场景、算法、结构或分组口径；
3. 判定指标与通过标准；
4. 稳定范围、阈值、差异或失效边界；
5. 对主结论的支持、修正或否决作用。

若预处理方法选择本身对最终结论敏感，应把不同合理预处理口径作为结构稳健性/场景对照的一部分，而不是把某一种处理结果包装成唯一事实。

若分析曾触发回退重算，正文只保留当前有效模型、当前预处理和最终证据，不叙述内部版本流水账。

## 命题与证明排版

- 全文命题允许为 0，最多 4 个；按章节编号为“命题 4.1”“命题 6.2”等；
- 命题优先用于问题简化、模型必要性、降维、约束删减、可行性保持、预处理等价性/误差界和理论失效边界；
- 使用 `hskproposition` 外框，将命题正文与 `hskproof` 短证明置于同一个外框内；
- 证明标题统一为“证明：”，结尾使用空心方块；
- 正文默认采用 B 级关键证明链，通常保留 2--6 个逻辑步骤；
- 完整证明超过半页时，正文保留条件、关键证明链、模型作用和失效边界，技术细节移附录；
- 命题框白底、细边、无阴影；流程图和机理图的彩色框限制不适用于命题证明环境；
- 数值实验、交叉验证、求解器状态和多算法一致性不能替代数学证明。

```latex
\begin{hskproposition}{变换模型的等价性}
\label{prop:equivalence}
在条件……成立时，原模型与变换模型具有相同的可行解映射和最优目标值。
\begin{hskproof}
由映射……可知两个可行域一一对应；目标函数保持不变，故最优值及最优解映射一致。
\end{hskproof}
\end{hskproposition}
```

## 排版与闭环

- 公式、命题、图表和交叉引用统一；
- 表格使用三线表，过长明细移附录；
- 图内保留简洁 MATLAB 标题，LaTeX 图注补充统计口径和解释，不逐字重复；
- 每张预处理图必须追溯到 `数据预处理结果.xlsx` 的真实工作表、字段和 `data_process.m`；
- 每张结果图追溯到主求解或结果深化分析工作簿、工作表、真实表头和 `qX_plot.m`；
- 摘要覆盖每问的模型、算法、主结果和结论，不把预处理步骤清单或分析方法清单当成结果；
- 正文不放完整代码，复杂算法用伪代码，完整 Python 和 MATLAB 代码放附录/附件；
- 模型、数据、预处理、参数或约束变化后，相关主结果、深化分析、命题和图表必须同步重算或标记 stale。

本模块输出 `latex_source_draft` 与可审查的 `paper_text`，随后执行 AI 模板感清除。清理后的 `latex_source` 才能进入编译模块。正式 LaTeX/PDF 交付同时附带最新版 `模型论文框架.md`。
