# Module 03：Python 求解、结果工作簿与验证

该模块统一代码求解、约束检查、多算法验证、敏感性和鲁棒性，禁止“算出一个数即结束”。

## 1. Python 主链路

路径配置 → 数据读取 → 字段/空值/维度/单位检查 → 异常处理 → 随机种子 → 特征/状态构造 → 模型与约束 → 求解 → 可行性检查 → 结果整理 → 多算法/多初值验证 → 敏感性与鲁棒性 → Excel 工作簿保存 → `main()`。

Python 不承担正式论文绘图。求解模板不得默认导入 `matplotlib`、`seaborn`，不得创建 `figures/` 或调用 `savefig`。

## 2. 求解可靠性

- 精确/凸问题：报告求解器状态、对偶间隙、KKT 残差或理论条件。
- 非凸连续优化：多初值、全局启发式 + 局部精修、上下界或网格/分支验证；无证明不写“全局最优”。
- 组合优化：给下界、松弛、最优间隙、重复运行和基准算法。
- 仿真：重复试验、随机种子、置信区间、收敛和方差控制。
- 数值机理：量纲、边界、守恒、极限状态和离散精度检查。

## 3. 统一输出

每问只建立一个结果数据目录：

```text
结果数据表/问题X/问题X结果数据/
```

其中固定输出：

```text
问题X求解结果.xlsx
问题X敏感性与鲁棒性结果.xlsx
```

### 求解工作簿

按需设置中文工作表：`核心指标`、`推荐方案`、`明细结果`、`约束违反检查`、`多算法对比`、`数据审计`。优化、调度、路径和带约束仿真必须包含 `约束违反检查`；不适用时在工作表中写明原因，不保留空表。

### 敏感性与鲁棒性工作簿

按需设置：`参数敏感性`、`鲁棒性区间`、`扰动明细`、`算法稳定性`。保留逐参数、逐扰动或逐重复试验数据，不只保留汇总结论。

## 4. 分题型验证

预测：基准模型、滚动/外样本验证、误差分解和残差诊断。

评价：替代赋权、权重扰动、秩相关、指标删减和归一化敏感性。

优化：约束最大违反量、多初值、多算法、参数扰动、上下界/最优间隙和解稳定性。

机理：量纲一致、边界状态、极限情况、守恒或几何可行性、离散误差。

统计/机器学习：数据泄漏、共线性、内生性、交叉验证、Bootstrap、校准和不确定性。

空间模型：空间权重矩阵替代、Moran/LISA、空间效应分解和稳健标准误。

## 5. 与 MATLAB 的交接

正式图必须满足：模型公式 → Python 函数 → 标准工作簿及工作表 → MATLAB 脚本 → 论文图号。复杂项目可选生成 `matlab_figure_handoff.json`，但不得用它替代工作簿中的真实数据。

## 6. 代码精简

优先成熟库和标准库；不写单实现接口、工厂、注册器或未来脚手架。删除无用 import、重复逻辑、进度条和调试输出，但不得删除输入审计、随机种子、目标函数、约束函数、约束检查和两类标准工作簿输出。
