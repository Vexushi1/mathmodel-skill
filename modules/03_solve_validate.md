# Module 03A：每问唯一Python脚本的主求解交付

本模块在 `问题X求解/` 中生成唯一的 `问题X求解.py`。助手只生成和静态检查，不运行赛题代码。

## 主链

```text
锁定模型
→ 创建问题X求解/问题X求解.py
→ 用户本地完整运行
→ 同目录问题X求解结果.xlsx
→ 验收运行配置与主结果质量门
```

脚本必须包含数据检查、模型、求解器状态、容差、停止条件、约束/残差、收敛或外样本检查、随机种子和中文工作簿输出。完整运行配置嵌入 `FULL_FIDELITY_CONFIG`，并写入工作簿的 `运行配置` 表；不生成独立 YAML、运行说明或报告文件。

主工作簿通过 `validate_user_execution.py` 验收后，才允许在原 `问题X求解.py` 中加入结果深化分析阶段。
