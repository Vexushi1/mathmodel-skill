# Module 03P：项目级统一数据预处理与数据口径冻结

## 0. 适用条件

当两个及以上小问共享同一原始数据源、共享统一清洗/坐标/单位/滤波/重采样口径，或用户明确要求统一数据总表时，本模块为正式求解前的强制阶段。

执行顺序固定为：

```text
problem_audit
→ model_design
→ data_preprocessing
→ solve_validate
→ result_analysis
```

模型设计阶段先说明哪些预处理是必要且有依据的；本模块只执行一次，不重新选择模型，不以结果好坏反向调参。

## 1. 核心原则

1. 原始数据是不可变事实源，不覆盖、不改写；
2. 全项目只维护一个统一预处理入口；
3. 默认目录固定为 `数据预处理/`；
4. 默认只生成两个文件：`数据预处理.py` 与 `数据预处理结果.xlsx`；
5. 原始数据只允许 `数据预处理.py` 直接读取；
6. 一旦统一工作簿通过质量门，所有问题主求解、深化分析和后续数据型绘图只能读取统一工作簿及已验收标准结果工作簿；
7. 小问专属派生特征可以在本问脚本内计算，但不得重新执行项目级清洗、滤波、单位换算、坐标修正或异常处理；
8. 若后问发现必须改变统一预处理口径，必须回退本模块，递增相关 semantic revision，并使依赖小问结果 stale。

## 2. 数据预处理合同

进入代码前必须锁定：

| 项目 | 要求 |
|---|---|
| 原始数据源 | 文件名、字段、单位、粒度、关联键 |
| 不可变字段 | 原始对象中必须原样保留的物理量或标签 |
| 允许处理 | 缺失、重复、异常、单位、坐标、滤波、重采样、编码等 |
| 禁止处理 | 会破坏题意或物理意义的归一化、删点、平滑、插值等 |
| 参数依据 | 每个不可逆处理参数必须给数据或机理依据 |
| 统一输出对象 | 后续所有小问共同读取的标准字段/矩阵 |
| 质量门 | 输出无未说明缺失、单位一致、维度一致、哈希可追溯 |

## 3. `数据预处理.py` 职责

脚本必须包含：

- 路径与原始文件存在性检查；
- 字段、维度、主键、坐标、单位、NaN/Inf、重复检查；
- 题目专属的数据质量审计；
- 模型设计阶段已锁定的统一处理；
- 处理前后关键统计量；
- 原始数据 SHA256 与脚本 SHA256；
- 预处理质量门；
- 单一 Excel 工作簿输出；
- 主函数入口。

禁止：

- 求解任一小问核心模型；
- 生成某一小问专属最优参数、预测、评价或决策结果；
- 为提高某问结果而局部改清洗参数；
- 输出论文图；
- 生成额外 JSON/YAML/日志文件作为默认交付。

## 4. 统一工作簿

默认文件：

```text
数据预处理/数据预处理结果.xlsx
```

公共必备工作表：

- `运行配置`：`项目, 值`；
- `数据审计`：`数据源, 检查项, 结论, 处理方式`；
- `预处理参数`：`步骤, 参数, 取值, 单位, 依据`；
- `预处理质量门`：`检查项, 是否通过, 证据`。

题目专属数据表按真实数据结构命名，但必须中文、含明确单位和索引。不得把不同物理对象硬拼成一张超宽表；“一个总表”指一个统一工作簿，可以包含多个有明确对象语义的工作表。

## 5. 下游读取硬规则

正式进入 `solve_validate` 后：

```text
问题X求解.py
    └─ 允许读取：数据预处理结果.xlsx + 已验收前问/本问标准工作簿
    └─ 禁止读取：原始 CSV/XLSX/TXT 等共享数据源
```

如果代码扫描发现后续问题再次直接读取统一原始数据源，应判为数据口径违规，而不是普通代码风格 warning。

## 6. 地震类题目的推荐统一输出

当地震类赛题同时给出速度模型与地震记录时，推荐统一工作簿包含：

- `参考速度模型`：保留经过坐标/单位审计后的参考速度场，不做无依据平滑或标准化；
- `预处理地震记录`：完成统一去直流、去趋势、频谱审计、经依据确定的零相位带通、必要坏道处理与边界 taper 后的振幅保持记录；
- `频谱审计`：有效频带、主频、噪声底等；
- `道质量审计`：RMS、robust Z-score、相邻道相关及坏道判定；
- 四个公共工作表。

原始速度突变若具有地质结构意义，不得按普通异常值删除。AGC、逐道强归一化等改变相对振幅的处理不得进入统一主数据链，除非题意明确要求且模型设计已说明其不会破坏后续幅值解释。

## 7. 语义与 stale 传播

统一预处理是模型语义的一部分。下列变化均属于 `preprocessing` 语义变化：

- 原始数据源变化；
- 坐标、单位、关联键变化；
- 缺失/异常处理变化；
- 滤波、重采样、标准化、插值或平滑参数变化；
- 统一工作簿字段或对象含义变化。

任一发生后，所有依赖该统一工作簿的小问主结果、深化分析、MATLAB图表和论文结果摘要全部 stale，不能继续沿用旧结果。

## 8. 阶段门槛

进入 `solve_validate` 前必须满足：

1. 模型设计已锁定数据预处理语义；
2. `数据预处理.py` 静态检查通过；
3. 用户本地 full-fidelity 运行并返回 `数据预处理结果.xlsx`；
4. 统一工作簿的 `预处理质量门` 全部通过；
5. 后续小问的数据依赖统一指向该工作簿；
6. 不再允许直接读取共享原始数据。

未完成时暂停在 `awaiting_user_preprocessing`，不得提前生成正式小问主求解结果。
