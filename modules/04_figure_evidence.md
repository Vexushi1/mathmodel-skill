# Module 04：MATLAB 结果图证据、预处理对照与机理图精修

## 正确顺序

1. 若 `preprocessing_decision=project_level`，先读取已验收的 `数据预处理结果.xlsx`，生成 `数据预处理/data_process.m` 并为预处理阶段选择有证据价值的图型；
2. Python 完成完整主求解并通过主结果质量门；
3. Python 基于题目风险完成实际需要的结果深化分析；
4. 锁定 `问题X求解/` 中的两个标准工作簿；
5. 继承当前 `preprocessing_decision`，明确绘图是否需要统一预处理工作簿、原始数据或只需要结果工作簿；
6. 为每张图先写 Core conclusion，再按信息效率选择图型；
7. 生成 MATLAB 代码前实际读取需要使用的工作簿，锁定工作簿名、工作表名、真实表头、单位和数据类型；
8. 设置简洁 `title` 或一个整体 `sgtitle`，拟定不逐字重复的论文图注；
9. 项目级预处理统一使用 `数据预处理/data_process.m`；每问通用命名合同写作 `q{x}_plot.m`，实际文件使用 `q1_plot.m`、`q2_plot.m` 等并放在 `问题X求解/`；
10. 检查核心结论是否有图或表证据，并同步 `模型论文框架.md`；
11. 只精修 S/A 级机理图；
12. MATLAB 默认只保留图窗供人工检查，不自动创建图表子目录或批量导出图片。

## P 类：数据预处理可视化证据

数据预处理也必须进入 MATLAB Figure Evidence 链。它的作用是**证明处理有必要、处理后数据满足当前模型输入要求且没有破坏关键信息**，不是为了让图形更平滑或更好看。

### P.1 准入与生成规则

必须先区分三种状态：

| 状态 | 预处理图规则 |
|---|---|
| `not_needed` | 不创建 `data_process.m`，也不生成“处理前后对比图”。数据没有发生项目级修改时不得为了流程完整伪造预处理图。 |
| `question_local` | 不创建项目级 `data_process.m`。若本问局部变换需要解释，在对应 `qX_plot.m` 中增加局部变换证据，底层变换必须由 Python 求解脚本完成并输出数据。 |
| `project_level` + `structural` | 必须创建 `data_process.m`。优先展示时间/空间对齐、采样覆盖、单位或坐标口径、表关联覆盖等真正可解释结构修正的图；若某个纯结构步骤不适合画处理前后曲线，则用最能说明数据口径变化的可视化，而不是伪造连续曲线。 |
| `project_level` + `transformative` | 必须创建 `data_process.m`，并至少包含一类处理前后或修复验证证据。若操作改变观测值、缺失结构、采样、频谱、分布或空间覆盖，应优先用二维对照图验证处理影响。 |

因此，`data_process.m` 的生成条件是 **`preprocessing_decision=project_level`**，而不是“某张图看起来是否漂亮”。脚本必须有证据内容，但不要求每个预处理操作各画一张图；只保留能够回答关键质量问题的图。

### P.2 Python → 工作簿 → MATLAB 接口

预处理图必须遵循：

```text
原始附件
→ 数据预处理.py
→ 数据预处理结果.xlsx
   ├─ 处理后正式数据
   ├─ 处理前/处理后对照底层数据
   └─ 修复或变换验证数据
→ data_process.m
→ 预处理证据图
```

Python 负责计算全部预处理结果，并把绘图需要的**真实底层数据**写入 `数据预处理结果.xlsx`。可按题目真实对象设置中文工作表，例如：

- `处理前后对照`：相同索引下的原始值、处理值及差值；
- `缺失修复验证`：被人工掩蔽或真实缺口位置、真实/估计值、误差；
- `采样覆盖对照`：处理前后时间、空间或网格覆盖；
- `异常处理对照`：原始值、判定依据、处理值和保留/修复标记；
- `频域对照`、`分布对照`、`空间对照`：仅在题目对象确实需要时建立。

这些工作表不是固定模板，禁止为了满足名称而生成空表。工作表名称和字段由实际预处理操作决定，但必须能从 Python 输出追溯到真实数据。

当 `project_level` 已启用时，MATLAB **不得重新读取共享原始附件来构造处理前曲线**。需要展示的“处理前”数据应由 `数据预处理.py` 原样抽取并写入统一工作簿，以保证 MATLAB 仍只读取冻结后的数据事实源。

### P.3 推荐图型

只在能够支撑一个明确判断时选择图型，常见证据包括：

- 连续序列：处理前后曲线叠加或分面，用于观察缺口修复、去趋势、平滑、滤波或重采样影响；
- 缺失数据：缺失位置/缺口长度分布、人工掩蔽恢复误差、真实值—估计值散点；
- 异常处理：处理前后局部分布、箱线/散点、阈值附近样本对比；
- 时间或空间采样：处理前后采样点、覆盖密度或规则网格对比；
- 多表结构统一：时间覆盖、空间覆盖、关联成功率、共同索引或结构映射的可视化；
- 滤波/去噪：时域与频域至少选真正需要的一类，不机械同时画两类；
- 标准化/变换：只有尺度或分布变化本身是模型成立条件时才画，不为常规标准化额外占版面。

预处理图不得仅证明“曲线变得更光滑”。正文必须解释处理消除了什么具体问题、保留了什么关键信息，以及处理结果为什么满足后续模型要求。

### P.4 MATLAB 职责边界

MATLAB 只负责读取 Python 输出的 Excel/CSV、绘图、布局、坐标轴、图例和论文展示。禁止在 MATLAB 中：

- 重新插值、填补、预测、滤波、平滑、去噪、异常修复或重采样；
- 根据论文希望的图形效果修改预处理参数；
- 从摘要统计量反推处理前或处理后的数据序列；
- 绕过 `project_level` 统一工作簿直接读取对应共享原始附件；
- 用绘图脚本承担预处理质量门或核心模型计算。

如果 MATLAB 绘图时发现数据口径存在问题，应回退 Python 预处理阶段修正并重新验收工作簿，而不是在绘图脚本里偷偷修数据。

### P.5 脚本放置与命名

1. `preprocessing_decision=project_level` 时统一建立 `数据预处理/data_process.m`；
2. 项目级数据预处理 MATLAB 绘图脚本的固定文件名为 **`data_process.m`**；
3. `data_process.m` 只读取 `数据预处理结果.xlsx`，不得读取对应共享原始附件；
4. 若某问还需要引用同一预处理证据，可在 `qX_plot.m` 中读取统一工作簿的相应工作表，但不得复制预处理计算；
5. `not_needed` 和 `question_local` 不创建项目级 `data_process.m`。

## A 类：机理与推导图

优先表达公式来源、约束来源、临界状态和策略机制。图内只放对象、变量、方向、边界、距离、角度、流向和临界状态，完整推导留在正文。禁止用通用“输入—模型—输出”流程图替代题目专属机理图。

## B 类：结果图合同

每张图记录：Core conclusion、Figure role、MATLAB title、论文 caption、Panel map、Source workbook、Worksheet、Required headers、Expected positions（可选）、MATLAB script、Export files、Statistics/error、Reviewer risk、Paper location 和 Caption duty。

结果证据优先来自本问主求解工作簿或结果深化分析工作簿：

- 主结果、决策变量、预测明细、基础误差和质量门证据来自 `问题X求解结果.xlsx`；
- 参数、场景、算法、结构、阈值、异质性和稳定范围证据来自 `问题X结果深化分析.xlsx`。

预处理证据来自 `数据预处理结果.xlsx` 中 Python 已输出的底层对照数据和验证数据，不得由 MATLAB 自己恢复或构造。

只有图本身确实需要底层数据时，才按 `preprocessing_decision` 追加数据事实源：

- `not_needed`：允许读取必要原始数据；
- `question_local`：允许读取必要原始数据，但不得在 MATLAB 中重新构造求解所需的模型变换；应优先使用 Python 已输出到底层结果表的数据；
- `project_level`：`data_process.m` 和需要数据事实源的 `qX_plot.m` 只读取 `数据预处理结果.xlsx` 中已冻结的数据及处理前后证据，不得绕回对应共享原始附件。

不得为了让所有 MATLAB 脚本结构一致而强制每张问题图读取 `数据预处理结果.xlsx`。若问题图只依赖标准结果工作簿，则不额外加载预处理数据。

不得在 MATLAB 中重新求解，不得从摘要数字反推绘图序列。图型必须提高信息展示或比较效率，否则降级为更直接的二维图。

## 实表读取规则

正式脚本必须：

1. 使用已核对的真实工作簿名、工作表名和表头；
2. 读取第一行原始表头并做空白归一化；
3. 对每个要求字段执行精确相等匹配，并断言只出现一次；
4. 可登记期望列号，当实际位置变化时给出结构漂移警告；
5. 禁止模糊匹配、别名词典、相似字段猜测和自动回退；
6. 工作簿变化后重新读取并更新 Figure Contract；
7. 检查文件、工作表、非空、主键、非法值和排序。

```matlab
headers = strtrim(string(raw(1, :)));
xMatches = find(headers == xHeader);
assert(numel(xMatches) == 1, "字段缺失或重复: %s", xHeader);
xColumn = xMatches(1);
if isfinite(expectedXColumn) && xColumn ~= expectedXColumn
    warning("字段%s由第%d列移动到第%d列", xHeader, expectedXColumn, xColumn);
end
```

## 图标题与风格

单图使用 `title`，多面板使用一个 `sgtitle`。标题只说明研究对象、指标关系和必要方法，不写结论长句。默认白底、细轴、低饱和深色、中文坐标轴和单位、字号 18，网格关闭或极浅。颜色不是固定约束，但同一对象和同一语义应保持一致。图窗默认可见，不批量自动导出。

处理前/处理后对比图应保证同一变量使用一致的坐标范围、单位和索引；若采用双轴会削弱可比性，优先改为分面或统一量纲。多面板中每个面板必须承担独立证据，不能把同一结论换三种图重复展示。

## 分析图准入

结果深化分析不是每种方法都要画图。只有满足以下条件时才入图：

- 分析方法与风险来源匹配；
- 图能展示稳定范围、阈值、算法一致性、结构稳健性、结构差异或异质性；
- 图的底层数据已完整写入分析工作簿；
- 图能直接支撑正文中的一个核心判断。

统一扰动曲线、无解释的算法柱状图和只展示“结果变化不大”的装饰图删除。

## 入文闭环

预处理图和结果图都必须形成：

```text
Python程序
→ 中文结果工作簿
→ 工作表
→ MATLAB绘图程序
→ 图像文件
→ LaTeX图号
→ 正文结论
```

图后另起正文段解释趋势、关键数值、机制、稳定范围或失效边界。预处理图还必须说明“为什么需要处理—处理改变了什么—哪些真实信息被保留—为什么可用于后续模型”。正式图片在进入 LaTeX 时按需人工导出；求解阶段不额外生成图片文件。
