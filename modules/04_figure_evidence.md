# Module 04：MATLAB 结果图证据与机理图精修

## 正确顺序

1. Python 完成求解、检验并锁定两类标准工作簿；
2. 先写每张图的 Core conclusion，再按 `templates/figure/chart_selection.md` 选择图型；
3. 同时读取 `templates/figure/scientific_composite_system.md`，判定使用单图、层叠组合图、多面板或混合组合图；
4. 为每个问题只生成一个自包含 MATLAB 文件 `QX_plot.m`；
5. 一次运行该文件，生成该问题全部结果图、诊断图、敏感性图和鲁棒性图；
6. 检查每个核心结论是否有图/表证据；
7. 回看早期机理图合同，只精修 S/A 级图；
8. 统一图号、图注、正文引用和结论映射。

## A 类：机理/推导图

优先表达公式来源、约束来源和临界状态，其次是对象关系和策略机制。图内只放对象、变量、方向、边界、距离、角度、流向和临界状态，完整推导留在正文。

几何图优先 GeoGebra/SVG，结构图优先 PPT/draw.io/SVG，可编译结构图可用 TikZ；数据驱动机理图可以由 MATLAB 读取结果工作簿绘制。禁止用通用“输入—模型—输出”流程图替代题目专属机理图。

## B 类：结果图

每张核心图建立：Core conclusion、Figure role、Composition level、Layer map、Axis contract、Panel map、Source workbook、Worksheet、MATLAB script、Local plot function、Export files、Statistics/error、Rendering transforms、Reviewer risk、Paper location 和 Caption duty。

源数据只允许来自：

```text
结果数据表/问题X/问题X结果数据/问题X求解结果.xlsx
结果数据表/问题X/问题X结果数据/问题X敏感性与鲁棒性结果.xlsx
```

不得在 MATLAB 中重算核心指标，不得根据论文摘要数字伪造绘图序列。图型由结论任务和底层数据决定；禁止为装饰选择 3D、饼图、彩虹色或信息密度不足的多面板。

## 单文件绘图合同

- 问题一、问题二等分别使用 `Q1_plot.m`、`Q2_plot.m`；文件名中的编号必须与问题编号一致；
- 每个问题只交付一个 MATLAB 绘图文件，目录为 `MATLAB绘图/问题X/QX_plot.m`；
- 文件必须自包含，读取工作簿、字段检查、科研样式、可选导出等辅助逻辑写为文件末尾本地函数；
- 一次运行必须创建该问题全部需要的图窗，包括核心结果、模型诊断、多算法比较、敏感性和鲁棒性图；
- 不适用的图不生成空图窗，应由工作簿 `适用性说明` 记录原因；
- 一个文件可以创建多个独立图窗、层叠组合图、多面板图或混合组合图；“单文件”不等于“单图”；
- 禁止额外交付 `read_result.m`、`style.m`、`export.m` 等辅助 MATLAB 文件。

## 三类科研图增强

### 1. 高对比视觉系统

- 核心结果使用深海军蓝 `#123B5D`；
- 第二证据使用高对比青绿 `#009E91`；
- 第三方法或结构差异使用蓝紫 `#6B4FA3`；
- 风险、失败和不可行状态使用暗红 `#C63D3D`；
- 最优点和临界点使用橙色 `#E07A24`；
- 坐标轴和文字使用墨黑 `#181C22`；
- 灰色与米色只用于非重点数据、置信区间和背景区域；
- 同一变量跨图层、跨面板保持同色，不按面板重新分配颜色。

### 2. 层叠组合图：同一坐标区多图形

层叠组合图用于同时呈现原始样本、统计汇总、模型关系和关键结论。优先组合包括：

- 柱状 + 折线；
- 堆叠柱 + 总量折线；
- 散点 + 模型线 + 区间带；
- 箱线 + 抖动散点；
- 小提琴 + 箱线/中位数 + 散点；
- 直方图 + 密度曲线 + 参考线；
- 中心线 + 双层分位数带 + 关键点；
- 热图 + 等高线 + 推荐点；
- Pareto 散点 + 前沿线 + 推荐点；
- 点估计 + 误差棒 + 原始重复试验点。

同一坐标区按照“背景/区间 → 结构图形 → 原始点 → 模型线 → 关键结论”的顺序绘制。两种图形表达相同信息时删除弱层。

柱线双轴必须通过准入：共享同一横轴、单位确实不同、存在机制关系、轴颜色与图形一致、不得通过缩放制造相关性、每图最多两个纵轴。同单位时必须使用单轴。

### 3. 多面板与混合组合图

多面板用于不同证据问题，通常为主结果 → 机制/分层 → 误差/约束 → 稳定性。优先采用上一下二、左大右二、上一下三等非对称布局。一个面板可以继续使用层叠组合图，此时属于混合组合图。

多面板通常限制为 3--4 个；主面板面积最大；共享颜色、单位、图例和相关坐标尺度；面板只保留 a、b、c、d，不重复总标题。缩放到论文实际尺寸不可读时拆分。

## MATLAB 绘图计算边界

允许的非决策性渲染变换包括：确定性抖动、柱体定位、透明区间、固定带宽 KDE 轮廓、直方分箱、图例和面板布局。

必须由 Python 输出：拟合系数、预测线、置信/预测区间、Pareto 前沿状态、最优点、显著性、敏感性指数、模型排名和任何进入正文结论的统计量。MATLAB 只负责读取和呈现。

## MATLAB 绘图规范

- 默认创建可见图窗并保留，不自动关闭；
- 默认不批量调用 `exportgraphics` 或 `print`；人工调整后由 `QX_plot.m` 内的可选导出开关统一导出；
- 白底，刻度向外，坐标轴和文字使用高对比墨黑；
- 默认关闭网格，必要时仅开启单方向浅网格并置于底层；
- 坐标轴刻度字号约 16--17，坐标轴名称约 18，图例约 15--16，面板字母 20--22；
- 主线宽约 2.4--3.0，次线约 1.7--2.1，辅助线约 1.0--1.3；
- 图内不重复写总标题；中文坐标轴和单位完整，标签不重叠，图例不遮挡；
- 正式图保存到 `figures/`，可编辑源文件保存到 `figures_editable/`；文件名使用英文或拼音。

## 入文闭环

图后另起正文段，按 `templates/writing/caption_explanation.md` 组织趋势/差异、关键数值、机制和结论作用，不套用固定句式。无法绑定小问、公式、工作簿工作表、图层/面板职责或结论的图删除。
