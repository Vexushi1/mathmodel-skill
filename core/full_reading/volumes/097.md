# 空间模型 Pack

## 1. 进入条件

当观测对象具有坐标、区域邻接、距离、网络空间或明显空间相关，且问题关注空间分布、溢出、聚集、异质性或空间预测时加载。先明确空间单元、尺度、投影坐标、时间切片和边界单元。

## 2. 初始化结构化简优先项与 comparator 选择

空间模型之前先识别“空间”到底提供了哪一种数学结构：

- **坐标与尺度**：先统一 CRS、距离单位和空间粒度；距离关系若可解析，优先直接使用几何关系而不是先构造黑箱权重矩阵。
- **对称与规则区域**：规则几何、周期网格、径向/平移对称可降维、卷积化或只计算基本区域。
- **邻接稀疏性**：局部邻接、有限支持 kernel、KNN 等形成稀疏结构时优先稀疏线性代数或图算法。
- **卷积/平稳结构**：规则格点且关系仅依赖相对位移时，检查 convolution / spectral / Toeplitz 结构。
- **边界与孤立单元**：先识别边界条件、孤岛和 disconnected region，能拆分的区域不强行同一模型。
- **网络等价**：若空间问题本质是邻接、路径、流或覆盖，优先转入 graph/network 专用结构。
- **空间相关是否必要**：先用残差或机制判断空间依赖是否真实存在；“有经纬度”不自动推出 SAR/SDM/GWR。
- **尺度与 MAUP**：题目若只要求某固定空间单元，不为方法复杂度主动引入多尺度；若结论对尺度敏感，再使用多尺度 comparator。

主模型应是保留真实空间依赖后的最小充分空间结构。SDM、贝叶斯层次、GWR、GNN 等可以作为 comparator，用来检验溢出、非平稳或复杂邻接是否显著改变目标结论。

## 3. 变量与公式闭环

- 定义空间单元、坐标/邻接、距离阈值、权重标准化和时间维度；
- 说明权重矩阵 $W$ 的构造、稀疏性、方向性和孤立单元处理；
- 区分空间滞后、空间误差和解释变量溢出；
- 空间回归报告直接、间接和总效应，不能只解释原始系数；
- 因果表述需额外识别假设，空间相关本身不构成因果证据。

## 4. 必做验证与输出

- 比较邻接、距离、K 近邻等替代权重矩阵；
- 检查 Moran's I、LISA、残差空间相关和边界效应；
- 使用稳健标准误、时空切分或留区验证；
- 检查尺度变化和 MAUP 风险；
- 工作簿保留空间单元键、坐标、权重摘要、局部统计量、效应分解和替代矩阵结果。

## 5. 否决或降级条件

空间单元与数据无法对齐、投影/距离计算错误、权重矩阵无机制依据、孤立单元未处理、残差仍有强空间相关，或直接把空间相关解释为因果时，模型必须重构。复杂图模型缺少空间基准和外区验证时降级。

# 统计与机器学习 Pack

## 1. 进入条件

当任务涉及参数估计、假设检验、关系解释、分类、聚类、风险识别、特征筛选或因果分析时加载。必须先声明目标属于描述、预测还是因果，三者不能混写。

## 2. 初始化结构化简优先项与 comparator 选择

在选择统计模型或机器学习器之前，先确定**estimand / 识别对象**，再检查数据结构能否把问题降成低维：

- **目标类型先分清**：描述、关联、预测、因果对应不同 estimand；模型复杂度不能弥补目标定义不清。
- **可识别性优先**：先检查设计矩阵秩、处理/结果/混杂、重复测量、分组与时间结构；不可识别参数不能靠更复杂算法“估出来”。
- **充分统计量/低维参数**：若题目或分布结构允许用均值、方差、计数、低维系数等充分统计量回答，不保留全部原始高维状态。
- **函数形式与变换**：对数、比率、链接函数、分层结构或交互项若有机制依据，先让模型表达正确，再比较 ML 容量。
- **共线与冗余特征**：定义相关、近线性依赖、高相关重复变量先处理其数学冗余，不把冗余特征数量当作“高维复杂性”。
- **组别/时间依赖**：cluster、panel、longitudinal、paired data 先保留真实采样结构，不能用 i.i.d. 黑箱模型抹掉设计信息。
- **透明模型充分性**：低维 GLM/混合模型/经典分类器若已满足解释和外样本要求，可作为主模型；ML 只有在非线性或高维交互带来稳定增益时升级。

高级 ML、DML、因果森林等可作为 comparator 或主模型，但必须说明相对最小充分统计结构新增了什么可识别信息或预测能力。

## 3. 变量与公式闭环

- 定义总体、样本、响应变量、特征、分组/时间结构、损失函数和统计量；
- 数据清洗、插补、标准化、编码、采样和特征选择必须在训练折内完成；
- 回归检查函数形式、共线性、异方差、残差和影响点；
- 因果模型明确处理、结果、混杂、识别假设和估计量，不由相关性直接推出因果。

## 4. 必做验证与输出

按需在主结果核对后依 `modules/03_result_analysis.md` 比较不同数学结构，或在同一模型上比较不同求解算法。沿用项目后端、合法数据和共同评价，逐项记录实际专项证据。

- 训练/验证/测试严格分离，分类使用分层或时间/组别感知划分；
- 报告置信区间或 Bootstrap，不只报点估计；
- 分类检查不平衡指标、阈值、校准和混淆矩阵；
- 回归检查残差、稳健标准误和替代设定；
- 工作簿保留样本划分、逐折指标、预测/残差、系数或重要性、校准和稳健性结果。

## 5. 否决或降级条件

存在数据泄漏、检验前提明显不满足、样本量无法支撑参数规模、只报告训练指标、用特征重要性代替因果效应，或因果识别假设不可辩护时，结论必须降级。黑箱模型无法验证且未优于透明基准时不作主模型。
