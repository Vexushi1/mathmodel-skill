只有真实且有证据支持的独立验证才设置相应二级标题：没有 comparator 时用“模型检验”，实际完成不同模型或同模型不同算法的可比对照时用“模型检验与对照”；都没有独立任务时不凑第四节。主计算收敛/离散精度说明可以就地属于“模型求解”，不自动解释成参数鲁棒性或多模型检验。

若存在独立验证内容，主结果段先明确当前主结论，再用短桥接说明仍需检查哪类风险，例如参数扰动、边界依赖、随机性、模型设定或 solver 一致性。

验证段的基本逻辑为：

```text
被检验的风险/主张
→ 改变什么
→ 保持什么不变
→ 使用什么指标
→ 结果变化到什么范围
→ 主结论是否改变以及有效边界
```

以下情形通常值得独立 VALIDATE 功能槽：

- 两类以上参数敏感性/鲁棒性检验；
- Bootstrap、留一法、交叉验证或外样本；
- 多 seed / 多初值一致性；
- 边界、阈值或关键参数扰动；
- 替代算法或替代模型；
- 残差、误差、置信区间或预测区间；
- 局部最优/启发式方案的独立挑战。

简单问题没有真实风险时不强制验证。多方法结果不仅比较数值一致性，还要比较边界、活跃约束、候选结构或解结构等结构结论；数值接近而结构判断冲突时，不得直接宣称稳定。

## 11. Result → Validation Bridge

只有存在真实后续分析任务与有效证据时，才按**主结果 → 分析动机 → 真实证据 → 结论回收**组织正文。这是逻辑连续性，不是固定四段、固定句式或新的登记/门禁。

- **主结果**先回答当前问题，说明决定性数值、图表和成立条件；如有待检验的真实风险，提出具体受影响的指标/结论，不预告虚构试验。
- **分析动机**明确承接哪个主结果、为何需要额外分析、改变什么、固定什么以及比较指标；真实模型/算法 comparator 必须在输入与评价口径上可比。
- **证据解释**只消费 current 的已验收主求解证据、真实 03B 分析工作簿或经现有规则判定无需独立 03B 的直接证据。可选敏感性、边界、收敛精度、误差、模型/算法对照、消融或实际应用情景，不要求每问都做。
- **结论回收**说明检验如何支持、修正、否决或限制主结论。影响核心答案时同步修改摘要、正文结果与相关 Claim；内部的 support / modify / reject 是证据处置概念，不原样打印进论文。

例如实际比较 **300 次与 1200 次迭代**，需要在相同目标、输入与可比求解条件下检查目标值和关键决策变量，并明确一致性容差。若结果在容差内近似一致，只能说明较短预算在该实验条件下已得到近似解；只有真实耗时或成本证据才可量化节约。迭代一致或目标曲线趋缓均**不能证明全局最优**。若 1200 次显著改进或解结构改变，须收窄或修正“300 次足够”的主张。

当 VALIDATE 单列时，桥接句应让读者恢复“主结果已回答什么、风险何在、下一段实际检验什么”，可自然发问，也可直接陈述。没有必要的独立分析时由主结果直接闭合题意；没有证据时保留待办，**不为了语言衔接生成新 03B 或把未执行分析写成已验证结论**。

## 12. 跨问递进

后问只恢复真实继承的模型、状态或判据，再说明新增条件怎样改变当前数学困难。不要从头复制前问完整模型，也不要为了显得连贯虚构不存在的依赖。

问题一、问题二、问题三的一级顺序服从模板；局部数学依赖只决定各问题章节内部的展开顺序。

若数据章或共享基础章启用，其顺序只是大章节**内部**的组织顺序，不构成重排全文一级章节的权限。共同轨迹、共同概率关系或共同网络结构不从头复制；后问只写真实新增部分。“同理”只能用于确实没有结构变化的推导。

solver 的跨问递进也要与结构增量一致：若继续使用前问 solver，只需指出决定其适用性的结构仍然保持，并写新增编码/约束；若换 solver，则明确是哪项新增维度、离散性、耦合、非光滑、不确定性或规模使原方法不足。不要写“为了提高精度，本问换用更先进算法”而没有当前计算结构依据。

## 13. 图结果叙事

### 13.0 CUMCM 图表的正文落点：先论证职责，后图型

按当前 Figure Contract 的 Core conclusion、Figure role、Paper location 与本问 `模型论文框架.md` 的标题规划决定落点，而不是看“折线图/柱状图”或绘图脚本名：机理、几何与决定性约束示意通常归“XX模型的建立”；算法流程、离散精度和内在数值合法性通常归“模型求解”；直接答案、最优方案与决定性趋势归“模型求解结果与分析”；独立参数敏感性、鲁棒性、外样本与有效替代方法比较归“模型检验（与对照）”。

**核心优先级是首次证明该判断的位置。** 同类参数曲线如果用于步长精度选择，应就地放在求解部分；若用于检验现实参数扰动是否改变最终结论，应放在检验部分。图表通常只正式展示一次，其他位置编号回指；主结果不因以后还有检验而推迟解释。图、表、正文各自承担“是什么/怎样读/说明什么”，无解释的连续裸堆图表应重写。

**预登记到写作的交接。** 图表可以先于论文制作；前期在现有“论文位置”／Paper location 中登记“所属小问或共享范围＋预期论证功能”，例如“问题二／结果与分析，具体小节写作时确定”。尚无正文时，“正文引用位置”留空，不预写物理行号、页码，不提前锁死三级标题；归属未定时在原位置或既有待办中说明。Figure role 保持原有证据用途定义，不改成章节槽位。

1. **该问开始先盘点。** 结合当前模板、active 骨架和标题规划，读取本问全部相关登记，包括仅在全局证据链出现、跨问共享、位置空缺或待定的对象，复用同一 Figure ID／已有表标识及来源。不能先按“结果节图”筛选而漏掉未定项。全论文或跨聊天恢复仍按现行要求读取完整框架；随后再按本问与功能节定向读取。
2. **安排后分节消费。** 按真实支撑判断和 current 证据确定主要展示位置及解释任务，再按标识检索必要登记行、表头、合同和证据。当前 resolver 不自动筛选图表行；这是现有项目文本的读取动作。未运行、未导出、未确认或缺相应 accepted 证据的对象只能保留待办或舍弃，不能因排好位置自动变成可入文。机理图沿用自身来源与审阅要求，不补造工作簿。
3. **该问完成核对去向。** 对本范围拟入文对象明确采用、合并、拆分、移位、省略、弃用或仍待完成的实际处置；在现有映射、当前写作选择或待办中记必要理由，不新增记录表或状态枚举。采用后将“论文位置”更新为真实章节／小节标题路径，并回填实际 caption 与正文引用锚点；数字编号只作辅助。合并或拆分保留新旧对象及来源关系，其他章节回指主要展示位置，不重复计作新证据。省略时确认必要答案与证据仍有适当表达，不强迫全部图表入文；只写一问不宣称全文已闭合。

普通表格沿用已有表标识、caption/label 或唯一名称，在现有标题规划／写作选择中承接用途和位置，不插入 Figure 九列表，不强制图片文件、MATLAB 绘图脚本或 B2 Figure 绑定。已启用 B2 的图片被替换或移除时，原绑定、Paper Fragment 和 policy 要求仍按原规则处理；文字处置或改成表格不等于原 Figure 门已通过，不自动关闭 policy。协议不能表达的替代保留为原流程未闭合项。

旧项目不补造历史预登记，也不批量迁移；本次触及的写作范围按现有证据补充即可。归属裁决不增加逐图用户审批；图片本身的既有人工确认要求保持。上述交接适用于当前实际论文骨架，非 CUMCM 不强套本节列举的 CUMCM 字面标题。

本步骤只使用已有 Figure ID、工作簿与图表映射，不另设必填工作单。图表位置或 caption 调整**不等于**已批准模型或 accepted 数值改变、也不要求重新运行 03A/03B；但受影响的 Framework、论文 Figure 引用、LaTeX 正式审计与编译证明仍需按当前依赖关系刷新。图表数据必须 current 且真实已验收，不因新标题需求而制造 03B 或其他不存在的实验。

图表可读性先按职责分工处理：图题/表题负责识别对象与范围，轴/图例/表头/行名/表注负责读数条件，正文负责决定性特征、证据解释和题目含义。三层不能机械重复；图题和表题也不能直接使用只有作者内部才能理解的运行名作为最终显示。

核心图优先解释：

```text
图展示的关系与局部作用
→ 决定性特征
→ 必要关键数值
→ 对当前问题的影响
→ 有证据支持时解释原因
→ 必要时收束到答案/下一步
```

这是功能清单，不是固定六句话。现有模型不足以解释原因时，只陈述可确认现象及其问题含义，不编造因果机制。

从图产生的想法按 §7.3/9 处理：自然的观察、疑问和比较视角可以保留，但图像相近、平稳或出现拐点本身不能证明等价、鲁棒或因果；解释回到相应方程、数据或已执行检验，避免把视觉印象写成数学性质。

不同证据按其真实角色取舍：单点最优或参数组合说明决策含义及决定性约束；曲线说明趋势、极值、拐点、阈值或稳定区间怎样改变当前判断；算法/精度/验证图说明比较指标、差异量以及主结论是否变化；空间、网络或机理图说明位置、连接或边界结构对当前答案的作用。不得把所有图都改写成同一种“先升后降”模板。

图第一次出现时不只写“结果如图所示”，也不逐字重复 caption。图题说明对象、关系、范围和必要统计口径；坐标轴、图例、colorbar、panel label 与必要直接标注负责读数；正文解释决定性特征和问题含义，不把大段结果分析塞进 caption。多面板图先说明共同问题，只解释各 panel 对结论有独立贡献的差异；多张核心图之间若没有正文解释，不得连续裸堆。原因解释只能来自当前模型方程、活跃约束、物理/几何机制、统计结构、资源竞争、边界效应或已证实的数据规律。

表格首先要能独立读懂“比较什么”。表题说明对象、比较内容或关系，必要时补充时间、地区、场景、样本或统计口径；行名使用模型/方案/样本/地区/场景的可读名称，不直接把内部 run id、代码变量或文件名当最终显示名。列名优先写现实含义，可同时保留必要符号，单位放在表头或紧邻表注中。若 `t_c / Cmax / eps` 等符号单独出现会让评委无法恢复含义，就补可读名称或邻近解释。

比较表还要交代必要的 baseline、时间/场景和指标口径。误差、风险、损失、拟合、收益、约束余量等不能默认“越大越好”；方向不显然时在表头、表注或邻近正文说明。无量纲量明确标注无量纲或给定义，不为整齐虚构单位。同名指标若算法、样本或归一化口径不同，必须区分。

一张表通常服务一个主要比较问题；共同支撑该问题的多个指标可以共表，互不相关的任务不应堆进同一宽表。过宽时优先拆比较维度、使用分组表头或删真正冗余列，不通过缩小字号、压缩列名、去掉单位来硬塞。正文只提炼关键差异、排序、约束状态和不确定区间，不逐格复述。
