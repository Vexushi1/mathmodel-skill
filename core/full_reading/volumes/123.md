# 结果深化分析检查

## 1. 前置门槛

- [ ] 主结果已在当前模型口径下完整求出；
- [ ] `问题X求解结果.xlsx` 已通过工作簿 Schema；
- [ ] `主结果质量门` 的精度、收敛、可行性、残差、外样本或可识别性要求全部通过；
- [ ] 后续分析不是为了补救未通过的主结果；
- [ ] 当前模型、数据和参数哈希与主结果一致。

## 2. 分析方法选择

- [ ] 已从题目要求、模型结构、数据特征、主结果表现和评委风险识别关键风险；
- [ ] 每项分析都对应一个明确问题和一个可判定指标；
- [ ] 敏感性、鲁棒性、多算法、结构稳健性、阈值、异质性、误差分解或外样本稳定性按需选择；
- [ ] 未将所有问题统一设置为 ±5%、±10% 参数扰动；
- [ ] 未将随机重复运行直接等同于鲁棒性；
- [ ] 未为了“完整”生成与结论无关的分析。

## 3. 分析设计表

`分析设计` 至少记录：

```text
风险来源 | 分析问题 | 方法 | 指标 | 通过标准
```

并检查：

- [ ] 输入变化、场景、算法、结构或分组口径明确；
- [ ] 通过标准在看到结果前确定；
- [ ] 方法与风险来源匹配；
- [ ] 分析能支持、修正或否决一个核心结论；
- [ ] 论文位置和图表需求已登记。

## 4. 实质分析

至少执行一项：

- [ ] 参数与机制敏感性；
- [ ] 阈值与失效边界；
- [ ] 场景压力测试；
- [ ] 算法一致性、多初值或上下界复核；
- [ ] 模型结构、约束、赋权或分布假设稳健性；
- [ ] 区域、时间、人群或资源等级异质性；
- [ ] 误差分解；
- [ ] 外样本、滚动或迁移稳定性。

每项分析检查：

- [ ] 底层数据完整写入工作簿；
- [ ] 随机种子、样本数、场景和参数范围可复现；
- [ ] 结果包含稳定范围、阈值、差异或失效边界，而非只写“变化不大”；
- [ ] 多算法比较同时报告目标值、可行性、时间、随机性或最优间隙中的适用项；
- [ ] 结构对照只改变待检验设定，不同时更换多项口径导致不可解释。

## 5. 结论稳定性汇总

选用新两类比较时，还须按 `modules/03_result_analysis.md` 核对每个 required 检验 ID 的已审查对象、共同评价、冻结判据、真实非空专项表和处置。敏感性表不能替代缺失的 `多模型检验`／`同模型多算法检验`。同算法换 seed 不计多算法；模型／函数改名不计多模型。有效负结果与运行失败分别处理，附加 claim 的 modify/reject 不能自动推成核心答案否证。

`结论稳定性汇总` 至少记录：

```text
核心结论 | 分析方法 | 稳定范围 | 是否保持
```

并检查：

- [ ] 每个核心结论都有对应证据；
- [ ] 失效边界和适用范围写清；
- [ ] 结论反转或性能严重退化时未强行解释为稳定；
- [ ] 分析方法与正文表述一致；
- [ ] 工作表、图表和正文位置可追溯。

## 6. 回退重算

出现下列情况时设置 `result_analysis_status: redo_required`：

- 合理参数范围内核心结论频繁反转；
- 场景变化下主方案大面积不可行；
- 不同可靠算法给出明显不一致的解；
- 替代模型结构导致结论完全改变；
- 某些关键群体或时期误差不可接受；
- 发现主求解存在局部最优、泄漏、数值误差或实现问题。

处理要求：

- [ ] 标记主结果、结果分析、所选Python/MATLAB图和论文摘要 stale；
- [ ] 回退模型设计或主求解；
- [ ] 重新完整求解并通过质量门；
- [ ] 重新执行所需分析；
- [ ] 删除旧结论，不在正式框架中并列保留版本。

## 7. 工作簿与图表

- [ ] 文件名为 `问题X结果深化分析.xlsx`；
- [ ] 包含 `分析设计`、至少一个实质分析表和 `结论稳定性汇总`；
- [ ] 不包含空工作表或 `适用性说明` 占位表；
- [ ] 所选Python/MATLAB绘图脚本只读取实际工作簿和真实表头；
- [ ] 分析图能展示稳定范围、阈值、算法一致性、结构差异或异质性；
- [ ] 装饰性扰动图已删除。
