# 综合评价题 Pack

## 1. 进入条件

当题目要求构建指标体系、综合评分、排序、分级、优选或比较对象时加载。先确认评价对象、评价目的、决策主体、时间/空间口径和最终排序或分类用途。

## 2. 初始化结构化简优先项与 comparator 选择

综合评价之前先判断**题目是否真的需要构造综合指数**：

- 若题目已经给出明确目标函数、合格阈值、硬性优先级或唯一决定性指标，优先直接回答，不为形式完整强行 AHP/熵权/TOPSIS。
- **指标定义优先**：先剔除同义、重复、线性依赖或由定义可恢复的指标；能由守恒/比率关系消去的信息不重复计权。
- **支配与 Pareto**：若对象 A 在所有关键指标上不劣且至少一项更优，可先删除被严格支配对象，再讨论权衡。
- **单调变换不变性**：明确排序是否只依赖相对次序，避免对不影响结论的归一化或尺度处理赋予虚假“方法创新”。
- **阈值/等级结构**：存在明确标准时优先建立可解释的分级规则，而不是先压成单一分数再反推等级。
- **权重必要性**：只有当多个不可约指标必须折中时才引入权重；客观离散度不自动等于现实重要性。
- **潜变量/效率模型**：只有指标存在共同潜在结构、前沿效率或偏好机制时，才考虑 PCA/因子/DEA/学习排序。

主模型应是能直接回答评价目的的最小充分评价结构；复杂评价模型可作为 comparator，用于检验排序、分级或权重机制是否真正改变结论。

## 3. 变量与公式闭环

- 指标先于赋权，记录指标来源、正负向、单位、层级、缺失和现实解释；
- 检查高相关、重复计量、低方差和目标泄漏；
- 说明归一化、权重、综合得分和排序规则；
- AHP 需一致性检验，熵权只反映离散度，不能直接解释为现实重要性；
- 组合赋权说明主客观权重的融合机制。

## 4. 必做验证与输出

- 替代归一化、替代赋权或权重扰动；
- 指标删减、异常对象和缺失处理敏感性；
- 使用 Spearman/Kendall、Top-k 重合率或名次区间检查排序稳定性；
- 与单指标、专家规则或已知等级对照；
- 工作簿保留原始指标、标准化值、权重、综合得分、名次和扰动下名次。

## 5. 否决或降级条件

指标含义不清、正负向错误、重复指标被多次计权、权重来源无法解释、TOPSIS 理想点不具现实含义，或轻微扰动导致排名完全翻转时，主评价体系必须重构。复杂方法不能提高解释性或稳定性时降级。

# 博弈与决策 Pack

## 1. 进入条件

当存在多个具有不同目标的参与者，且一方策略会改变他方收益、响应或信息时加载。先明确参与者、策略集合、收益、信息结构、行动时序、承诺能力和均衡概念。

## 2. 初始化结构化简优先项与 comparator 选择

首先判断题目是否**真的需要博弈模型**，再判断需要哪一种均衡结构：

- **战略互动必要性**：若各主体目标并不相互依赖，问题应拆成独立优化或集中式决策，不为了“多主体”强行博弈。
- **支配策略**：存在严格/弱支配策略时先消去被支配策略，必要时可直接得到均衡。
- **零和/常和**：若收益可化为零和，优先 minimax / 线性规划结构。
- **potential / identical-interest**：若存在势函数或共同目标，可把均衡搜索化为单一优化问题。
- **行动时序**：只有题面确有先承诺—后响应时才进入 Stackelberg；同时行动不能被人为改成双层。
- **信息结构**：完全/不完全信息、可观测/不可观测、信念更新必须由题面决定；信息结构不能靠方便求解假设。
- **best response 结构**：检查单调性、凸性、唯一响应和阈值性质，能解析得到反应函数时先化简再求均衡。
- **联盟与可转移效用**：合作博弈只有在联盟价值和可执行分配有现实基础时使用。

主模型是保留真实战略依赖后的最小充分决策/博弈结构。MPEC、双层规划、多主体仿真可作为 comparator，检验先后决策、有限理性或复杂交互是否真正改变策略。

## 3. 变量与公式闭环

- 定义参与者 $i$、策略 $s_i$、收益 $u_i$、信念、约束和时序；
- 收益函数必须由题目数据、成本收益机制或可解释参数构成；
- 明确纯/混合策略、完全/不完全信息和一次/重复博弈；
- 双层模型给出上下层变量、目标、约束和响应映射；
- 合作博弈说明联盟价值、分配公理和可执行条件。

## 4. 必做验证与输出

- 检查均衡存在性、唯一性或多均衡选择规则；
- 比较集中决策、非合作基准和不同信息情景；
- 对收益参数、信念、响应弹性和理性程度做敏感性；
- 检查策略可执行性、个体理性和预算/资源约束；
- 工作簿保留策略组合、参与者收益、均衡残差、情景比较和参数扰动。

## 5. 否决或降级条件

参与者目标没有冲突或互动、收益函数无法量化、行动顺序与 Stackelberg 假设不符、响应函数不可识别、均衡残差未检查，或只写博弈名称而无闭环时，模型不通过。MPEC 等方法未通过高级方法准入时降级。

# 图与网络 Pack

## 1. 进入条件

当题目对象可抽象为节点与边，并涉及连通、路径、流、匹配、传播、社区、中心性或网络韧性时加载。必须先说明节点、边、方向、权重、容量、时间和多重边如何从题目对象生成。

## 2. 初始化结构化简优先项与 comparator 选择

先识别**图的特殊拓扑**，再决定算法：

- **连通分量**：可独立处理的分量先拆开，避免对整个网络统一求解。
- **树 / 森林**：无环结构优先树 DP、递归、割边/子树分解，不按一般图问题处理。
- **DAG**：优先拓扑序、动态规划和路径递推；有向无环性可把大量组合搜索降为线性/多项式算法。
- **二部图**：优先匹配、指派、最小顶点覆盖等专用结构。
- **流网络**：守恒、容量、费用若与题意一致，优先最大流/最小费用流，而不是一般 MILP。
- **度量/欧氏结构**：距离满足三角不等式或几何邻近时，优先利用 metric、空间索引和几何剪枝。
- **对称与等价节点**：结构完全等价的节点可聚合；周期/重复子图可只计算基本单元。
- **稀疏和局部性**：邻接范围有限时优先稀疏矩阵、局部更新和专用图算法。
- **边/权的生成机制**：若边只是人为阈值化产生，先验证阈值是否必要；图结构不成立时不要为了使用 GNN 强造图。

主模型应利用真实拓扑得到最小充分网络结构。多层网络、随机图、图嵌入或 GNN 可作为 comparator，专门检验复杂关系是否提供超出经典拓扑算法的额外信息。

## 3. 变量与公式闭环

- 定义节点集合 $V$、边集合 $E$、邻接/权重矩阵、容量、成本、时间和流守恒；
- 说明自环、重复边、方向、负权、缺失边和孤立节点处理；
- 路径、流、匹配或传播模型给出目标与约束；
- 中心性和社区指标说明现实含义及其与决策输出的关系；
- 动态网络明确快照、事件时间或时间展开规则。

## 4. 必做验证与输出

- 检查连通分量、孤立节点、重复边、负权环和容量一致性；
- 与小规模枚举、替代算法或理论上下界比较；
- 分析删边、增边、权重扰动和节点失效下的稳定性；
- 报告时间/空间复杂度和规模可行性；
- 工作簿保留节点表、边表、路径/流明细、网络指标、扰动场景和约束检查。

## 5. 否决或降级条件

图结构无法从题意解释、边权混合不同单位、方向/时间属性被忽略、算法前提不满足，或只给网络可视化而没有决策闭环时，模型不通过。GNN 等方法缺少标签、样本规模或经典基准时降级。
