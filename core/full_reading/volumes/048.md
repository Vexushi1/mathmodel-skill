role: >-
  跨数学建模竞赛的正文推理与证据治理权威。约束核心公式的来源—推导—去向、共享基础模型、
  跨问递进、结构化简、模型/求解器/验证器角色、优化模型表达、模型建立理由与适用边界、
  模型建立—求解—结果解释的连续叙事、问题章节内部小节架构、详略分配、图表结果叙事、算法说明、

  不规定具体题型、固定算法、固定章节名或载体排版细节。

formula_reasoning_chain:
  required_for: core_formula_or_relation
  chain: [source, derivation, destination]
  source_allowed:
    - prompt_condition
    - definition
    - physical_or_geometric_mechanism
    - statistical_or_probability_principle
    - data_generation_mechanism
    - decision_logic_or_resource_constraint
    - state_transition
    - prior_formula_or_proposition
    - verified_standard_theorem
    - inherited_shared_model
  source_rule: 核心公式必须能指出题意、定义、机制、数据或已验证理论依据，禁止“根据相关理论可得”后直接悬空给式。
  derivation_rule: >-
    推导深度按题型自适应。需要说明从前一对象/条件到当前关系的关键理由；
    纯代数展开可压缩，但若删去某一步会使评委无法恢复题目条件/基本规律如何进入变量关系、控制方程、目标函数、约束、边界、
    结构化简、solver 前提或最终模型，则该步骤属于正文必须可恢复的非显然核心推导，不能仅因篇幅、难度或“不是最终公式”而外移。
  core_derivation_body_closure:
    governance_level: default
    applies_when_any:
      - prompt_condition_or_basic_law_to_model_relation_is_nontrivial
      - assumption_or_approximation_changes_model_structure
      - coordinate_variable_reference_frame_or_state_transformation_is_material
      - symmetry_reduction_dimension_reduction_or_decomposition_is_material
      - initial_or_boundary_condition_is_nontrivial
      - objective_constraint_metric_or_decision_rule_is_constructed
      - key_discretization_error_relation_or_solver_precondition_affects_main_result
      - later_question_adds_or_changes_a_material_relation
    required_body_recoverability:
      - current_object_condition_or_basic_law
      - material_assumption_or_applicability_condition
      - nontrivial_derivation_transformation_or_reduction
      - resulting_relation_boundary_constraint_metric_or_precondition
      - downstream_use_in_model_solver_validation_or_answer
    rule: >-
      正文必须能够独立恢复“为什么这样建、怎样从条件推出该关系、这个关系怎样进入后续模型或计算”。
      对机理/几何题，关键守恒、机制、坐标或对称化简应能追到控制关系及初边界；对优化/评价题，目标、约束、指标和决策规则应能追到题意或资源逻辑；
      对统计/预测题，关键变换、估计关系、损失/评价指标及其适用条件应能追到数据机制或统计原则；对数值求解，影响主结果可信度的关键离散思想、误差关系和 solver 前提应在正文可恢复。
    appendix_boundary: >-
      只有机械代数、重复代入、批量同型展开、完整代码/运行日志、重复系数表、非主线补充实验或不承担主论证闭环的扩展推导可压缩或外置。
      外置后若正文无法恢复模型成立、化简合法性、关键边界/可行域、主要算法前提或结论来源，则不得外置。
    theorem_rule: >-
      标准定理可以引用来源而不重写教材式证明，但正文仍需核验本题适用条件，并写清定理结论如何转化为当前模型关系、边界或 solver 前提。
    inheritance_rule: >-
      共享模型已在前文完整推导时，后问可通过明确锚点继承，不重复整套推导；后问新增或改变的条件、关系、约束、边界和 solver 前提必须重新推导或说明，
      不用“同理”掩盖真实增量。
    machine_boundary:

        paper_policy: preserve
        summary_policy: include_by_default_when_summary_is_required_or_inline
      key_bridge_relation:
        definition: >-
          不一定直接进入 solver，但连接机理、定义、证明、变换、判据、边界、降维与最终模型；
          删除后会造成关键来源、充分性、候选域或推导链断裂。
        paper_policy: preserve_near_the_derivation_or_transformation
        summary_policy: include_only_when_needed_to_recover_final_model_or_solver_precondition
      supporting_derivation:
        definition: >-
          对理解推导有帮助但不承担独立模型/判据/证明/solver 接口的关系；若其中某一步虽无独立接口，
          却是恢复本题非显然核心推导、关键变换/化简、初边值/约束来源、solver 前提或核心证明不可缺少的逻辑步骤，
          则仍属于正文必须可恢复的信息。
        paper_policy: compress_only_if_core_derivation_body_closure_remains_recoverable
        summary_policy: exclude_by_default
      routine_algebra:
        definition: 机械展开、重复代换、单位整理或可由相邻式直接恢复的普通代数步骤。
        paper_policy: compress_or_omit
        summary_policy: exclude
        trace_policy: normally_not_registered
    role_assignment_basis:
      - downstream_mathematical_use
      - dependency_break_if_removed
      - solver_validator_or_answer_consumption
      - proof_reduction_or_boundary_dependency
    bridge_preservation_rule: >-
      “不是最终 solver 方程”不等于“可删除中间式”。若某关系承担 Source→Derivation→Destination 的关键桥接，
      或后续命题、缩域、边界、solver precondition 需要回指，它应登记为 key_bridge_relation 并保留可恢复表达。
    anti_bloat_rule: >-
      角色分类不是增加公式数量的配额；routine_algebra 不因新增 taxonomy 进入 Core Formula Trace。
      supporting_derivation 只能在不破坏 core_derivation_body_closure 的前提下压缩；简单解析题不要求额外造桥接式。
    machine_boundary:
      may_check: [declared_role_value, declared_role_anchor_presence, stale_role_status_conflict]
      must_not_claim: [mathematical_role_from_regex, bridge_necessity_from_formula_position, formula_correctness_from_role_label]

  chain_quality_rules:
    - 连续公式应形成逻辑链而非公式集合。
    - “进一步可得、同理可得”只能连接确有直接数学关系的步骤，不能代替对象机制说明。
