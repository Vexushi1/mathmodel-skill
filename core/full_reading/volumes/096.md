# 预测题 Pack

## 1. 进入条件

当题目要求预测未来数值、类别、风险、需求、趋势或事件概率时加载。先锁定预测对象、时间粒度、预测跨度、可用历史窗口、信息可获得时点和数据泄漏边界。

## 2. 初始化结构化简优先项与 comparator 选择

预测模型选择前先识别数据生成结构，目标是把“需要学习的未知部分”压缩到最小：

- **预测对象与 horizon**：先确定一步/多步、短期/长期、点预测/区间预测，不同 horizon 不共用未经论证的模型复杂度。
- **趋势、季节、周期与 regime**：能由题面周期、日历、制度阶段或显式趋势分解的部分先显式建模；机器学习只学习剩余结构。
- **信息可得时点**：外生变量、滞后项和统计量必须在预测时点真实可用；未来信息不能因为相关性强就进入模型。
- **最小充分状态/滞后**：检查是否存在 Markov 状态、低阶递推、充分滞后或状态空间表达，避免把完整历史窗口无差别输入高容量模型。
- **层级与同质结构**：多个地区/产品/主体若共享趋势或季节结构，优先考虑 pooling、hierarchical、grouped forecast，而不是每组独立堆模型。
- **目标变换与约束**：比率、增长率、对数、差分、守恒/容量约束若能显著简化动态关系，应在模型容量升级前考虑。
- **基准充分性**：季节朴素、漂移、线性/状态空间等透明基准若已满足题目精度和机制要求，它就可能是主模型；复杂模型只有在外样本证据显示仍存在可学习结构时升级。

主模型取能满足 horizon、精度和信息约束的最小充分预测模型。树模型、深度时序模型、机理融合等可作为 comparator，用于回答“非线性/长依赖/高维交互是否带来稳定的外样本增益”。

## 3. 变量与公式闭环

- 定义目标变量、时间索引、滞后项、窗口、外生变量、预测区间和评价指标；
- 所有特征只能使用预测时点之前可获得的信息；标准化、插补和特征选择必须在训练折内完成；
- 说明趋势、季节、周期、结构突变和异常值处理；
- 递归多步、直接多步或多输出策略必须与预测跨度一致。

## 4. 必做验证与输出

按需在主结果核对后依 `modules/03_result_analysis.md` 比较不同数学结构，或在同一模型上比较不同求解算法。沿用项目后端、合法数据和共同评价，逐项记录实际专项证据。

- 使用时间顺序划分、滚动验证或扩展窗口，不随机打乱时间；
- 报告至少一个尺度相关指标和一个尺度无关指标，并给出预测区间覆盖率；
- 检查残差均值、相关性、异方差、极端时段和结构突变；
- 与朴素基准、替代模型和不同窗口比较；
- 工作簿保留真实值、预测值、上下界、逐折指标、残差和特征/参数敏感性。

## 5. 否决或降级条件

存在未来信息泄漏、用训练集误差代替外样本误差、只报单一平均指标、预测跨度与验证设计不一致，或小样本盲用深度学习时，模型不通过。无法稳定优于朴素基准的复杂模型降级为补充。

# 调度 Pack

## 1. 进入条件

当题目包含作业、资源、工序、车辆、人员、设备、时间窗、优先级、释放时间、截止期、切换时间或冲突约束时加载。先明确调度对象、资源容量、时间单位、可抢占性和滚动决策方式。

## 2. 初始化结构化简优先项与 comparator 选择

在建立时间索引 MILP/CP-SAT 或元启发式前，先检查调度结构能否得到排序、递推或分解：

- **机器结构**：单机、相同并行机、均匀机、无关机、流水/作业车间的可化简性不同，先精确识别。
- **precedence DAG**：先做拓扑约束传播、最早/最晚时刻和关键路径，能固定的顺序不再作为决策变量。
- **交换论证**：对相邻任务比较交换前后目标差，能推出 SPT/EDD/Smith 等排序指标时优先排序而非组合搜索。
- **支配规则**：被另一任务/方案在处理时间、截止期、权重、资源占用上严格支配的候选先删除。
- **事件点而非全时域**：若状态只在释放、完成、切换、维护等事件时改变，优先事件驱动或连续时间模型，避免过细时间离散。
- **分资源/分阶段**：耦合弱的资源组、工序段或日期可先分解，再处理少数共享约束。
- **可抢占/不可抢占与 setup**：题面条件若能让切换时间为常数、序列无关或可吸收，应先消掉不必要变量。
- **下界与可行域**：关键路径、机器负载、总处理量等下界先算，既可缩域也可给后续 solver 最优性基准。

主模型是保留全部必要资源冲突与时序约束后的最小充分调度模型。ALNS/GA/滚动优化等可作为 comparator 或大规模 solver，但必须说明精确结构为什么仍不足。

## 3. 变量与公式闭环

- 定义开始/完成时间、排序变量、资源指派、占用状态、延误、切换和成本变量；
- 明确工序先后、资源互斥、容量、时间窗、运输/切换、维护和人员规则；
- 说明时间连续或离散建模、Big-M 取值和对称性消除；
- 多目标调度说明总工期、延误、成本、负载均衡之间的权衡。

## 4. 必做验证与输出

- 输出全部约束违反量和资源冲突检查；
- 报告总工期、延误、成本、利用率、空闲和切换次数；
- 与简单派工规则、下界、小规模精确解或替代算法比较；
- 检查到达时间、加工时间、资源故障和需求扰动下的稳定性；
- 工作簿保留逐作业时刻、逐资源占用、甘特图底层数据、多算法对比和可行性检查。

## 5. 否决或降级条件

遗漏工序先后或资源冲突、Big-M 无依据、时间离散导致显著误差、启发式没有可行性修复或基准比较，或只给甘特图不检查约束时，结果不通过。无法报告下界或间隙时不得写全局最优。

# 仿真题 Pack

## 1. 进入条件

当系统由随机事件、个体交互、排队、库存、传播、可靠性、复杂动态或难以解析的机制驱动，需要通过重复运行获得分布和风险时加载。先定义系统边界、状态、事件/转移、时间推进和停止条件。

## 2. 初始化结构化简优先项与 comparator 选择

先回答“**这个系统真的必须靠仿真才能回答吗？**”：

- **解析/递推结构优先**：排队、可靠性、库存、Markov、renewal、birth-death 等若已有低维状态和可解递推，先用解析或半解析关系。
- **最小充分状态**：未来若只依赖当前库存、队长、设备状态等压缩状态，不保存无关完整历史。
- **事件驱动优先**：系统只在到达、离开、故障、补货、切换时变化时，优先离散事件，不用过细固定步长。
- **聚合与同质性**：大量同质个体若只通过总量/比例交互，检查 mean-field、aggregate state 或计数过程是否足够。
- **守恒与流平衡**：先用资源、人数、库存、概率等守恒减少状态空间，并作为仿真更新恒等关系。
- **稳态/时间尺度**：若问题只关心长期指标，先判断稳态分布或更新周期是否可直接求；只有暂态/非平稳结构需要完整轨迹。
- **随机性必要性**：题目中的不确定量若只通过线性期望进入目标，先检查 deterministic equivalent；随机存在不等于必须 Monte Carlo。
- **外层优化与内层仿真分离**：能解析掉的内层统计量先解析，减少仿真噪声和重复次数。

主模型在解析结构不足时才采用最小充分仿真模型。ABM、RL、仿真—优化等可作为 comparator 或必要增强，但必须说明异质交互/随机反馈为何无法被低维状态保留。

## 3. 变量与公式闭环

- 定义状态变量、事件类型、转移概率、随机变量分布、资源容量和停止条件；
- 参数分布必须有数据、文献或题目机制来源；
- 连续时间、固定步长和事件驱动方案说明更新顺序；
- 仿真—优化区分外层决策变量与内层随机输出，避免把噪声当成目标改进。

## 4. 必做验证与输出

- 固定并记录随机种子、重复次数和置信区间；
- 检查暖启动、稳态、时间步、运行长度和重复次数收敛；
- 采用共同随机数、对偶变量或分层抽样等方差控制时说明方法；
- 与解析结果、历史数据、边界场景和独立实现对比；
- 工作簿保留逐次试验、轨迹/事件明细、分位数、置信区间和收敛诊断。

## 5. 否决或降级条件

随机分布无依据、事件逻辑与现实矛盾、重复次数不足、未处理暖启动/稳态、结果随步长剧烈变化，或只展示单次轨迹时，仿真结果不通过。强化学习或代理模型缺乏稳定性和基准比较时降级为探索性分析。
