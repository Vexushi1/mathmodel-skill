## 完整小节对照观察

### A：直接计算——不增加篇幅

两份水绝热混合，冷水 2 kg/20°C、热水 80°C、目标 40°C。两版均从等比热、无散热前提写热量守恒，解得 1 kg，并代回检验；候选正文与基线完全相同。没有强插“我们希望知道”或新增迭代算法、小节。这是无须改写的通过案例，不是性能提升。

### B：整数供给——把约束与结果的理由写出来

基线已定义整数批数、逐期约束、成本，枚举全部 9 个候选并用 `ceil(4/3)=2` 独立核对。候选新增的是明确的解释而非新模型：

> 供给以每批 3 单位交付，因此我们以批数 x_1、x_2 为决策，分别取整数 0、1、2；若允许任意连续供给量，就会纳入不符合整批规则的方案。

> 由于不能跨期储存或调剂，各期缺口必须由当期供给弥补，故应分别要求 3x_1≥4、3x_2≥4。仅约束总供给会丢失这一局部要求。又因允许超额供给，需求应写成下界而非等式。

候选同时解释每期余量 2 来自整批限制，最优性来自唯一可行解，而非很多可行方案之间的成本优势。两版模型、完整枚举、停止条件、(2,2)、供给(6,6)、成本10和检验边界一致。新增文字有可恢复的误解排除功能；代价是局部变长，只在该选择确有说明价值时使用。

### C：预测——均值与局部误差各说明什么

两版均保持训练拟合 `y_hat=2t+1`，留出预测(7,9,11)、观测(7,12,11)、残差(0,3,0)、MAE=1、最大误差3。基线已说明训练准确不意味着留出准确；候选进一步说明：

> 因此，我们认为评价这组预测时应同时保留平均误差和局部最大误差；平均误差为 1 不能理解成每一点都只偏离 1。

这里“我们认为”是有数据支持的评价取舍；不用生硬改成无主语，也不能据此推断原因。候选没有变更模型或新增鲁棒性结果。它补强的是平均指标与集中误差的关系，不是证明预测模型普遍有效。

### D：命题与算法——证明后具体能做什么

两版证明本体及伪代码完全相同：在 [0,2] 上用连续性、端点值和正导数证明唯一解，按指定二分算法计算。候选新增说明：`f(m)<3` 时严格递增排除所有 `x≤m`，反之保留左半区间；区间半宽控制位置误差，不能直接以函数残差替代。首次中点1精确命中、残差0、epsilon=1e-6、30次上限及未达精度失败状态均保留。

本例也可解析求解，但输入已指定展示二分，试写未擅自更换算法，也未虚构直接法的困难。命题前后更清楚，证明/伪代码内部没有变成聊天。该 Markdown 试写不是 LaTeX 排版质量证明。

## 清理保全与边界试验

四个完整候选小节在语义复核后不需要删除实质内容，清理稿因此与各自原稿相同；“不改”也是合法结果，不人为制造差稿来显示清理收益。

额外构造 B 的过度口语局部压力输入，明确它不是自然生成效果样本：

> 总量够了是不是就行了呢？我们觉得还是得看看每一期，毕竟跨期不能搬来搬去。说白了就是不能只看总量。我们需要分别要求 3x_1≥4、3x_2≥4；允许超额供给，所以这里不能写等式。

实际清理后：

> 总量充足是否足以满足两期需求？由于不能跨期储存或调剂，我们需要分别要求 3x_1≥4、3x_2≥4；允许超额供给，因此需求约束为下界而非等式。

删除重复与闲聊词，保留问题、作者声音、约束必要性、两个不等式和下界理由。以下边界也逐项作语义复核，并由既有 v8.3.1 测试检查可机检的部分；人工判断不冒充脚本结论：

| 场景 | 本次核验结论 |
|---|---|
| 同一枚举解释分别以“我们需要/需要/当前任务需要”表达 | 既有审计行为应相同，不以主语定优劣 |
| “我们采用遗传算法，该算法收敛速度快” | 仍缺具体结构依据，不能因有第一人称放行 |
| 没有新公式的约束必要性说明 | 保留无法由相邻内容替代的理由，不按新公式数量删除 |
| 用“我们认为全局最优”描述启发式结果 | 不放宽原有主张冲突检查 |
| “我们一致认为”但没有共识事实 | 改为当前有依据的选择，不补造团队讨论 |
| “我们希望知道误差在哪里”且已给出留出误差 | 回答 t=4 的误差3，不只写以后研究 |
| 由图提出成因想法但没有原因变量 | 保留观察和待检验方向，不写成因果结论 |
| 已有紧凑正确计算或证明/伪代码 | 不为自然口吻增加章节、代词、算法或删除证明步骤 |
