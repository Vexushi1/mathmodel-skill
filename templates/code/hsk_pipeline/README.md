# HSK Python 求解模板 v6.2.3

复制到具体项目的 `Python求解/`，并将脚本改为中文名，如 `问题一求解.py`。模板导入时不创建目录、不设置随机种子、不执行求解；所有运行副作用只发生在 `main()`。

## 运行前必须填写

在 `build_config()` 中逐问填写：

- `problem_name`；
- 一个主标签和最多两个必要次标签；
- 六个验证 capability 标志；
- 随机种子。

题型留空会直接报错，禁止通过空标签绕过专项工作表校验。显式约束或可行性能力为 true 时，必须实现约束违反检查。

## 固定输出

```text
结果数据表/
└─ 问题一/
   └─ 问题一结果数据/
      ├─ 问题一求解结果.xlsx
      └─ 问题一敏感性与鲁棒性结果.xlsx
```

求解工作簿承载核心指标、题型专项结果和 capability 对应的约束/残差/精度检查；敏感性与鲁棒性工作簿保留逐参数、逐扰动或逐重复数据。两类工作簿由 `result_io.py` 校验后写入。

Python 不生成正式论文图。运行顺序为：Python 求解 → 两类工作簿 → MATLAB 读取工作簿绘图。
