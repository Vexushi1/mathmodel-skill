- 全文命题上限：4
- 当前计划命题数：0
- 当前命题状态：`not_assessed / planned / current / stale`
- 使用原则：命题可以为 0；优先用于问题简化、模型必要性说明、关键点识别、维度或候选范围缩减、约束删减、算法可行性和理论边界，不按小问机械分配。
- 正文证明默认：B 级关键证明链；连续推理通常用 3--8 行自然分段 + 必要公式，只有存在明显独立阶段时才使用 2--6 个编号步骤；超过半页的完整技术证明移附录。
