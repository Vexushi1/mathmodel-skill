# 附录代码说明模板

| 项目 | 内容 |
|---|---|
| 程序名称 | 项目根目录中的 `问题X求解.py`、`问题X结果深化分析.py`；`结果数据表/问题X/q{x}_plot.m` |
| 输入 | 项目根目录中的题目附件、已锁定参数，以及结果深化分析阶段所需的已通过质量门主结果 |
| 功能 | Python 完成主求解与题目专属结果深化分析；MATLAB 读取同目录真实工作簿绘图 |
| 主要输出 | `结果数据表/问题X/问题X求解结果.xlsx`、`结果数据表/问题X/问题X结果深化分析.xlsx`、`图表/qx_*.pdf` |
| 复现顺序 | 项目根目录 Python 主求解 → Python 结果深化分析 → 对应问题目录 MATLAB 绘图 → LaTeX 编译 |

旧 `问题X敏感性与鲁棒性.py` 和 `问题X敏感性与鲁棒性结果.xlsx` 仅用于明确的历史项目兼容，不得作为新项目附录和提交包的默认名称。
