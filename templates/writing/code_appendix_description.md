# 附录代码说明模板

| 项目 | 内容 |
|---|---|
| 程序名称 | `问题X求解/问题X求解.py`；`问题X求解/问题X结果深化分析.py`；`问题X求解/qX_plot.m` |
| 输入 | 主求解读取项目根目录赛题附件和已锁定参数；深化分析读取已验收主结果工作簿及必要原始数据 |
| 功能 | 主求解 Python 完成模型求解与主结果质量检查；主工作簿 accepted 后冻结该脚本；独立深化 Python 完成题目专属敏感性、鲁棒性、多算法、阈值或结构分析；MATLAB 读取同目录两个工作簿绘图 |
| 主要输出 | `问题X求解/问题X求解结果.xlsx`、`问题X求解/问题X结果深化分析.xlsx` |
| 复现顺序 | 运行 `问题X求解.py` → 验收主工作簿并冻结主脚本 → 运行 `问题X结果深化分析.py` → 验收深化工作簿 → 运行 `qX_plot.m` → LaTeX 编译 |

完整运行配置分别写在对应阶段 Python 和对应工作簿的 `运行配置` 表中。求解目录默认不包含独立配置、说明、校验报告、图表目录或自动导出的图片。
