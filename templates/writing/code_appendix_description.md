# 附录代码说明模板

| 项目 | 内容 |
|---|---|
| 程序名称 | `问题X求解/问题X求解.py`；`问题X求解/qX_plot.m` |
| 输入 | 项目根目录赛题附件、已锁定参数；深化阶段读取已验收的主结果工作簿 |
| 功能 | 同一 Python 脚本先完成主求解，验收后覆盖更新并完成题目专属结果深化分析；MATLAB 读取同目录两个工作簿绘图 |
| 主要输出 | `问题X求解/问题X求解结果.xlsx`、`问题X求解/问题X结果深化分析.xlsx` |
| 复现顺序 | 运行主求解版本 → 验收主工作簿 → 覆盖更新同一脚本并运行分析阶段 → 验收深化工作簿 → 运行 `qX_plot.m` → LaTeX 编译 |

完整运行配置写在 Python 和两个工作簿的 `运行配置` 表中。求解目录默认不包含独立配置、说明、校验报告、图表目录或自动导出的图片。
