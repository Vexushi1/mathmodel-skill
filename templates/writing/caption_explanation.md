# HSK MATLAB 图标题、论文图注与正文解释规范

MATLAB 图标题、DOCX/LaTeX 图注和正文解释承担不同职责：图内 `title`/`sgtitle` 便于本地筛图、答辩和快速识别；论文图注说明图号、统计口径、样本/时间范围或误差定义；正文解释完成证据链。三者不得逐字重复，也不要全篇重复“由图X可知”“这一结果说明”“为后文提供依据”等固定套话。

## 1. 图片排布

```text
[保留简洁 MATLAB title 或 sgtitle 的图片]

图X 图名（必要时补充统计口径，但不逐字复制图内标题）

[另起正文段解释]
```

图内标题只写“研究对象 + 指标或关系 + 必要方法信息”，不写完整结论、推荐方案或整段说明。多面板使用一个整体 `sgtitle`；只有面板对象确有差异时再加短子标题。

图片解释段按需要选择以下要素，不要求机械凑齐句式：

1. **读图结论**：指出最主要的趋势、差异、转折、区间或异常；
2. **关键数值**：引用支撑结论的峰值、均值、误差、分位数、临界点或改变量；
3. **机制解释**：说明该现象由哪个变量、约束、公式或场景驱动；
4. **模型作用**：说明它验证、否定或修正了什么模型判断；
5. **决策含义**：仅在题目需要时说明对方案选择或风险控制的影响。

图标题、论文图注、源工作簿、工作表、固定列、MATLAB 脚本和支撑结论应同步登记在 `模型论文框架.md`。

## 2. 表格排布

```text
表X 表名

[Word 原生三线表]

[必要时另起正文段解释]
```

表后解释优先比较关键行列、量级、排序、约束状态和不确定区间。正文不要逐格复述表格，也不要只重复表题。

## 3. 表达变化

根据证据性质自然组织语句：

- 趋势证据：变化方向 + 关键拐点 + 形成原因；
- 对比证据：对象差异 + 数值幅度 + 评价口径；
- 稳健性证据：扰动范围 + 结论保持情况 + 失效边界；
- 诊断证据：异常模式 + 对模型假设的影响 + 修正措施；
- 约束证据：最大违反量 + 容差 + 可行性结论。

这些是信息结构，不是可复制的固定句式。

## 4. 负面清单

| 错误写法 | 问题 | 修正方式 |
|---|---|---|
| 删除 MATLAB 图内标题，只依赖图注识别 | 本地筛图和答辩复用困难 | 保留简洁 `title`/`sgtitle`，图注补充统计口径 |
| MATLAB 标题与论文图注逐字相同 | 信息重复，版面冗余 | 标题负责快速识别，图注负责样本、范围、统计和误差口径 |
| 图题后接大段解释 | 题注过长且污染正文格式 | 图注只保留必要识别与统计信息，解释另起正文段 |
| 每段都以“由图X可知”开头 | AI 模板感强，表达机械 | 直接陈述趋势、数值或对比关系 |
| 删除所有图后解释 | 图表变成装饰，证据链断裂 | 至少说明图支撑的核心结论 |
| 只写“结果显著”“模型有效” | 缺少数值和检验依据 | 引用具体指标、区间、检验或约束状态 |
| 逐点复述全部数据 | 正文冗长，未提炼信息 | 只选择支撑结论的关键数值 |
| 表格截图入文 | 不可编辑、不能统一格式 | 使用 Word 原生表格或 LaTeX 三线表 |
