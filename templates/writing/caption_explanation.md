# HSK MATLAB 图标题、论文图注与正文解释规范

MATLAB 图标题、DOCX/LaTeX 图题和正文解释承担不同职责：图内 `title`/`sgtitle` 便于本地筛图、答辩和快速识别；论文图题承担正式编号和必要统计口径；正文解释完成证据链。三者不得逐字重复，也不要全篇重复“由图X可知”“这一结果说明”“为后文提供依据”等固定套话。

## 1. 图片排布：严格图下

```text
[居中的图片，保留简洁 MATLAB title 或 sgtitle]

图X 图名（必要时补充统计口径）

[邻近正文中显式引用图X并解释]
```

- 图片整体居中；
- **图题必须位于图片正下方**，不能漂到图上方；
- 图题应与图片保持在同一页或同一浮动对象中，避免图题与图片分离；
- 图内标题只写研究对象、指标/关系和必要方法信息，不写完整结论和长段说明；
- 正式论文图题不能由 MATLAB 图内标题替代；图内标题与图题不逐字重复；
- **正文中的每张核心图至少有一次邻近的显式编号引用。** LaTeX 使用 `图~\ref{...}` 或等价交叉引用；DOCX 正文直接写“图 X”。只有 caption、正文完全不提图号视为证据链未闭合。

核心图的正文解释优先形成三层关系：

```text
图号引用
→ 读图结论/关键数值
→ 模型机制或题目含义
```

可以按证据性质自然选择以下要素：

1. **读图结论**：主要趋势、差异、转折、区间或异常；
2. **关键数值**：支撑判断的峰值、均值、误差、分位数、临界点或改变量；
3. **机制解释**：该现象由哪个变量、约束、公式或场景驱动；
4. **模型作用**：它验证、否定或修正了什么模型判断；
5. **决策含义**：仅在题目需要时说明对方案选择或风险控制的影响。

引用句式应自然变化。例如：

- “图 X 给出了……，其中……”；
- “从图 X 的空间分布来看，……”；
- “结合图 X(a) 与图 X(b)，可以看到……”；
- “在图 X 所示范围内，……”；
- 先写关键结果，再补“该差异在图 X 中表现为……”。

这些只是表达方式示例，不是可复制句库。连续图不得采用完全相同的段首和论证节奏，也不要求每张图都从“由图可知”开始。

## 2. 表格排布：严格表上

```text
表X 表名

[居中的原生三线表]

[邻近正文中显式引用表X并解释]
```

- **表题必须位于表格正上方**；
- 表格整体居中；
- 三线表只保留表顶线、表头下线和表底线；
- 数值和短文本单元格默认水平、垂直居中；
- 较长的文字说明列可以左对齐，但不得影响其他列的居中规范；
- **正文中的每张核心表至少有一次邻近编号引用。** LaTeX 使用 `表~\ref{...}` 或等价交叉引用；DOCX 正文直接写“表 X”；
- 表后解释优先比较关键行列、量级、排序、约束状态和不确定区间，不逐格复述。

自然写法可以是“见表 X”“表 X 汇总了……”“从表 X 的误差统计看……”“表 X 中三种方案的差别主要集中在……”。不要求所有表格都采用同一种句式。

## 3. 核心图表、补充图表与附录图表

不同证据层级使用不同正文解释强度：

- **正文核心图表**：必须有显式编号引用，并解释至少一个核心趋势/数值及其模型含义；
- **正文补充图表**：必须有编号引用，可用较短解释说明它补充哪一项判断；
- **附录数值合法性/复现图表**：按正文需要引用，不要求每张都写独立长段，但不得在正文引用不存在的附录图表。

不要为了满足“图后解释”而给每张图机械凑三句话。证据已经由相邻段完整说明时，不再重复。

## 4. 正文解释的语言风格

正文解释属于证据链，不是图表旁的套话。终稿执行 `modules/05_writing/latex.md` 的科研初学者式学术表达：语言认真、克制、略显朴素，但保持规范学术语。

推荐按证据自然组织：

- 趋势证据：变化方向 + 关键拐点 + 形成原因；
- 对比证据：对象差异 + 数值幅度 + 评价口径；
- 稳健性证据：扰动范围 + 结论保持情况 + 失效边界；
- 诊断证据：异常模式 + 对模型假设的影响 + 修正措施；
- 约束证据：最大违反量 + 容差 + 可行性结论。

优先正向说明图表实际展示的规律。真实存在反常、失效或限制时再使用“但、然而、不过”等转折，不让每个图表解释都以限制句收尾。

## 5. 证据登记

图标题、论文图题、源工作簿、工作表、固定列、MATLAB 脚本和支撑结论应同步登记在 `模型论文框架.md`。表格的源工作簿/工作表和正文结论也应可反向定位。

## 6. 负面清单

| 错误写法 | 问题 | 修正方式 |
|---|---|---|
| 图题放在图片上方 | 不符合“表上图下” | 图题移到图片正下方 |
| 表题放在表格下方 | 不符合“表上图下” | 表题移到表格正上方 |
| MATLAB 标题替代正式图题 | 缺少论文编号与正式语义 | 保留图内简洁标题，同时使用正式 `\caption` |
| MATLAB 标题与论文图题逐字相同 | 信息重复 | 标题负责快速识别，图题负责正式编号与统计口径 |
| 核心图/表只有 caption，正文从未引用编号 | 证据链断裂 | 在邻近正文显式引用“图 X/表 X”并解释 |
| 三线表内容默认左对齐 | 数值比较困难、版面不统一 | 数值和短文本默认水平/垂直居中 |
| 每段都以“由图X可知”开头 | 模板感强 | 从趋势、异常、数值、对比或图号本身自然起句 |
| 每个表都机械写“见表X可知” | 模板感强 | 根据表格作用变化引用方式 |
| 图题后接大段解释 | 题注过长 | 图题简洁，解释另起正文段 |
| 删除所有图后/邻近解释 | 图表变成装饰 | 至少说明核心图表支撑的判断和机制 |
| 逐点复述全部数据 | 正文冗长 | 只选择支撑结论的关键数值 |
| 表格截图入文 | 不可编辑、不能统一格式 | 使用 Word 原生表格或 LaTeX 三线表 |
