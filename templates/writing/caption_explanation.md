# HSK 图表题注与正文解释模板

## 1. 图片模板

```text
[图片]

图X 图名

由图X可知，……。这一结果说明……，并为后文……提供依据。
```

## 2. 表格模板

```text
表X 表名

[Word 原生三线表]

由表X可知，……。该结果与……一致，为……提供了数值依据。
```

## 3. 题注错误写法负面清单

| 错误写法 | 问题 | 修正方式 |
|---|---|---|
| 图题后接大段解释 | 题注过长且污染正文格式 | 图题只保留图号和图名，解释另起正文段 |
| 删除所有图后解释 | 图表变成装饰，证据链断裂 | 保留“由图X可知……”解释段 |
| 图后解释拆成多段 | 版面破碎、逻辑不连贯 | 整合成一个自然段 |
| 表格截图入文 | 不可编辑、不能统一格式 | 使用 Word 原生表格 |
