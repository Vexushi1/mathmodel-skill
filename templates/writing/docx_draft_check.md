# HSK DOCX 草稿检查模板

| 检查项 | 是/否 | 备注 |
|---|---|---|
| 章节结构是否完整 |  |  |
| 每问是否有问题分析和模型路线 |  |  |
| 变量、假设、公式是否可追踪 |  |  |
| 核心结果是否填入正文 |  |  |
| 机理图是否已有合同或占位 |  |  |
| 结果图是否有数据来源和代码来源 |  |  |
| 待补图表是否明确 |  |  |
| DOCX 中哪些内容需迁移到 LaTeX |  |  |
| 最终需精修的 S 级机理图是否锁定 |  |  |



| 是否基于用户最后上传的 DOCX 底稿继续修改 |  |  |
| 正文字体、字号、缩进和行距是否统一 |  |  |
| 一级标题是否居中黑色 |  |  |
| 表格是否为 Word 原生表格而非图片 |  |  |
| 三线表是否只保留表顶线、表头下线和表底线 |  |  |
| 图题是否只写图号与图名 |  |  |
| 图后是否有一个正文格式解释段 |  |  |
| 图题/表题样式是否未污染后续正文 |  |  |
| 公式是否居中并编号 |  |  |
| 摘要是否分段且含核心数值 |  |  |
| 参考文献、附录是否分页；如有致谢是否单独分页 |  |  |
| 附录代码是否有说明表，正文是否有伪代码 |  |  |
