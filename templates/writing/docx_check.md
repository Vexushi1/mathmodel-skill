# HSK DOCX 草稿统一检查表

DOCX 用于内容锁定、人工批注和 LaTeX 迁移检查。检查结果只用于内部修改，不机械进入终稿正文。

## 1. 内容、当前框架与模型闭环

| 检查项 | 是/否 | 备注 |
|---|---|---|
| 项目根目录 `模型论文框架.md` 是否存在且为 current |  |  |
| 框架是否只保留当前有效模型、参数、约束、命题、证明、结果和图表映射 |  |  |
| 章节结构是否完整并逐问回应题目 |  |  |
| 每问是否包含问题分析、两条路线和选择理由 |  |  |
| 变量、假设、公式、Python 实现和结果是否可追踪 |  |  |
| 已求解小问是否在框架中有包含核心数值的 current 结果摘要 |  |  |
| 核心结果、单位、区间和约束状态是否已填入正文 |  |  |
| 敏感性、鲁棒性和多算法验证是否有真实结果 |  |  |
| S/A 级机理图是否已有合同、初稿或明确占位 |  |  |
| 每张结果图是否绑定工作簿、工作表、固定列、MATLAB 脚本和框架映射 |  |  |
| 所有待补内容是否标明负责人、来源或前置条件 |  |  |

## 2. 命题与证明

| 检查项 | 是/否 | 备注 |
|---|---|---|
| 全文命题是否按实际需要设置，允许为 0 且不超过 4 个 |  |  |
| 当前命题数、P1--P4 编号、框架表和项目状态是否一致 |  |  |
| 命题是否承担问题简化、模型必要性、关键点识别、降维、候选范围缩减、约束删减、算法可行性或理论边界中的至少一项 |  |  |
| 是否已删除变量定义、直接代数变形、题意复述和同义重复命题 |  |  |
| 每个命题是否完整写出假设、定义域、参数范围和结论 |  |  |
| 每个命题是否标明完整证明、关键证明链或引用定理三种等级之一 |  |  |
| 引用定理时是否写明定理名称/文献并核验本题适用条件 |  |  |
| 证明是否不存在循环论证、隐藏前提、偷换变量或量词扩大 |  |  |
| 是否未把有限实验、交叉验证或求解器退出状态当作严格证明 |  |  |
| 正文证明是否默认压缩为 2--6 个关键逻辑步骤、通常 3--8 行 |  |  |
| 超过半页的完整技术证明是否已移入附录 |  |  |
| 证明后是否说明该命题如何简化问题、说明模型必要性、定位关键点、缩减范围或保证算法可行 |  |  |
| 是否写明命题失效边界，且实际参数位于适用范围内 |  |  |
| 模型、参数或约束变化后，相关证明是否已重新检查 |  |  |

## 3. 排版与原生对象

| 检查项 | 是/否 | 备注 |
|---|---|---|
| 是否基于用户最后上传的 DOCX 底稿继续修改 |  |  |
| 中文宋体、英文 Times New Roman、小四是否统一 |  |  |
| 正文是否两端对齐、段前后 0、首行缩进 2 字符、1.5 倍行距 |  |  |
| 一级标题是否居中、黑色，未使用默认蓝色样式 |  |  |
| 表格是否为 Word 原生表格而非截图 |  |  |
| 三线表是否只保留表顶线、表头下线和表底线 |  |  |
| 表题是否在表上，图题是否在图下且只含图号与图名 |  |  |
| 核心公式是否居中、连续编号且符号与正文一致 |  |  |
| 命题是否按章节编号，证明是否以黑体“证明：”开头并以空心方块结束 |  |  |
| 命题正文与短证明是否位于同一个外框，且框内没有嵌套第二层边框 |  |  |
| 命题框是否采用白底细边、无阴影和无大面积底色，可使用黑色、深灰或克制深蓝边线 |  |  |
| 是否未将流程图、机理图的彩色框限制误用于命题证明外框 |  |  |
| 命题框是否原则上未跨页 |  |  |
| 命题与证明是否使用正文样式，未进入目录 |  |  |
| 题注、表格、命题和公式样式是否未污染后续正文 |  |  |
