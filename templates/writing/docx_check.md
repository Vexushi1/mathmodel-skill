# HSK DOCX 草稿统一检查表

DOCX 用于内容锁定、人工批注和 LaTeX 迁移检查。检查结果只用于内部修改，不机械进入终稿正文。

## 1. 内容、当前框架与模型闭环

| 检查项 | 是/否 | 备注 |
|---|---|---|
| 项目根目录 `模型论文框架.md` 是否存在且为 current |  |  |
| 框架是否只保留当前有效模型、参数、约束、命题、证明、结果和图表映射 |  |  |
| 章节结构是否完整并逐问回应题目 |  |  |
| 问题背景是否原则上只有一个自然段，且每句话都推进研究对象/现实矛盾/建模必要性 |  |  |
| “问题分析”是否按问题一、问题二……逐问分小节 |  |  |
| 每问问题分析是否只写难点、对象关系、跨问依赖和建模抓手，未出现数学公式与最终结果 |  |  |
| “模型假设”和“符号说明”是否为两个独立一级章节 |  |  |
| 可见模型假设是否采用 1.、2.、3. 自然编号而非 H1/A1 |  |  |
| 各问主章节是否采用“问题X模型建立及求解” |  |  |
| 每问详细推导后、求解前是否有“核心模型汇总” |  |  |

| 变量、假设、公式、Python 实现和结果是否可追踪 |  |  |
| 已求解小问是否在框架中有包含核心数值的 current 结果摘要 |  |  |
| 核心结果、单位、区间和约束状态是否已填入正文 |  |  |
| 结果深化证据是否真实存在并贴近对应结论 |  |  |
