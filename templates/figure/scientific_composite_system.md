# 高对比科研图与组合图系统

本文件统一定义数学建模正式结果图的三类增强方向：高对比视觉系统、同一坐标区内的层叠组合图、多面板证据链组合图。三者均由每问唯一的 `QX_plot.m` 实现。

## 1. 三层组合定义

### 1.1 层叠组合图

在同一个坐标区中叠加两种或多种互补图形语法，例如：

- 柱状 + 折线；
- 堆叠柱 + 总量折线；
- 散点 + 模型直线/曲线 + 置信带；
- 箱线 + 抖动散点；
- 小提琴 + 箱线 + 原始散点；
- 直方图 + 密度曲线 + 分位数线；
- 中位数曲线 + 双层分位数带；
- 热图 + 等高线 + 推荐点；
- Pareto 散点 + 前沿线 + 推荐方案点；
- 点估计 + 误差棒 + 原始重复试验点。

层叠组合图用于回答同一个证据问题，不得把无关指标强行叠在一起。

### 1.2 多面板组合图

使用多个坐标区组织互补证据，常见顺序为：主结果 → 机制/分层 → 误差/约束 → 敏感性/鲁棒性。优先采用 1+2、左大右二、1+3 等非对称布局，不机械固定为 2×2。

### 1.3 混合组合图

多面板图中的某个面板本身使用层叠组合图。例如：a 面板为预测曲线+区间带，b 面板为残差散点+零线，c 面板为箱线+散点，d 面板为参数热图+等高线。

## 2. 何时升级为组合图

- 单一图形无法同时表达原始样本与统计汇总时，使用层叠组合图；
- 同一横轴下需要比较数量与变化率、总量与比例时，可使用柱线组合；
- 需要同时表达分布形状、四分位数和个体样本时，使用小提琴/箱线与散点组合；
- 需要表达观测关系与模型关系时，使用散点、模型线和区间带组合；
- 一个核心结论需要结果、机制和验证三类证据时，使用多面板；
- 单图或单面板已足够清楚时，不为复杂而组合。

## 3. 层叠组合图选择矩阵

| 证据结构 | 优先组合 | 必需数据 | 关键规则 |
|---|---|---|---|
| 类别规模 + 变化率/效率 | 柱状 + 折线 | 类别、柱指标、线指标、单位 | 同单位优先单轴；不同单位仅在必要时双轴 |
| 类别组成 + 总量 | 堆叠柱 + 总量折线 | 类别、组成分量、总量 | 分量之和必须与总量口径一致 |
| 观测关系 + 模型关系 | 散点 + 拟合线/机理曲线 + 区间带 | 原始点、模型线、上下界 | 支撑结论的模型线和区间由 Python 输出 |
| 分组位置 + 原始样本 | 箱线 + 抖动散点 | 组别、逐样本值 | 箱体作汇总，散点不得被完全遮挡 |
| 分布形状 + 样本 + 汇总 | 小提琴 + 箱线/中位数 + 散点 | 组别、逐样本值 | 小样本时弱化或删除小提琴层 |
| 分布频数 + 平滑形状 | 直方图 + 密度曲线 + 参考线 | 逐样本值、分箱或密度参数 | 密度线与直方图使用一致归一化口径 |
| 趋势 + 不确定性 | 中心线 + 双层区间带 + 关键点 | 横轴、中位数/均值、分位数/区间 | 先画宽区间，再画窄区间和中心线 |
| 参数面 + 阈值 | 热图 + 等高线 + 基准/推荐点 | 参数网格、响应矩阵、边界、推荐点 | 不可行区域必须遮罩或单独编码 |
| 多目标权衡 | 散点 + Pareto 前沿 + 推荐点 | 可行方案、各目标、前沿状态 | 推荐点使用高对比描边，不隐藏非前沿点 |
| 估计量 + 不确定性 + 重复试验 | 点估计 + 误差棒 + 原始点 | 点估计、区间、逐次结果 | 原始点透明、点估计置于最上层 |

## 4. 绘制层级：从背景到结论

同一坐标区按以下顺序绘制：

1. 背景层：可行域、风险区、置信带、分位数带；
2. 结构层：柱体、小提琴、箱体、热图；
3. 原始数据层：散点、重复试验点、场景点；
4. 模型层：趋势线、拟合线、Pareto 前沿、等高线；
5. 结论层：最优点、临界点、基准线、容差线和少量标签。

后绘制的结论层不得被前面的填充对象遮挡。透明度通常为：宽区间 0.10--0.16，窄区间 0.18--0.28，原始散点 0.35--0.70，主体结构 0.82--0.95。

## 5. 高对比颜色角色

推荐固定角色映射：

| 角色 | HEX |
|---|---|
| 主模型/核心结果 | `#123B5D` |
| 改进模型/第二证据 | `#009E91` |
| 第三方法/结构差异 | `#6B4FA3` |
| 风险/失败/不可行 | `#C63D3D` |
| 最优点/临界点 | `#E07A24` |
| 次级阈值/警戒 | `#D3A000` |
| 坐标轴/文字 | `#181C22` |
| 非重点数据 | `#8B929A` |
| 区间/背景 | `#E5E7E9` |
| 辅助区域 | `#E8D7BF` |

一张图通常使用一个主色、一个对比色、一个风险或强调色和灰色辅助。同一变量跨图层、跨面板必须保持同色。

## 6. 双纵轴准入

柱线组合只有同时满足以下条件才允许双纵轴：

1. 两个指标共享同一横轴和同一观测对象；
2. 两个指标单位确实不同，无法通过合理标准化放在单轴；
3. 两个指标之间存在需要共同阅读的机制关系；
4. 左右轴颜色与对应图形一致，且图注明确单位；
5. 不通过任意缩放制造相关性或夸大趋势；
6. 每张图最多两个纵轴。

若两个指标单位相同或可直接比较，必须使用单轴。无机制关系的两个指标不得仅为节省版面叠加。

## 7. 典型组合细则

### 7.1 柱状 + 折线

- 柱体承担规模、数量、成本或绝对量；
- 折线承担效率、比例、增长率、累计值或第二连续指标；
- 柱体采用主色或分类色，折线采用橙色/青绿色并增加深色描边标记；
- 类别较多时优先排序；折线点与柱中心严格对齐；
- 不同时使用堆叠柱、三条折线和双轴造成认知过载。

### 7.2 散点 + 模型线

- 原始点使用半透明填充和深色边缘；
- 模型线线宽高于散点边缘；
- 有区间时先绘制区间带，再绘制模型线和原始点；
- 模型线、置信区间和预测区间若承担模型结论，必须由 Python 工作簿提供；MATLAB 仅允许计算抖动、显示网格和非决策性视觉辅助。

### 7.3 箱线 + 散点

- 箱体宽度克制，原始点采用确定性抖动；
- 中位数线使用墨黑或主色，离群点不删除；
- 样本量较小时应显示全部散点；
- 组间颜色用于真实分组，不为装饰随机换色。

### 7.4 小提琴 + 箱线 + 散点

- 小提琴表示密度形状，箱体表示四分位数，散点表示真实样本；
- 样本过少或密度估计不稳定时，降级为箱线 + 散点；
- 小提琴层透明度低于散点和中位数；
- 核密度带宽属于绘图参数，必须固定并记录，不能将形状解释为新的模型结论。

### 7.5 直方图 + 密度 + 参考线

- 直方图采用 `Normalization="pdf"` 时，密度线也使用概率密度口径；
- 均值、中位数、阈值只保留与结论相关的参考线；
- 小样本不得用过度平滑的密度曲线掩盖离散结构。

### 7.6 线 + 双层区间带

- 先画 5%--95% 宽区间，再画 25%--75% 窄区间，最后画中位数；
- 不可行场景不得从区间中静默删除，应附加失败率或暗红标记；
- 关键点使用橙色和深色外轮廓。

## 8. 多面板证据链

- 面板通常为 3--4 个；主面板面积最大；
- 优先布局：上一下二、左大右二、上一下三；
- 面板顺序：主结果 → 机制/分层 → 误差/约束 → 稳定性；
- 每个面板可以使用本文件定义的层叠组合图；
- 图例优先共享，相关面板共享尺度和颜色映射；
- 面板只保留 a、b、c、d，不重复总标题。

## 9. MATLAB 允许与禁止的绘图计算

允许的非决策性渲染变换：确定性抖动、柱体定位、透明区间、图例布局、固定带宽 KDE 轮廓、直方分箱、面板布局。

必须由 Python 输出：拟合系数、预测线、置信/预测区间、Pareto 前沿状态、最优点、显著性、敏感性指数、模型排名和任何进入正文结论的统计量。

## 10. Figure Contract 增补

每张图应记录：

- Composition level：single / layered / multi-panel / hybrid；
- Layer map：背景、结构、原始数据、模型、结论各层；
- Axis contract：单轴/双轴、单位、范围和基准线；
- Panel map：多面板时各面板职责；
- Shared color mapping：变量和颜色角色；
- Rendering transforms：抖动、KDE、分箱等仅绘图参数；
- Source workbook/worksheet by layer or panel。

## 11. 删除和降级规则

- 两种图形表达相同信息时删除弱层；
- 双轴没有机制关系时拆图；
- 小提琴样本不足时降级为箱线 + 散点；
- 原始点过密时使用透明度、抽样显示或密度轮廓，但底层数据不得删除；
- 多面板缩放到论文实际尺寸后不可读时拆分；
- 无法追溯到工作簿或无法说明证据作用的组合图不得进入终稿。
