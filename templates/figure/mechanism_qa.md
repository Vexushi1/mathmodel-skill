# HSK 机理/推导图 QA 检查表

| 检查项 | 是/否 | 备注 |
|---|---|---|
| 该图是否为本题专属，而不是通用流程图 |  |  |
| 图中是否包含题目中的真实对象、动作或约束 |  |  |
| 图中符号是否与正文变量表一致 |  |  |
| 图是否能导出至少一个公式、约束、假设或判定条件 |  |  |
| 正文是否明确引用该图并解释其作用 |  |  |
| 图注是否说明机制、边界或推导关系 |  |  |
| 是否解释了为什么不能使用过度简化模型 |  |  |
| 是否包含临界状态、反例或边界验证（若适用） |  |  |
| 图是否避免装饰性元素，保持清晰可读 |  |  |
| 该图是否与代码中的判断函数或结果输出闭合 |  |  |
| 图前六问是否均已回答，尤其是支撑公式/约束、评委应相信什么、无图时哪段说不清 |  |  |
| S 级图是否至少绑定 1 个核心公式或 1 组核心约束 |  |  |
| 图中是否避免堆叠完整公式推导，仅保留必要变量和关系 |  |  |
| 是否排除了通用输入—模型—输出流程图作为核心机理图 |  |  |
| 若为几何图，切线、边界、方向和临界状态是否精确 |  |  |
