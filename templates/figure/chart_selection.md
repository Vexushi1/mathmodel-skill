# 结果图型选择索引

图型由“要证明的结论”、底层数据结构和信息展示效率共同决定，不按软件默认、图型新奇度或固定禁用清单选择。每张图先填写结果图 Figure Contract，再查本表。

## 图型选择表

| 证据任务 | 常规优先图型 | 可选高级图型 | 必需底层数据 | 主要准入条件与风险控制 |
|---|---|---|---|---|
| 方案/类别数值比较 | 排序条形图、点图、带区间点图 | 饼图、环形图、3D 柱状图、华夫图 | 对象、指标、误差/区间、排序或占比 | 饼图仅用于少量类别和明确整体占比；3D 柱状图仅在双分类结构有额外价值时使用，并处理遮挡 |
| 时间趋势与预测 | 折线 + 区间、真实—预测对照、残差时序 | 流图、河流图、面积堆叠、三维时间曲面 | 时间、真实值、预测值、上下界、分组 | 三维或堆叠表达必须保持时间顺序清晰，不能用平滑或透视掩盖误差 |
| 参数敏感性 | 参数—响应曲线、龙卷风图、局部热图 | 3D 响应曲面、等高线、平行坐标、交互式参数面板 | 参数值、响应、基准点、可行状态 | 3D 曲面要求规则或可解释网格，并附色条、单位及必要的等高线/二维投影 |
| 鲁棒性与扰动 | 区间图、箱线 + 散点、ECDF、场景分位数图 | 密度脊线图、雨云图、三维场景曲面 | 逐次扰动结果、分位数、失败标记 | 必须展示尾部、失败场景或原始点，不能只展示均值或光滑表面 |
| 多算法比较 | 性能剖面、误差—时间散点、带区间点图 | 雷达图、平行坐标、气泡图、三维性能面 | 算法、实例/重复、目标、时间、可行性 | 雷达图指标需同向并标准化、算法数量受控；三维性能面必须避免遮挡和尺度混淆 |
| 排名稳定性 | 名次热图、slopegraph、Top-k 重合率曲线 | 雷达图、弦图、排名流图 | 对象、扰动场景、名次/得分 | 雷达图只比较少量对象；弦图或流图必须控制连线数量并明确方向和权重 |
| 分布差异 | ECDF、箱线/小提琴 + 原始点、直方/密度 | 雨云图、密度脊线图、三维密度曲面 | 逐样本值、组别、统计量 | 高级分布图必须保留样本量、原始点或可核对统计量，不能用平滑掩盖小样本 |
| 相关性与变量结构 | 相关矩阵、散点矩阵、载荷图 | 雷达图、弦图、网络图、3D 散点/曲面 | 配对样本、相关/载荷、显著性 | 不得由相关直接宣称因果；三维图需控制视角并提供二维补充视图 |
| 空间分布 | 分级设色图、局部统计量图、空间残差图 | 3D 地形/曲面、体素图、流线图、空间动画 | 空间键、几何、数值、缺失状态 | 投影、坐标和单位正确；3D 高度或颜色映射必须有明确物理含义 |
| 路径与网络 | 简化网络图、路径高亮、流量宽度图、邻接热图 | 桑基图、弦图、3D 网络、流向动画 | 节点、边、权重、路径/流 | 控制节点和边数量，宽度、方向、颜色和层级含义必须明确，避免毛线团 |
| 调度与资源占用 | 甘特图、资源占用阶梯图、冲突矩阵 | 3D 甘特图、桑基图、资源流图、动画 | 作业、资源、开始/结束、状态 | 高级图只在同时表达多资源或流转关系时采用，不能替代可行性检查 |
| 多目标权衡 | Pareto 前沿、平行坐标、目标空间散点 | 雷达图、3D Pareto 曲面、交互式目标空间 | 可行方案、各目标、推荐点 | 目标需同向化或明确方向；3D 只适用于三目标且需提供二维投影或切片 |
| 约束与可行域 | 可行域图、违反量点图、临界边界图 | 3D 可行域、约束曲面、体积切片 | 约束值、容差、变量/场景 | 三维可行域必须标明边界和可行侧，必要时提供截面图，不得替代约束检查表 |
| 模型拟合与诊断 | 真实—拟合散点、残差图、QQ 图、校准图 | 3D 残差曲面、联合密度图、交互诊断面板 | 真实值、拟合值、残差、概率 | 高级图必须提升异质性或局部结构识别，不得只报 $R^2$ 或准确率 |
| 构成比例与层级 | 排序条形图、堆叠条形图、矩形树图 | 饼图、环形图、旭日图、华夫图、桑基图 | 类别、数值、总量、层级或流向 | 饼图/环形图类别少且总量口径一致；层级数据优先旭日图或矩形树图 |
| 多指标画像 | 平行坐标、标准化点图、热图 | 雷达图、星形坐标、glyph 图 | 对象、指标、方向、标准化值 | 雷达图指标应同向、标准化方法透明、对象数量受控，避免面积错觉 |

## 高级图表通用准入规则

饼图、环形图、雷达图、3D 柱状图、3D 曲面及其他高级图表均允许使用，但必须通过以下检查：

1. **结论匹配**：图型直接服务 Core conclusion，而不是为了视觉复杂度；
2. **信息效率**：相较常规图，能更快或更完整地展示比例、层级、多维结构、空间形态或响应面；
3. **比较可读性**：主要对象、差异、极值和推荐方案能够快速辨认；
4. **视觉诚实性**：透视、面积、角度、遮挡、色彩和归一化不会系统性放大或缩小差异；
5. **数据充分性**：数据量、类别数、维度数和网格密度足以支撑该图型；
6. **补充证据**：必要时同时提供二维投影、等高线、数据标签、原始点或结果表；
7. **可复现性**：能够从指定工作簿、工作表和 `q{x}_plot.m` 重绘。

若高级图表未通过上述检查，改用更直接的二维图型。这里的降级依据是信息效率和误导风险，而不是图型名称。

## 配色规则

1. 默认从 HSK 规则色板中选择颜色，作为稳定起点而非固定限制；
2. 可根据变量语义、连续/离散结构、类别数量、背景和竞赛论文风格灵活调整；
3. 同一对象、算法或方案在全文保持同色，同一方向性语义保持一致；
4. 连续变量使用连续色带，类别变量使用离散色板，正负或高低方向使用发散色带；
5. 颜色数量不得超过有效辨识能力，必要时结合线型、标记、纹理和透明度；
6. 配色不得遮蔽误差线、散点、边界、标签和关键推荐点。

## 多面板规则

1. 只有同一核心结论需要多种互补证据时组合多面板；
2. 每个面板承担独立证据，不把四张弱图拼成一张“大图”；
3. 面板顺序遵循“主结果 → 机制/分层 → 误差/验证”；
4. 面板只保留 a、b、c、d 标记，不重复总标题；
5. 图例、颜色、变量命名和统计口径在面板间一致；
6. 高级面板与常规面板组合时，应说明各自不可替代的证据职责。

## 删除规则

无法绑定小问、工作簿、工作表、`q{x}_plot.m` 和正文结论的图删除。无法从底层数据重绘，或高级形式不能提高信息展示效率的图不得进入终稿。
