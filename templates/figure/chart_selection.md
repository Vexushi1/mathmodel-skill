# 结果图型选择索引

图型由“要证明的结论”和底层数据结构决定，不按软件默认或视觉新奇度选择。正式绘图同时执行 `templates/figure/scientific_composite_system.md` 的高对比配色、层叠组合图和多面板证据链规则。

## 1. 基础图型选择

| 证据任务 | 优先图型 | 必需底层数据 | 不推荐做法 |
|---|---|---|---|
| 方案/类别数值比较 | 排序条形图、点图、带区间点图 | 对象、指标、误差/区间、排序 | 饼图、3D 柱图、未排序拥挤柱图 |
| 时间趋势与预测 | 折线 + 区间、真实—预测对照、残差时序 | 时间、真实值、预测值、上下界 | 只有平滑曲线、截断时间轴掩盖误差 |
| 参数敏感性 | 参数—响应曲线、龙卷风图、局部热图 | 参数值、响应、基准点、可行状态 | 只报弹性系数、把无量纲和有量纲混画 |
| 鲁棒性与扰动 | 区间图、箱线/小提琴 + 散点、ECDF、场景分位数图 | 逐次扰动结果、分位数、失败标记 | 只展示均值柱图、隐藏失败场景 |
| 多算法比较 | 性能剖面、误差—时间散点、带区间点图 | 算法、实例/重复、目标、时间、可行性 | 只报最佳一次结果、双轴混淆尺度 |
| 排名稳定性 | 名次热图、slopegraph、Top-k 重合率曲线 | 对象、扰动场景、名次/得分 | 雷达图堆叠过多对象 |
| 分布差异 | ECDF、箱线/小提琴 + 原始点、直方/密度 | 逐样本值、组别、统计量 | 只报均值、平滑密度掩盖小样本 |
| 相关性与变量结构 | 散点 + 模型线、相关矩阵、散点矩阵、载荷图 | 配对样本、模型线、区间、相关/载荷 | 由相关直接宣称因果 |
| 空间分布 | 分级设色图、局部统计量图、空间残差图 | 空间键、几何、数值、缺失状态 | 彩虹色、无图例单位、错误投影 |
| 路径与网络 | 简化网络图、路径高亮、流量宽度图、邻接热图 | 节点、边、权重、路径/流 | 毛线团网络、节点大小无定义 |
| 调度与资源占用 | 甘特图、资源占用阶梯图、冲突矩阵 | 作业、资源、开始/结束、状态 | 只画甘特图而不提供可行性检查 |
| 多目标权衡 | Pareto 散点 + 前沿线 + 推荐点、平行坐标（少量方案） | 可行方案、各目标、前沿状态、推荐点 | 先武断加权再只画总分 |
| 约束与可行域 | 可行域图、违反量点图、临界边界图 | 约束值、容差、变量/场景 | 用结果图替代约束检查表 |
| 模型拟合与诊断 | 真实—拟合散点 + 参考线、残差图、QQ 图、校准图 | 真实值、拟合值、残差、概率 | 只报 $R^2$ 或准确率 |

## 2. 层叠组合图优先级

当单一图形无法同时表达原始数据、统计汇总和模型结论时，优先使用同一坐标区内的层叠组合图。

| 同时需要表达 | 优先层叠组合 | 轴规则 |
|---|---|---|
| 类别绝对量与效率/比例 | 柱状 + 折线 | 同单位单轴；不同单位通过双轴准入后使用双轴 |
| 类别组成与总量 | 堆叠柱 + 总量折线 | 总量必须等于各分量口径之和 |
| 原始观测与模型关系 | 散点 + 模型线 + 区间带 | 模型线和区间由 Python 输出 |
| 分组统计与原始样本 | 箱线 + 抖动散点 | 箱体居后，散点和中位数居前 |
| 分布形状、四分位数与样本 | 小提琴 + 箱线/中位数 + 散点 | 小样本降级为箱线 + 散点 |
| 频数分布与平滑形状 | 直方图 + 密度曲线 + 参考线 | 直方图和密度使用一致归一化 |
| 中心趋势与不确定性 | 中心线 + 双层区间带 + 关键点 | 宽区间先画，中心线和关键点最后画 |
| 参数面与阈值边界 | 热图 + 等高线 + 推荐点 | 不可行区域遮罩，不使用彩虹色 |
| 多目标方案与前沿 | 散点 + Pareto 前沿 + 推荐点 | 非前沿点保留为背景证据 |
| 点估计、区间和重复结果 | 误差棒 + 点估计 + 原始点 | 原始点透明，估计量置于最上层 |

## 3. 组合层级选择

- `single`：单一图形已足够回答结论；
- `layered`：同一坐标区叠加多种图形语法；
- `multi-panel`：多个坐标区组织结果、机制和验证；
- `hybrid`：多面板中的一个或多个面板使用层叠组合。

优先顺序不是越复杂越好，而是使用能够完整表达证据的最低复杂度。层叠组合图仍无法容纳不同证据问题时，再升级为多面板或混合组合图。

## 4. 多面板规则

1. 只有同一核心结论需要多种互补证据时组合多面板；
2. 每个面板承担独立证据，不把四张弱图拼成一张“大图”；
3. 面板顺序遵循“主结果 → 机制/分层 → 误差/约束 → 稳定性”；
4. 优先使用上一下二、左大右二、上一下三等非对称布局；
5. 面板可以使用层叠组合图；
6. 面板只保留 a、b、c、d 标记，不重复总标题；
7. 图例、颜色、变量命名、单位和统计口径在面板间一致。

## 5. 双轴与视觉计算边界

- 双轴仅用于共享横轴、单位不同且存在明确机制关系的两个指标；每图最多两个纵轴；
- 左右轴颜色必须与对应图形一致，禁止通过任意缩放制造相关性；
- MATLAB 可进行抖动、透明度、固定带宽 KDE、直方分箱和布局等非决策性渲染；
- 拟合线、预测线、置信区间、Pareto 状态、显著性和进入正文的统计量必须由 Python 工作簿提供。

## 6. 删除规则

无法绑定小问、工作簿、工作表、`QX_plot.m` 本地图函数和正文结论的图删除。两种图形表达同一信息时删除弱层；组合后缩放到论文实际尺寸不可读时拆分；无法从底层数据重绘的图不得进入终稿。
