# HSK MATLAB 科研绘图模板 v6.2.2

MATLAB 只读取 Python 输出的两类标准工作簿，不重新求解。

```text
结果数据表/问题X/问题X结果数据/
├─ 问题X求解结果.xlsx
└─ 问题X敏感性与鲁棒性结果.xlsx
```

## 问题绘图脚本命名

每个问题只设置一个主绘图入口，统一命名为：

```text
MATLAB绘图/问题一/q1_plot.m
MATLAB绘图/问题二/q2_plot.m
MATLAB绘图/问题三/q3_plot.m
...
```

规则为 `q{x}_plot.m`，其中 `x` 是阿拉伯数字问题编号。不要使用 `问题一结果绘图.m`、`plot_q1.m`、`q1_polt.m` 等其他命名。

一个主入口可以调用若干问题专属辅助函数，但论文图的读取、生成和图窗管理应从 `q{x}_plot.m` 进入。

## 使用顺序

1. `books = hsk_read_result_workbooks(projectRoot, "问题一")`；
2. 用 `readtable(books.solution, "Sheet", "明细结果", "VariableNamingRule", "preserve")` 读取工作表；
3. 运行对应的 `q{x}_plot.m`；
4. 保留可见图窗，人工调整尺寸、视角、图例、标签和颜色；
5. 需要导出时显式调用 `hsk_export_figure(fig, outputBase)`。

## 图型与配色

- 常规图表、饼图、环形图、雷达图、3D 柱状图、3D 曲面及其他高级图表均可使用；
- 选型依据是结论匹配、信息展示效率、比较效率、失真风险和可复现性；
- 默认调用 `hsk_apply_scientific_style.m` 提供的规则色板；
- 默认色板不是固定限制，可根据变量语义、类别数量、连续/离散结构、三维表面和论文整体风格灵活调整；
- 3D 图需要处理视角、遮挡、色条、投影和单位；必要时同时给出二维投影或等高线；
- 饼图和雷达图需控制类别或对象数量，并保留可核对的比例、标准化方法或数值信息。

禁止默认隐藏图窗、批量自动导出、关闭图窗或在 MATLAB 中重新计算核心结果。
