# HSK MATLAB 单文件科研绘图模板 v6.2.2

MATLAB 只读取 Python 输出的两类标准工作簿，不重新求解：

```text
结果数据表/问题X/问题X结果数据/
├─ 问题X求解结果.xlsx
└─ 问题X敏感性与鲁棒性结果.xlsx
```

## 每问唯一输出

每个问题只生成一个自包含 MATLAB 文件：

```text
MATLAB绘图/
├─ 问题一/Q1_plot.m
├─ 问题二/Q2_plot.m
└─ 问题三/Q3_plot.m
```

文件名必须使用 `QX_plot.m`，其中 `X` 为阿拉伯数字问题编号。文件内部使用“主入口函数 + 文件末尾本地函数”，不得额外交付读取、样式、导出或根目录定位辅助 `.m` 文件。

## 四级图形复杂度

- `single`：单一图形即可完整表达结论；
- `layered`：同一坐标区内叠加多种图形；
- `multi-panel`：多个坐标区形成结果—机制—验证证据链；
- `hybrid`：多面板中的一个或多个面板继续使用层叠组合图。

`QX_plot.m` 内置典型层叠函数：

- `plot_bar_line_combo`：柱状 + 折线；
- `plot_scatter_fit_combo`：散点 + 模型线 + 区间带；
- `plot_box_scatter_combo`：箱线 + 抖动散点；
- `plot_violin_scatter_combo`：小提琴 + 箱线/中位数 + 散点；
- `plot_hist_density_combo`：直方图 + 密度 + 参考线；
- `plot_hybrid_evidence_combo`：主结果、敏感性和鲁棒性混合组合图。

完整选择规则见 `templates/figure/scientific_composite_system.md` 和 `templates/figure/chart_selection.md`。

## 使用顺序

1. 复制 `QX_plot.m`，同步替换文件名、入口函数名、`problemIndex` 和 `problemName`；
2. 根据两类标准工作簿中的真实工作表和字段，选择单图、层叠、多面板或混合组合；
3. 删除与该问题不适配的示例函数，保留真正支撑结论的绘图函数；
4. 直接运行一次 `QX_plot`，生成核心结果、诊断、多算法比较、敏感性和鲁棒性等全部需要的图窗；
5. 不适用的图不创建空图窗，由工作簿 `适用性说明` 记录原因；
6. 保留可见图窗，人工调整尺寸、图例、标签和面板布局；
7. 确认后将文件内 `exportFigures` 改为 `true`，统一导出 PDF/PNG，可选 SVG。

## 高对比风格

默认颜色角色：深海军蓝表示主结果，青绿表示第二证据，蓝紫表示第三方法，暗红表示风险或不可行状态，橙色表示最优点或临界点；灰色和米色只用于非重点数据、区间和背景。同一变量跨图层、跨面板保持同色。

默认刻度向外、轴线墨黑、坐标轴名称约 18、刻度约 16--17、图例约 15--16。主线宽约 2.4--3.0，次线约 1.7--2.1。网格默认关闭，必要时只使用极浅单方向网格。

## 约束

- 一个 `QX_plot.m` 可以创建多个独立图窗，不要求把所有图强行拼成总览图；
- 双纵轴仅用于共享横轴、单位不同且存在明确机制关系的两个指标；
- MATLAB 可进行抖动、透明度、固定带宽 KDE、直方分箱和布局等非决策性渲染；
- 拟合线、预测线、置信区间、Pareto 状态、显著性和进入正文的统计量由 Python 工作簿提供；
- 所有正式图必须记录源工作簿和工作表；
- 禁止根据摘要数字或人工构造序列反推图表；
- 禁止默认隐藏或关闭图窗；
- 默认不自动导出，导出由同一文件内的显式开关控制。
