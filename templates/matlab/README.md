# HSK MATLAB 单文件科研绘图模板 v6.2.2

MATLAB 只读取 Python 输出的两类标准工作簿，不重新求解：

```text
结果数据表/问题X/问题X结果数据/
├─ 问题X求解结果.xlsx
└─ 问题X敏感性与鲁棒性结果.xlsx
```

## 每问唯一输出

每个问题只生成一个自包含 MATLAB 文件：

```text
MATLAB绘图/
├─ 问题一/Q1_plot.m
├─ 问题二/Q2_plot.m
└─ 问题三/Q3_plot.m
```

文件名必须使用 `QX_plot.m`，其中 `X` 为阿拉伯数字问题编号。文件内部使用“主入口函数 + 文件末尾本地函数”，不得额外交付读取、样式、导出或根目录定位辅助 `.m` 文件。

## 使用顺序

1. 复制 `QX_plot.m`，同步替换文件名、入口函数名、`problemIndex` 和 `problemName`；
2. 根据两类标准工作簿中的真实工作表和字段，编写该问题全部绘图函数；
3. 直接运行一次 `QX_plot`，生成核心结果、诊断、多算法比较、敏感性和鲁棒性等全部需要的图窗；
4. 不适用的图不创建空图窗，由工作簿 `适用性说明` 记录原因；
5. 保留可见图窗，人工调整尺寸、图例、标签和多面板布局；
6. 确认后将文件内 `exportFigures` 改为 `true`，统一导出 PDF/PNG，可选 SVG。

## 约束

- 一个 `QX_plot.m` 可以创建多个独立图窗，不要求把所有图强行拼成一张多面板图；
- 所有正式图必须记录源工作簿和工作表；
- 禁止根据摘要数字或人工构造序列反推图表；
- 禁止默认隐藏或关闭图窗；
- 默认不自动导出，导出由同一文件内的显式开关控制；
- 仓库中的历史 helper 文件只用于维护参考，不作为项目交付物复制。
