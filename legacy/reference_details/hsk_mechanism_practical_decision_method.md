# HSK 机理图实战判定法

## 1. 定位

本文件用于补强 v6.1.6 的机理图协议。机理图不是通用流程图，也不是排版装饰；它的直接目标是解释**题目对象关系、核心公式来源、约束成立机制和临界状态判定**。凡不能绑定核心公式、约束或结论的图，应降级为文字说明、并入其他图，或删除。

## 2. 五类机理图

| 类型 | 核心作用 | 适用题目 | 优先级 |
|---|---|---|---|
| 对象关系图 | 说明题目对象的位置、作用、传递关系和边界 | 几何、物理、交通、供应链、生态系统 | 高 |
| 公式来源图 | 说明某个核心公式为何成立 | 几何推导、动力学、微元、遮挡、碰撞、投影 | 极高 |
| 约束来源图 | 说明目标函数或约束条件从哪里来 | 优化、调度、路径规划、资源配置 | 极高 |
| 临界状态图 | 展示刚好满足/刚好失效的边界状态 | 碰撞、遮挡、覆盖、装载、阈值、排队 | 极高 |
| 策略机制图 | 说明策略变量如何影响结果 | 投放策略、政策模拟、资源配置、博弈 | 中高 |

优先保留公式来源图、约束来源图和临界状态图。普通“输入—模型—输出”流程图不视为核心机理图。

## 3. 图前六问

每张机理图绘制前必须回答：

```text
1. 这张图解释哪个题目对象？
2. 这张图支撑哪一个公式、目标函数或约束？
3. 图中必须出现哪些变量？
4. 哪些变量不能放进图里，避免图太乱？
5. 评委看完这张图后，应该相信什么？
6. 如果没有这张图，正文哪一段会说不清？
```

若第 2、5、6 条答不上来，该图不得升为 S 级图。

## 4. 公式/约束绑定规则

1. S 级机理图必须至少绑定 1 个核心公式或 1 组核心约束。
2. A 级机理图应至少绑定变量关系、假设来源、边界条件或结果解释。
3. B 级图若不能支撑公式、约束、假设或结论，原则上删除。
4. 图上只保留必要变量、方向、角度、边界和临界状态，不在图内堆完整公式推导。
5. 公式推导写在正文中，推荐句式为：“结合图 X 的几何关系，可得……”。

## 5. 图面表达规则

图中应画：

- 题目对象；
- 坐标系或空间/时间边界；
- 关键变量符号；
- 方向、距离、角度、流向或决策顺序；
- 可行/不可行、遮挡/未遮挡、碰撞/未碰撞等临界状态。

图中不应放：

- 大段公式推导；
- 与本题无关的算法框；
- 没有变量符号的装饰元素；
- AI 自动生成但几何关系不精确的形状；
- 与正文公式、代码判断无法对应的符号。

## 6. 题型打法

| 题型 | 推荐机理图 | 推荐工具 |
|---|---|---|
| 几何/物理/运动/遮挡/碰撞 | 对象关系图 + 公式来源图 + 临界状态图 | GeoGebra / 几何画板 / SVG / PPT |
| 优化/调度/路径/资源配置 | 变量流图 + 约束来源图 + 策略机制图 | PPT / draw.io / SVG |
| 机器学习/预测 | 特征构造机制图 + 误差来源图 + 解释变量影响路径图 | PPT / draw.io / Python 结果图 |
| 空间计量/网络 | 空间邻接关系图 + 权重矩阵构造图 + 溢出路径图 | GIS / Python / SVG / draw.io |
| 博弈/双层规划/Stackelberg | 参与方关系图 + 决策时序图 + 收益传导图 | PPT / draw.io / SVG |

Python 默认用于可复现结果图；需要精确几何控制的示意图优先使用 GeoGebra、几何画板、PPT 或可编辑 SVG。

## 7. 负面清单

以下图不得作为核心机理图：

```text
1. 只有输入、模型、输出的通用流程图。
2. 只有算法步骤，没有题目对象的流程图。
3. 图中没有任何变量符号的装饰图。
4. 把大段公式推导塞进图里的图。
5. 和正文公式、约束或代码判断没有对应关系的图。
6. AI 自动生成但几何、方向、切线、边界不精确的图。
7. 看起来高级但不能解释约束来源的图。
```

## 8. S/A/B 终筛规则

```text
S级：没有它，核心公式、约束或临界状态说不清。必须后期人工精修。
A级：能明显提高理解，但不是核心公式或约束的唯一来源。简洁处理即可。
B级：删掉不影响论文逻辑。删除或并入文字说明。
```

终稿前执行：删除 B 级图，合并重复 A 级图，锁定 S 级图，统一风格并补齐图—公式—代码—正文闭环。

## 9. 一句话硬规则

机理图不是流程图，不以展示模型名称为目标，而以解释题目对象关系、核心公式来源、约束成立机制和临界状态为目标。凡不能绑定核心公式、约束或结论的机理图，应降级为文字说明或删除。
