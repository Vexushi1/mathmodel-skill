# HSK 高级模型使用准入规则

> 用途：防止为了“显得高级”堆模型名称。凡使用下列高级模型，必须先说明必要性、变量闭环、数据支撑和计算可行性；否则应降级为经典稳健模型或作为附加验证。

| 模型 | 准入问题 | 必须交付 | 常见否决原因 |
|---|---|---|---|
| W-DRO | 不确定变量是什么？经验分布从何而来？鲁棒半径如何确定？ | 不确定集、半径敏感性、稳健-性能权衡 | 样本极少却构造高维分布鲁棒 |
| CVaR | 风险变量是什么？置信水平为何合理？尾部损失是否有现实意义？ | 损失分布、置信水平、CVaR 结果解释 | 没有随机损失却硬加风险项 |
| MPEC | 上下层或均衡约束是否真实存在？互补约束如何求解？ | 上下层变量、KKT/互补条件、可行性检查 | 业务中不存在均衡或反应者 |
| Stackelberg | 领导者和跟随者是否明确？行动顺序是否符合题意？ | 双方目标、策略空间、均衡求解 | 只有单主体优化却强行博弈 |
| 图神经网络 | 图结构来自哪里？节点/边特征是否足够？样本量是否支撑？ | 图构造、特征表、训练验证方案 | 只有少量节点或无真实边关系 |
| 空间杜宾模型 | 是否存在空间相关？权重矩阵如何构造？ | Moran's I、权重矩阵、稳健性对比 | 没有空间单元或空间关系牵强 |
| 双重机器学习 | 处理变量、结果变量、混杂变量是否明确？ | 变量分组、交叉拟合、稳健性检验 | 只是预测题却声称因果识别 |
| 强化学习 | 是否存在可交互环境、状态、动作、奖励和多阶段反馈？ | MDP 定义、奖励函数、仿真环境 | 静态优化题硬套 RL |
| 深度学习 | 样本量是否足够？是否优于传统模型？ | 数据规模说明、基线对比、过拟合控制 | 小样本无验证直接用 LSTM/CNN |

## 准入四问

使用任何高级模型前，必须回答：

1. **必要性**：经典模型为什么不足？
2. **变量闭环**：决策变量、状态变量、目标变量和约束是否完整？
3. **数据支撑**：题目附件或可合理补充的数据是否足够？
4. **计算可行性**：比赛时间内是否能稳定求解并复现？

若任一问题无法回答，应将高级模型降级为“备选验证”或直接否决。
