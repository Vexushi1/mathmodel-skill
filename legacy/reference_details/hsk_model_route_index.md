# HSK 题型—模型路线索引

> 用途：快速启动建模路线比较。该索引只能辅助选型，不能替代逐字审题、数据字段审计和变量闭环。

| 题型 | 经典稳健路线 | 高级创新路线 | 慎用模型 | 核心检查 |
|---|---|---|---|---|
| 预测题 | ARIMA / GM(1,1) / 回归 / XGBoost | 时序集成 / 贝叶斯状态空间 / 分层预测 | 小样本 LSTM、无验证深度学习 | 时间粒度、训练测试切分、残差诊断 |
| 评价题 | AHP / 熵权法 / TOPSIS / 灰色关联 | VIKOR / PROMETHEE / 组合赋权 / 稳健排序 | 只用主观权重、指标方向未统一 | 指标方向、权重敏感性、排序稳定性 |
| 优化题 | LP / IP / NLP / 动态规划 / 图论 | 多目标优化 / 鲁棒优化 / 随机规划 | 纯启发式无可行性检查 | 目标函数、约束、可行性、最优性证据 |
| 机理题 | 几何解析 / 微分方程 / 仿真 / 参数反演 | 机理-数据融合 / 多算法交叉验证 | 黑箱机器学习替代机理 | 物理量单位、边界条件、误差传播 |
| 分类题 | Logistic / SVM / 决策树 / 随机森林 | Stacking / XGBoost / 可解释机器学习 | 类别极不平衡但不处理 | 混淆矩阵、类别指标、泛化检验 |
| 聚类题 | K-means / 层次聚类 / DBSCAN | 谱聚类 / GMM / 稳健聚类 | 不定簇数强行聚类 | 标准化、簇数选择、轮廓系数 |
| 图论网络题 | 最短路 / 最小生成树 / 最大流 / TSP | 多层网络 / 时空网络 / 网络鲁棒性 | 边权无现实解释 | 节点边定义、连通性、复杂度 |
| 空间题 | 空间权重矩阵 / Moran's I / GWR | 空间杜宾模型 / 空间滞后模型 / 图模型 | 普通回归忽略空间相关 | 权重矩阵、空间自相关、边界效应 |
| 不确定性题 | 灵敏度分析 / 蒙特卡罗 / 情景分析 | CVaR / 鲁棒优化 / W-DRO | 无不确定变量却强上鲁棒 | 不确定源、分布/集合、置信水平 |

## 使用流程

1. 先根据题干判断题型；
2. 再检查数据是否支撑该类模型；
3. 每问至少给一条经典稳健路线和一条改进/创新路线；
4. 高级路线必须通过 `references/hsk_advanced_model_gatekeeping.md` 的准入检查；
5. 最终路线必须能落到变量、公式、代码、结果和论文图表。
