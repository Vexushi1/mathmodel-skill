# HSK Stage 10：LaTeX 终稿论文协议

## 1. 定位

LaTeX 阶段只在模型、结果、核心图表和正文逻辑基本锁定后执行。中文国赛论文默认基于 `cumcmthesis` 模板，保留国赛模板体系。

## 2. 终稿任务

LaTeX 终稿负责：正式公式编号、图表交叉引用、三线表、摘要单页控制、目录页码、参考文献、附录、图表位置、最终 PDF 编译和提交检查。

## 3. 插图规范

- 机理图优先插入后期精修导出的 PDF；
- 结果图优先插入由代码生成的 PDF/PNG；
- SVG 不作为 LaTeX 主插图格式，除非编译链明确支持；
- 图像文件名建议英文或拼音，避免中文路径导致编译失败。

## 4. DOCX 草稿迁移检查

迁移时必须检查：DOCX 草稿中的图位占坑是否全部替换、公式是否重新编号、正文引用是否闭合、结果数值是否与 `data_output/` 一致、图注是否解释机制或结论。

## 5. 从 DOCX 排版稿迁移到 LaTeX 的额外检查

若 DOCX 草稿已按 Word 格式深度修改，迁移 LaTeX 前还需检查：

1. 原生 Word 表格是否已转换为 LaTeX 三线表；
2. 图题和“由图X可知……”解释段是否分离；
3. 图后解释是否保留在正文而非 caption 中；
4. 公式是否重新用 LaTeX 编号并交叉引用；
5. 正文伪代码是否转为 algorithm / table / enumerate 等 LaTeX 结构；
6. 附录代码说明表和完整代码是否完整迁移。

## 6. AI 模板感清除

LaTeX 终稿编译前必须执行 AI 模板感清除。检查对象包括摘要、问题分析、模型评价、结论、图表解释和附录说明。

清除规则：

1. 删除“具有重要意义”“提供参考价值”“较好地解决”等空泛句。
2. 删除没有结果证据支撑的“显著提高”“明显优于”“效果较好”。
3. 删除正文中过多的路线比较表、检查表、合同表和 QA 表；必要时移入附录或交接材料。
4. 删除不能支撑结论的装饰图、通用流程图和无题目对象的算法流程图。
5. 将泛化表述改为具体误差、排名、提升率、稳定性指标、约束违反量或鲁棒性结果。
6. 将模板化问题分析改写为本题对象、核心难点、建模抓手和结果用途。
7. 检查摘要、结论和正文结果是否一致；任何核心结论必须能反向定位到公式、表格、图或结果文件。

若某个结论无法被公式、数据、代码输出、图表、约束检查或鲁棒性分析支撑，应删除或降级为讨论，不得写成最终结论。
