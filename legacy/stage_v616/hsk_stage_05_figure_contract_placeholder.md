# HSK Stage 05：机理图合同与图位占坑协议

## 1. 定位

本阶段位于“逐问机制理解、变量公式闭环”之后，正式求解和论文精修之前。目标不是立即画出最终机理图，而是为每个核心机制建立图表合同、图位占坑和正文解释钩子，避免建模过程被画图排版拖慢。

## 2. 执行原则

1. 先规划，后精修：审题和建模阶段只做机理图合同与占位，不做最终美化。
2. 每问有机制解释，但不强制每问单独留一张图。
3. 一张核心机理图可以服务多个小问，并在多个章节重复引用。
4. 机理图数量以少而精为原则，全文通常保留 3--6 张核心机理图。
5. 结果稳定后，再统一筛选、合并、生成 SVG/PPT/GeoGebra 草稿并人工精修。

## 3. 机理图合同字段

| 字段 | 要求 |
|---|---|
| 图编号 | 图 X，允许暂定 |
| 图名 | 简洁说明该图表达的机制 |
| 对应问题 | 可对应单问或多问 |
| 图的作用 | mechanism / derivation / boundary / validation / decision |
| 图中对象 | 题目对象、变量、几何元素、状态或约束边界 |
| 支撑公式/约束 | 对应公式编号或暂定公式 |
| 变量链接 | 对应变量表中的符号 |
| 评委质疑点 | 若无该图，评委可能质疑什么 |
| 图等级 | S / A / B |
| 后期处理方式 | SVG / PPT / GeoGebra / Python / 不画 |

## 4. 图等级

- S 级：题目对象抽象、核心公式来源、关键约束机制、临界状态判断。后期必须人工精修。
- A 级：辅助说明、局部结构、普通几何关系。可用简洁 SVG / PPT 线稿。
- B 级：文字、公式或结果图能说清楚的内容。原则上不单独绘制。

## 5. DOCX / LaTeX 占位要求

论文草稿中可以先放置图位占坑，但占坑必须写清：图名、对应问题、图的作用、支撑公式、Reviewer risk 和后期处理方式。

示例：

```text
【图 X 占位：刚性把手链等效机理图】
对应问题：问题一、问题二、问题三、问题五
图的作用：说明真实板凳由孔中心等效为刚性点链
支撑公式：||P_i-P_{i-1}||_2=d_i
Reviewer risk：若无该图，评委可能质疑把板凳龙误化为柔性绳或忽略孔距约束
后期处理：SVG/PPT 黑白线稿精修后替换
```

## 6. 后期精修规则

模型求解、结果图、约束检查、敏感性和鲁棒性完成后，再统一执行：

```text
删除不必要机理图 → 合并重复机理图 → 锁定 S 级图 → 生成 SVG/PPT/GeoGebra 草稿 → 人工精修 → 导出 PDF/PNG/SVG → 替换占位图 → 补正文解释
```

SVG 线稿应尽量使用普通 `line`、`polyline`、`rect`、`circle` 和 `text`，避免使用 SVG marker 箭头，以保证转 EMF/PPT 后可编辑。


## 7. 实战判定补充

建立机理图合同前，先执行图前六问：

```text
1. 这张图解释哪个题目对象？
2. 这张图支撑哪一个公式、目标函数或约束？
3. 图中必须出现哪些变量？
4. 哪些变量不能放进图里，避免图太乱？
5. 评委看完这张图后，应该相信什么？
6. 如果没有这张图，正文哪一段会说不清？
```

若第 2、5、6 条答不上来，该图不得升为 S 级图。S 级图必须至少绑定 1 个核心公式或 1 组核心约束；B 级图若不能支撑公式、约束、假设或结论，应删除或并入正文文字。

图面只放对象、变量、方向、边界、距离、角度、流向、决策顺序和临界状态；公式推导放正文。
