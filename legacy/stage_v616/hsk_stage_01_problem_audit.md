# HSK Stage 01：逐字审题与问题理解报告

## 核心原则

不急于建模，不直接给代码。先把题目拆成“背景、对象、动作、数据、约束、目标、输出”，并先形成手工草图/机理草图。

## 标准输出

### 1. 题目要素拆解

| 模块 | 内容 |
|---|---|
| 背景信息 | 现实场景、研究对象、业务逻辑 |
| 核心问题 | 题目真正要求解决的问题 |
| 已知条件 | 数据、参数、附件、规则、边界 |
| 约束条件 | 明确约束与隐含约束 |
| 输出要求 | 数值、策略、图表、模型、结论 |
| 评价重点 | 准确性、创新性、可解释性、可操作性 |
| 初始草图 | 题目对象关系、空间位置、运动链路、作用机制和关键边界 |
| 易错简化 | 不能直接简化或容易被 AI 套错的地方 |

### 2. 各小问目标拆解

| 小问 | 直接目标 | 隐含目标 | 所需数据 | 问题依赖 | 题型分类 | 命题意图 | 最终交付 |
|---|---|---|---|---|---|---|---|

必须优先识别：题目中的真实对象及其几何/物理/业务关系；哪些对象不能被粗暴点化、线性化或静态化；哪些边界、临界状态或反例能够说明模型必要性；哪张图可以让评委相信队伍真正思考过题目。


## 禁止事项

- 不得跳过题目附件字段直接套模型；
- 不得把题目问题改写成更容易做但不等价的问题；
- 不得遗漏单位、时间粒度、空间粒度、边界条件；
- 不得用通用流程图替代本题对象关系图、机理图或临界图；
- 不得在没有解释关键机制的情况下直接套高级模型或优化算法。
