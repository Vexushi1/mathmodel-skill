# Legacy Archive

本目录仅用于旧项目追溯、兼容和迁移，不属于 v7.4.1 默认运行链路。

- `stage_v616/`：旧 Stage 00--12 文件；
- `old_stage_0_9/`：更早的评分、反馈层和状态系统；
- `v616_sources/`：v6.1.6 入口文件快照；
- `reference_details/`：已被活动模块吸收的详细旧协议；
- `writing_phrase_corpus/`：竞赛句式和语料，仅可人工查阅，不得自动套写；
- `competition_data/`：旧经验参数和 rubric 数据；
- `tools/`：非默认的下载、抽取和语料处理脚本；
- `matlab_compat/`：已退出新项目默认链路的 MATLAB 路径搜索与显式导出辅助函数。

`matlab_compat/` 只用于迁移仍依赖旧共享函数、旧 `结果数据表/问题X/` 或自动导出图表目录的历史项目。v7.2.0--v7.2.1 项目重新进入设计/求解时沿用三态 `preprocessing_decision`，并按当前题目、当前附件和模型输入要求重新执行通用数据审计，不得因共享原始数据、存在缺失或过去赛题习惯自动迁移为 `project_level`；v7.1.x 及更早项目继续只读兼容，重新进入当前流程时先完成数据审计与判定。v7.0.x 缺少语义治理字段的项目按既有规则迁移；v6.6.x 单脚本四文件项目也仅作为只读兼容输入。新项目使用 `问题X求解/` 中的两阶段 Python、两个标准工作簿和 `q{x}_plot.m`，只有 `project_level` 才额外创建 `数据预处理/`；MATLAB 默认只保留图窗而不自动导出文件。

除非用户明确要求兼容旧项目或查找旧规则，禁止加载本目录。
