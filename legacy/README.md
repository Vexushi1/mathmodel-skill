# Legacy Archive

本目录仅用于旧项目追溯、兼容和迁移，不属于 v6.2.0 默认运行链路。

- `stage_v616/`：旧 Stage 00--12 文件；
- `old_stage_0_9/`：更早的评分、反馈层和状态系统；
- `v616_sources/`：v6.1.6 入口文件快照；
- `reference_details/`：已被六大模块吸收的详细旧协议；
- `writing_phrase_corpus/`：竞赛句式和语料，仅可人工查阅，不得自动套写；
- `competition_data/`：旧经验参数和 rubric 数据；
- `tools/`：非默认的下载、抽取和语料处理脚本。

除非用户明确要求兼容旧项目或查找旧规则，禁止加载本目录。
