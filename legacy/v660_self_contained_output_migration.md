# v6.6.0 旧项目输出目录迁移说明

本文件仅用于历史项目迁移，不参与活动 Skill 默认加载、活动索引或用户新项目输出。

## 新项目标准

每个小问只保留一个自包含目录：

```text
问题X求解/
├─ 问题X求解.py
├─ 问题X求解结果.xlsx
├─ 问题X结果深化分析.xlsx
└─ qX_plot.m
```

主工作簿验收后，在同一个 `问题X求解.py` 中加入结果深化分析阶段，不再创建独立分析脚本。`qX_plot.m` 只读取同目录两个标准工作簿，默认不创建图表子目录或自动导出图片。

## 历史项目兼容

以下旧结构只读兼容，不再作为新项目输出：

- `结果数据表/问题X/`；
- 根目录 `问题X求解.py`；
- 根目录 `问题X结果深化分析.py`；
- `问题X敏感性与鲁棒性结果.xlsx`；
- 独立完整运行配置、运行说明和校验报告；
- `figure_evidence.yaml` 与自动导出的 `图表/`。

迁移时应先确认两个工作簿仍对应同一模型、数据和代码哈希，再移动文件。不得仅移动目录而跳过主结果质量门、结果深化分析验收或 stale 检查。
